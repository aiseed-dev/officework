= docx・xlsx との違い

Word や Excel から来た方へ。**画面はほとんど同じです。変えたのは、保存する形です。**

リボンのタブもボタンの並びも、覚えたとおりに使えます。
戸惑うのは、保存して開き直したときです。
その戸惑いは全部ここに集めました。

== 一番大きい違い — 本文と見た目を分けました

docx は、1つのファイルに本文と見た目を一緒に入れます。
officework の `.adoc` は、*本文だけ*を持ちます。見た目はテンプレートの側です。

[cols="1,2,2"]
|===
| |docx |officework の `.adoc`

|本文 |同じファイルの中 |このファイル
|スタイル |同じファイルの中 |テンプレート
|用紙・余白 |同じファイルの中 |テンプレート
|直接書式 |同じファイルの中 |*持てません*
|===

「直接書式」は、スタイルを使わずにその場で付けた書式のことです。
1か所だけ太くする、1行だけ下げる、といった指定です。
`.adoc` には居場所がないので、保存すると消えます。

分けた見返りは、*同じ原稿をテンプレートだけ替えて別の体裁で出せる*ことです。
報告書の書式が変わっても、原稿は書き直しません。

== 1つのファイルに詰めていた物を、外に出しました

[cols="1,2"]
|===
|前は文書の中 |いまの置き場

|複数の文書をまとめる |*フォルダ*。ディレクトリがそのままバインダーです
|文書に付けるプログラム |*JupyterLab やエディタ*。同じフォルダに `.ipynb` や `.py` として置きます
|差し込みの雛形の書き方 |*jinja2*。よく知られた書き方をそのまま使います
|ファイルの種類ごとの起動 |*OS の関連付け*。`.adoc` はこのアプリ、他は普段の道具が開きます
|===

officework は、同じフォルダにある他の道具のファイルと並んで働きます。
文書の中に何でも入れる作り方はやめました。

== 用紙の向きは、節ごとに決まります

Word では、1つの文書の中に縦の用紙と横の用紙が混ざりました。
どこで切り替わるかは、開いてみないと分かりません。

officework では*節が単位*です。画面の上に節タブが並び、
どの節がどの用紙かが一目で分かります。
節を足すときに、そのまま続けるか、新しい用紙にするかを選びます。

== シートは、表だけの節です

Excel のシートと、文書の節を*同じ物*にしました。

* 文書の中に、表計算のシートを節として足せます
* シートの並びは、節タブの並びです

「シート」と「文書」を別のアプリで開き分ける必要がありません。

== 原稿の中のシートが持てるのは、4つだけです

文書の中に置いたシートは、次の4つを持ちます。

[cols="1,2"]
|===
|持てる物 |書き方の例

|シート名 |表の題
|セルの値 |`\|4月 \|ボールペン \|12`
|式 |`=売上台帳[@数量]*150`
|セルの結合 |縦は `.2+`、横は `2+`
|===

書式・列幅・図形・ピボットテーブルは持てません。
**持てない物のボタンは、画面にも出しません。**
条件付き書式を作り込んでから「保存できませんでした」と言われるより、
最初から無いほうが良いためです。

量のある表を扱うときは、`.xlsx` で開いてください。そちらは制限が違います。

== 罫線は、場所と線を別々に決めます

Excel は「外枠だけ」「格子」のような*組み合わせの型*を選ぶ作りでした。
officework は2つに分けます。

. *どこに引くか* — 上・下・左・右・内側
. *どんな線か* — 太さ・種類・色

型を覚え直さずに、思ったとおりの罫線が引けます。

== 数式は LaTeX で書きます

docx の数式(OMML)は読みません。
数式は LaTeX の書き方で入れて、TeX か matplotlib で組みます。

論文や技術文書で使われている書き方なので、
書いたものを他の場所へ持ち出せます。

== 開いても、中のプログラムは走りません

docx や xlsx に入っているマクロは*実行しません*。
中身が見えないものを、開いただけで動かさないためです。

officework でプログラムを使うときは、
フォルダの中に `.py` として置きます。開く前に中身を読めます。

== docx・xlsx を開いたときに起きること

**開くと、本文はこのアプリの持ち方に移ります。**
そこから書き戻すので、*元のファイルとそっくり同じには戻りません*。

変更履歴は確定され、段落の外にあるしおりや脚注の印は失われます。
何が読めなかったかは、右クリックの
link:commands/右クリック/この版で読み飛ばしたもの.adoc[この版で読み飛ばしたもの]で見られます。
書き戻したときにどうなるかは link:commands/ファイル/保存.adoc[保存]に一覧があります。

*大事な docx は、写しを取ってから開いてください。*

== 代わりに増えたもの

[cols="1,2"]
|===
|増えたもの |なぜ

|フォルダの一覧(左に出ます) |フォルダがバインダーだからです。従来のオフィスが持たなかった物です
|出す形が4つ(`.adoc` `.docx` HTML PDF) |原稿を書いて、どの形でも出せるようにするためです
|Python からの操作 |画面でできることは、プログラムからも書けます
|===
