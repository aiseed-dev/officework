= docx・xlsx との違い

Word や Excel から来た方へ。**画面はほとんど同じです。変えたのは、保存する形です。**

リボンのタブもボタンの並びも、覚えたとおりに使えます。
戸惑うのは、保存して開き直したときです。
その戸惑いは全部ここに集めました。

== 一番大きい違い — 本文と見た目を分けました

docx は、1つのファイルに本文と見た目を一緒に入れます。
officework の `.adoc` は、*本文だけ*を持ちます。見た目はテンプレートの側です。

[cols="1,2,2"]
|===
| |docx |officework の `.adoc`

|本文 |同じファイルの中 |このファイル
|スタイル |同じファイルの中 |テンプレート
|用紙・余白 |同じファイルの中 |テンプレート
|直接書式 |同じファイルの中 |*持てません*
|===

「直接書式」は、スタイルを使わずにその場で付けた書式のことです。
1か所だけ太くする、1行だけ下げる、といった指定です。
`.adoc` には居場所がないので、保存すると消えます。

分けた見返りは、*同じ原稿をテンプレートだけ替えて別の体裁で出せる*ことです。
報告書の書式が変わっても、原稿は書き直しません。

== 文字で書いて、そのまま文書にできます

docx は、このアプリでしか作れません。中身は圧縮された XML だからです。
`.adoc` は*普通の文字*なので、書く道が増えます。

* どのエディタでも書けます。メモ帳でも構いません
* JupyterLab のノートから書き出せます
* Python で組み立てられます
* git で差分が読めます。どこを直したかが行で分かります

書いたものを officework で開くと、*体裁の付いた文書として出ます*。
下は実際に読める書き方です。

....
= 月次報告

== はじめに

今月の売上をまとめます。*太字*と_斜体_が書けます。

* 箇条書き
* 2つ目

.売上
|===
|品名 |数量 |金額

|ボールペン |12 |1,440
|ノート |5 |750
|===
....

**覚えなくても困りません。** リボンのボタンで作っても、
保存すれば同じ形になります。書きやすいほうを選んでください。

書き方の一覧は link:genkou-manual.ja.adoc[原稿の手引き]にあります。

=== HTML も、そのまま開けます

Web のページを保存したファイル(`.html` `.htm`)を、文書として開けます。
見出し・段落・表・箇条書き・画像を読み取ります。
「ファイル」の「URLを開く」に住所を打てば、その場で取ってきて開きます。

**JavaScript は動かしません。** 見えないものを開いただけで走らせないためです。
記入欄のあるページは、書き込んで送れます。

この版で読まないのは、入れ子の表(外の表のセルの字にまとめます)と、
`src` の無い画像です。

== 1つのファイルに詰めていた物を、外に出しました

[cols="1,2"]
|===
|前は文書の中 |いまの置き場

|複数の文書をまとめる |*フォルダ*。ディレクトリがそのままバインダーです
|文書に付けるプログラム |*JupyterLab やエディタ*。同じフォルダに `.ipynb` や `.py` として置きます
|差し込みの雛形の書き方 |*jinja2*。よく知られた書き方をそのまま使います
|ファイルの種類ごとの起動 |*OS の関連付け*。`.adoc` はこのアプリ、他は普段の道具が開きます
|===

officework は、同じフォルダにある他の道具のファイルと並んで働きます。
文書の中に何でも入れる作り方はやめました。

== 用紙の向きは、節ごとに決まります

Word では、1つの文書の中に縦の用紙と横の用紙が混ざりました。
どこで切り替わるかは、開いてみないと分かりません。

officework では*節が単位*です。画面の上に節タブが並び、
どの節がどの用紙かが一目で分かります。
節を足すときに、そのまま続けるか、新しい用紙にするかを選びます。

**いまはまだ、節タブができていません。** 画面の「余白」「印刷の向き」
「ページのサイズ」は*文書全体*に掛かります。節を足せるのはプログラムからだけです。

[source,python]
----
d.add_section("newPage")      # 新しい紙から始める節
d.add_section("continuous")   # そのまま続ける節
----

画面の「区切り」が入れるのは*ページの区切り*で、節の区切りではありません。
Word の「区切り」には両方入っているので、そこが違います。

== シートは、表だけの節です

Excel のシートと、文書の節を*同じ物*にしました。

* 文書の中に、表計算のシートを節として足せます
* シートの並びは、節タブの並びです

「シート」と「文書」を別のアプリで開き分ける必要がありません。

== 原稿の中のシートが持てるのは、4つだけです

文書の中に置いたシートは、次の4つを持ちます。

[cols="1,2"]
|===
|持てる物 |書き方の例

|シート名 |表の題
|セルの値 |`\|4月 \|ボールペン \|12`
|式 |`=売上台帳[@数量]*150`
|セルの結合 |縦は `.2+`、横は `2+`
|===

書式・列幅・図形・ピボットテーブルは持てません。
**持てない物のボタンは、画面にも出しません。**
条件付き書式を作り込んでから「保存できませんでした」と言われるより、
最初から無いほうが良いためです。

量のある表を扱うときは、`.xlsx` で開いてください。そちらは制限が違います。

== 罫線は、場所と線を別々に決めます

Excel は「外枠だけ」「格子」のような*組み合わせの型*を選ぶ作りでした。
officework は2つに分けます。

. *どこに引くか* — 上・下・左・右・内側
. *どんな線か* — 太さ・種類・色

型を覚え直さずに、思ったとおりの罫線が引けます。

== Web の書き方が、そのまま使えます

Word はウェブとの相性が良くありません。`.adoc` はもともとウェブ向けの
書き方なので、Word に無い表現がそのまま使えます。

[cols="1,2"]
|===
|書き方 |何になるか

|`NOTE:` `TIP:` `IMPORTANT:` `WARNING:` `CAUTION:` |色の付いた註記の箱
|`----` で囲む |コードの塊(等幅・折り返さない)
|`....` で囲む |打った字のまま出す塊
|`====` で囲む |例の箱(枠で囲みます)
|`****` で囲む |傍注の箱(本文の脇に置く話)
|`--` で囲む |入れ物。中に段落をいくつでも置けます
|`++++` で囲む |HTML をそのまま通します
|`項目:: 説明` |用語の一覧
|`* [ ]` `* [x]` |作業のリスト(チェックボックスが出ます)
|`**` `***` / `..` `...` |段を深くしたリスト(入れ子になります)
|3つの `'` だけの行 |横の区切り線
|===

註記は種類ごとに色が変わります。警告は橙、注意は赤、こつは緑です。

リストは `*` の数で段が決まります。`**` なら2段目、`***` なら3段目です。
番号付きは `.` の数で同じように決まります。
`* [ ] やること` と書くと、チェックボックスの付いた作業のリストになります。
済んだものは `* [x]` です。

`++++` の中には HTML を直に書けます。折りたためる箱もこれで作れます。

....
++++
<details><summary>押すと開きます</summary>中身です。</details>
++++
....

**CSS が無くても、そのまま見られます。** 書き出した HTML は、色も枠も
等幅も*要素そのものが持っています*。本文だけを他所のページに貼っても
崩れません。まとめて変えたい人は、`class` が付いているので
スタイルシートで上書きできます。

Word で同じことをすると、スタイルを1つずつ作って掛けることになります。

== 操作を絞ったところ

同じ名前のボタンでも、*できることを絞った*ものがあります。
迷ったときのためにここに並べます。

[cols="1,2,2"]
|===
|ボタン |Word / Excel |officework

|段落の行間 |最小値・固定値・倍数から選び、数を打つ。段落の前後の空きも決める |*倍数の3択*(1.0 → 1.5 → 2.0)を押すたびに回す
|箇条書き・ナンバリング |印の形を一覧から選ぶ |*段の深さで決まります*(`・`→`○`→`■`、`1.`→`(1)`→`1)`)。Tab で深く、Shift+Tab で浅く
|罫線 |組み合わせの型を選ぶ |*どこに引くか*と*どんな線か*を別々に決める
|===

絞ったのは、`.adoc` に持てる形に合わせたためです。
持てないものを画面で作れると、保存したときに消えます。

細かく決めたいときは、プログラムから書いてください。

== 数式は LaTeX で書きます

docx の数式(OMML)は読みません。
数式は LaTeX の書き方で入れて、TeX か matplotlib で組みます。

論文や技術文書で使われている書き方なので、
書いたものを他の場所へ持ち出せます。

== 開いても、中のプログラムは走りません

docx や xlsx に入っているマクロは*実行しません*。
中身が見えないものを、開いただけで動かさないためです。

officework でプログラムを使うときは、
フォルダの中に `.py` として置きます。開く前に中身を読めます。

== docx・xlsx を開いたときに起きること

**開くと、本文はこのアプリの持ち方に移ります。**
そこから書き戻すので、*元のファイルとそっくり同じには戻りません*。

変更履歴は確定され、段落の外にあるしおりや脚注の印は失われます。
何が読めなかったかは、右クリックの
link:commands/右クリック/この版で読み飛ばしたもの.adoc[この版で読み飛ばしたもの]で見られます。
書き戻したときにどうなるかは link:commands/ファイル/保存.adoc[保存]に一覧があります。

*大事な docx は、写しを取ってから開いてください。*

|フォルダの一覧(左に出ます) |フォルダがバインダーだからです。従来のオフィスが持たなかった物です
|出す形が4つ(`.adoc` `.docx` HTML PDF) |原稿を書いて、どの形でも出せるようにするためです
|読める形が4つ(`.adoc` `.docx` `.html` 文字だけのファイル) |Web のページも住所を打てば開けます

|文字で書く道 |ファイルが普通の文字なので、エディタでも Python でも書けます
|===
