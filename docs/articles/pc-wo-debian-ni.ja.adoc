= 古い Windows PC を Debian にして、様式の仕事をそちらでやる

////
配布用の 1 枚(普通の人の会で配る)。*マニュアルではない。*
* 2026-09-20 時点の書き物。発注者(yniji)の一人称で書いてある
* Debian の手順は Mac では通せないので、配る前に Debian を入れた PC で 1 度通す
  (Releases の .deb が Debian 13 の Xfce で入ることと、GNOME Boxes で Windows 11 が
  動くことも、その時に確かめる)
* 貼り付けるときはこの注記ごと消してよい
////

Windows の PC を Debian にすると、Python、git、apt が最初からそろいます。
Copilot に誘われることも、更新で勝手に再起動されることもありません。
Windows でしか動く物(会計ソフトなど)は、Debian の中の仮想環境で Windows を
動かして、そこで使います。PC は 1 台のままです。

WSL の逆です。WSL は Windows の中に Linux を入れますが、こちらは Debian の
中に Windows を入れます。土台は Debian で、Windows は客です。データと
コードは土台の側にあり、更新や再起動は Windows の都合で来なくなります。
仮想環境の Windows は写し(スナップショット)を取れるので、何かを入れる前に
戻せます。メールで届いたファイルのマクロが動いても、箱の中で止まります。

今までこれをしなかった理由は 1 つでした。Word と Excel のファイルが、
同じに開かないことです。officework がそこを埋めます。役所の様式や
取引先の帳票を、Word と同じ頁数、同じ折れ方、同じ列幅で開いて、刷ります。

== 誰に向くか

* 自分の PC を持っている人(個人事業主、小さな会社)。会社が管理している
  PC はできません
* メモリが 8GB 以上、ディスクが 128GB 以上の PC。仮想環境の Windows に
  4GB と 64GB を渡すためです。メモリが 16GB あれば楽です
* 古い PC が 1 台余っている人は、まずそちらで試すと安心です

== 0. 先にすること

* 残したいファイル(書類、写真)を USB か外付けのディスクに写します。
  Debian を入れると、その PC の中身は消えます
* Wi-Fi のパスワードを控えます
* Windows のプロダクトキーを控えます。ターミナルで次を打つと出ます(出ない
  PC もあります。その場合は仮想環境の Windows は認証なしで使います。壁紙の
  右下に印が出るだけで、動きます)
+
[source,console]
----
wmic path softwarelicensingservice get OA3xOriginalProductKey
----
* 8GB 以上の USB メモリを 1 本用意します。中身は消えます

== 1. Debian の USB を作る(15 分)

. https://www.debian.org/ の「ダウンロード」から、`debian-13.x.x-amd64-netinst.iso`
  を落とします
. Windows で https://rufus.ie/ の Rufus を落として開き、USB メモリと上の
  iso を選んで「スタート」を押します。聞かれたら「ISO イメージモード」の
  ままで進めます

== 2. USB から起動して入れる(30 分)

. USB を挿したまま PC を再起動し、起動のメニューを出します(メーカーに
  よって F12、F2、Esc、Delete のどれかを起動直後に押します)。USB を
  選びます
. 「Graphical install」を選びます。言語は日本語、場所は日本、キーボードは
  日本語です
. 名前とパスワードを決めます。パスワードは後で `sudo` のたびに使います
. ディスクは「ガイド - ディスク全体を使う」を選びます。この PC の中身は
  ここで消えます
. ソフトウェアの選択は「Debian デスクトップ環境」と「Xfce」に印を付けます
  (「GNOME」の印は外します)。Xfce は画面の作りが Windows と同じ形で、
  軽く、何年も変わりません。仮想環境の Windows にメモリを渡すので、外は
  軽い方がよいです
. 終わったら USB を抜いて再起動します。ログインすると、下にパネル、左に
  メニューの、Windows と同じ形の画面が出ます

== 3. 最初に入れる物(5 分)

「端末」を開いて打ちます。

[source,console]
----
sudo apt update
sudo apt install fonts-noto-cjk python3-pip python3-venv git
----

`fonts-noto-cjk` は日本語の書体です。これが無いと字が □ になります。

== 4. officework を入れる(5 分)

https://github.com/aiseed-dev/officework/releases から
`officework_..._amd64.deb` を落として、端末で打ちます(ファイル名は
落とした物に合わせます)。

[source,console]
----
cd ~/ダウンロード
sudo apt install ./officework_0.1.0-alpha.3_amd64.deb
----

アプリの一覧に officework が出ます。端末からも開けます。

[source,console]
----
officework 見積書.xlsx
----

Word と Excel のファイルが、タブで開きます。刷るときは Ctrl+P で PDF に
なります。

== 5. Python から様式を触る(5 分)

[source,console]
----
python3 -m venv ~/venv
~/venv/bin/pip install officework
~/venv/bin/python
----

`>>>` が出たら、Windows の 1 枚と同じことを打ちます。

[source,python]
----
from officework import sheet
b = sheet.Book.open("/home/自分の名前/見積書.xlsx")
b.recalc()
b.to_pdf()
----

== 6. プリンター

Debian は最初から印刷の仕組み(CUPS)を持っています。「設定」の
「プリンター」で、同じネットワークにあるプリンターは自動で出ます。
ここ数年のプリンターはドライバー無しで刷れます。

== 7. Windows は仮想環境で(30 分)

会計ソフトのように Windows でしか動く物は、Debian の中で Windows を
動かして使います。GNOME Boxes を使います。

. https://www.microsoft.com/software-download/windows11 から
  「Windows 11 ディスク イメージ (ISO)」を落とします
. 端末で `sudo apt install gnome-boxes` と打ちます。アプリの一覧に
  「Boxes」が出ます
. Boxes で「+」→「仮想マシンを新規作成」→ 落とした ISO を選びます。
  メモリは 4GB 以上、ディスクは 64GB 以上にします
. Windows の入れ方は普通の PC と同じです。プロダクトキーは、控えた物を
  入れるか、「プロダクト キーがありません」で進めます
. 入ったら、Windows の中に会計ソフトなどを入れます。USB の機器(認証の
  キーなど)は、Boxes の「デバイスと共有」で Windows に渡せます

Boxes の窓の中で Windows が動き、外は Debian のままです。様式の仕事は
外の officework と Python でやり、Windows でしか動く物だけを中でやります。

前提が 1 つあります。PC の設定(BIOS / UEFI)で「Virtualization」か
「VT-x」「SVM」が有効になっていることです。無効だと Boxes が遅いか
動きません。ここ 10 年の PC は有効になっている物がほとんどです。

== 困ったら

* *字が □ になる:* `sudo apt install fonts-noto-cjk` を打ち直します
* *officework の窓が開かない:* `sudo apt-get -f install` で足りない物が
  入ります
* *様式が Word と違って見える:* その様式(中身を空にした物)を GitHub の
  Issues に付けてください。直します
  https://github.com/aiseed-dev/officework/issues
