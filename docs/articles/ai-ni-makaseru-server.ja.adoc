AI に仕事をさせるサーバーを、こう作ります。会社の PC を 1 台、Debian に
して使います。

== 1 台で全部やります

公開の Web サイト、社内の道具(認証、メール、会議、予約、コードの置き場)、
AI の作業を、同じ 1 台に載せます。

画面(GNOME)も入れて、動かしたままにします。AI が Word を開いて答えを
取る、ブラウザで頁を見る、仮想環境の Windows を使う、が同じ機械でできる
ためです。人が見るときは、手元の PC からその画面に繋ぎます。

== AI にはルートの権限を渡します

サーバーの設定(入れる、設定する、動かす、直す)は、全部 AI がやります。
命令とファイルの仕事で、動いたかどうかが確かめられるので、AI の得意な
所です。

権限を渡して構わない理由は、壊れても初期化から始めればよいからです。
PC なら、それで戻ります。

== 初期化で戻らない物だけ、人が持ちます

* 鍵と認証。ドメインの登録、お金に関わる物の認証は、この機械に置きません。
* 外でやった操作。DNS を替える、メールを送る、外のサービスのデータを消す、
  の類は、AI が「やる前に言う」形にして、人が通します。
* 書類そのもの。機械の外にも写しを置きます。

== 公開の側と AI の側は分けます

* 外に開ける入り口は 80 と 443(と ssh)だけです。画面への接続は外に
  開けず、手元の PC から ssh の中を通します。
* 公開の Web と、AI の作業は、別の利用者で動かします。公開の側に穴が
  出ても、AI の側の書類と鍵に届かないようにするためです。

== 要る物

* PC が 1 台(メモリ 8GB 以上、ディスク 128GB 以上)
* インターネットの回線
* AI の利用料(月 100 ドルほど)

これだけです。稟議も、サーバーの契約も、人数分のライセンスも要りません。
