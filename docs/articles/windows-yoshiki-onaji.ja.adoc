会社の書類は Word と Excel のファイルです。この 1 枚は、そのファイルを
aiseed office で開いて、Word や Excel と同じに見えるか、同じに刷れるかを
見る所までです。15 分で、Python も端末も使いません。Word と Excel は
そのまま残ります。

== 1. 入れる(5 分)

. https://github.com/aiseed-dev/officework/releases を開き、
  `officework-...-windows-x86_64-setup.exe` を落とします
. 落ちたファイルを開きます。管理者の権限は要りません
. 「Windows によって PC が保護されました」と出ます。まだ署名を付けていない
  ためです。**「詳細情報」→「実行」** で進めます

スタートメニューに aiseed office が入ります。

== 2. 自分の様式を開く(3 分)

aiseed office を開き、ファイル > 開く で、自分の xlsx か docx を選びます。
表と文書は同じ窓のタブで開きます。

== 3. 刷る(2 分)

ファイル > 印刷(または Ctrl+P)で、PDF ができます。紙に出したいときは、
その PDF を開いて刷ります。

== 4. Word・Excel と並べて見る(5 分)

同じファイルを Word か Excel でも開いて、印刷プレビューを出します。
aiseed office の画面か PDF と並べて、3 つを見ます。

* 頁数が同じか
* 行の折れる所が同じか
* 表の列の幅が同じか

同じなら、この様式は aiseed office で扱えます。違って見える所があれば、
それが私たちの直す所です。

== 5. 違って見えたら

その様式を、中身を空にするか書き換えた物にして、GitHub の Issues に
付けてください。原因を調べて直します。

https://github.com/aiseed-dev/officework/issues

個人情報や社外秘の入った物は、そのまま送らないでください。
