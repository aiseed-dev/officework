= ダイアログのパラメータの台帳 — コマンドの手引きに書くための調べ
:toc:

発注者「ダイアログが出る場合は、パラメータがありますね。それを調べてください。
euro-office であればわかるでしょう」(2026-08-25)。

コマンドの手引き(docs/commands)の「ダイアログ」の節に書く中身を、
コマンドごとに調べた台帳です。

* **うちの列は、コードの選択肢の表から写した実物**です(calc/src/picks.rs・
  io.rs・writer/src の各腕。推測はありません)
* **Euro-Office の列は物差し**です。同じダイアログが向こうで何をパラメータに
  しているかを並べ、うちに無い物は「うちには無い」とはっきり分かるようにします。
  うちは MS Office と同じではないので、**違いは頁に書くのが正**です

手引きへの書き方: パラメータは「欄の名前 → 選べる値(全部)→ 既定」。
選べる値が実物の画面と食い違ったらこの台帳が間違っているので、直してから頁を直す。

== calc(表計算)

[cols="1,3,2,2"]
|===
|コマンド |うちのパラメータ(実物) |Euro-Office の同じ小窓 |頁に書くときの要点

|CSV の形(csv-kind)
|形式の6択: UTF-8(BOM付き)・カンマ / Shift_JIS(CP932)・カンマ / UTF-8(BOMなし)・カンマ / UTF-8(BOM付き)・タブ / Shift_JIS(CP932)・タブ / UTF-8(BOM付き)・セミコロン。既定: UTF-8(BOM付き)・カンマ
|読み込み時に文字コード・言語・区切り(タブ/カンマ/セミコロン/スペース/その他)・文字列の引用符・列の型を選ぶ
|うちは読み書き共通の6組から選ぶ形で、列の型の指定は無い。**既定が UTF-8 なことは Excel と違うので書く**

|大文字小文字(changecase)
|5択: 文の先頭だけ大文字 / すべて小文字 / すべて大文字 / 単語の先頭を大文字 / 大文字と小文字を入れ替え
|書式 > 文字種の変換(同等の5種)
|**表のセルで押したときだけ5択**。文書の本文では入れ替えの1動作(下の writer の欄)。罫線と同じ「どこで押すか」の型で書く

|重複の削除(dedup)
|比べる列(チェック・既定は全部)/ 先頭行は見出し(チェック・既定 OFF)
|Excel の「重複の削除」と同じ2欄(E-O 純正には専用が無く、標準フィルタの「重複なし」で代用する)
|Excel と同じ形。手引きの Python 断片が空のままなので埋める

|小計(subtotal)
|グループ化する列(見出しから)/ 集計する列(複数可)/ 集計方法: 合計・平均・個数・最大・最小 など
|グループの基準 / 集計する列 / 使う関数(E-O は3グループまで)
|うちは1グループ。多段の小計は無い、と書く

|区切り位置(data-split)
|区切り文字の入力(複数文字可)
|3段のウィザード: 区切りか固定長か → 区切り文字・引用符 → 列ごとの型
|**うちは1欄だけ**。固定長と列の型指定は無い、と書く

|条件付き書式(condformat)
|ルールの一覧から選ぶ: 0未満を赤字 / 重複 / 一意 / 平均より上 / 平均より下 / データバー / 色の濃淡 / アイコン など
|条件(セルの値が/数式が/日付が)+適用するスタイルを自分で組む
|うちは**出来合いのルールから選ぶ**形。条件と書式を自由に組む画面は無い、と書く

|並べ替え(sort)
|基準の1欄: 見出しを左から強い順に書く(例: 金額 降順, 品名)
|キー1〜3(列・昇順/降順)+オプション(見出しの有無・大文字小文字)
|うちは**字で書く**形(キーの数に上限なし)。書き方の例を頁に

|データの入力規則(dv)
|3タブ: 許可(全て/整数/小数/日付/時刻/テキストの長さ/リスト)/ 条件(等しい・より大きい など)/ 入力時メッセージ
|同じ3構成+エラー時の動き(停止/警告/情報)
|**エラー時の動きの選択は無い**(入らない値は入らない)、と書く

|関数の挿入(insert-function)
|分類 → 関数 → 引数の欄
|同じ3段
|同じ形。Excel の関数名がそのまま使えることを書く

|ウィンドウ枠の固定(freeze)
|5択: 固定の解除 / いまの位置で固定 / 最上行 / 最初の列 / 固定した枠に影
|同じ(影の項は無い)
|「影」はうち独自の見せ方なので一言添える

|セルを結合(merge)
|4択: 結合して中央に配置 / 横方向に結合(行ごと)/ セルの結合(揃えは触らない)/ 結合の解除
|同じ4種
|Excel と同じ並び。そのまま書く

|シート見出しの色(tab-color)
|シートを選ぶ → 色のパレット
|色のパレット1段
|同じ。パレットの色数だけ書く

|表のスタイル(table-tpl)
|スタイルの一覧(青・緑・灰 など)。選ぶと表になる(Ctrl+Z で戻せる)
|表に変換+スタイルのギャラリー
|「選ぶと表になる」= 変換まで1手なことを書く

|文字の向き(orient)
|6択: 角度なし / 左上がり45度 / 右下がり45度 / 上向き90度 / 下向き90度 / 縦書き(1字ずつ積む)
|同等の型+任意の角度
|**任意の角度は無い**、と書く

|紙に収める(fit-pages)
|5択: 拡大縮小しない / すべての列を1ページ / すべての行を1ページ / シートを1ページ / 横2×縦1
|拡大率(%)か「幅×高さのページ数」を数で
|うちは**よく使う型の5択**で、任意の%は無い、と書く

|改ページ(pagebreak)
|挿入・解除(行/列で変わる)+すべての改ページを外す
|同じ
|そのまま

|再表示(unhide)
|隠れているシートの一覧
|同じ
|そのまま

|復旧(recover)
|控えの一覧+「壊れたまま拾って開く(読み取り専用)」
|E-O は起動時の復旧ダイアログ
|拾って開くと**保存で元を上書きしない**ことを書く(決め済み)

|許可する操作(prot-allow)
|チェックの一覧: セルの書式 / 列・行の書式 / 列・行の挿入 / 削除 / ハイパーリンク / 並べ替え / オートフィルター / ピボット
|Excel のシート保護と同じ一覧
|そのまま

|シナリオ(scenario)
|一覧+「新しいシナリオ…」
|名前・コメント・設定の小窓
|うちの新規の聞き方を実機で確かめて書く

|ソルバー(solver)
|目標セル / 目標値 / 変わるセル / 制約条件(複数行)
|同じ4欄+解法の選択
|**解法の選択は無い**(1本の決め)、と書く

|ピボットテーブル(pivot-insert)
|おすすめの形 → または4段の選択: 行 → 列(任意)→ 値 → 集計方法(合計・平均・個数・最大・最小)
|フィールドを4つの箱(フィルター/列/行/値)へドラッグ
|うちは**順に聞く4段**で、ドラッグの箱は無い。おすすめから入れることを先に書く

|スパークライン(inssparkline)
|3択: 折れ線(既定)/ 縦棒 / 勝ち負け
|同じ3種
|そのまま

|スライサー(insslicer)
|列のチェック一覧(開いている列に ☑)
|同等
|そのまま

|名前の定義(name-scope)
|適用範囲の2択: このシートだけ / ブック全体
|同じ2種
|そのまま

|数式で使用(paste-name)
|定義済みの名前と表の一覧
|同じ
|そのまま

|記号と特殊文字(inssymbol)
|分類(最近使った/組の一覧)→ 字の升。**Unicode を打つ道**(例: 3012 → 〒)
|フォント / 部分集合 / 文字コード
|**フォントの選択は無い**。Unicode の道は書く価値がある

|通貨(currency)
|通貨の一覧(並びは画面の言語に従う)→ 記号
|表示形式の小窓の中
|そのまま

|日付の形(datefmt)
|形の一覧(選ぶとその形でファイルに残る)
|表示形式の小窓の中
|「ファイルに残る」= 書式コードが入ることを書く
|===

== writer(文書)

[cols="1,3,2,2"]
|===
|コマンド |うちのパラメータ(実物) |Euro-Office / Word の同じ小窓 |頁に書くときの要点

|ルビ(ruby)
|読みの1欄(既定: いまのルビ。空にすると外れる)
|Word: 対象文字列・ルビ・配置・オフセット・サイズ。E-O: ルビ文字・配置・位置
|うちは**読みだけ**。配置や大きさの指定は無い、と書く。空で外れる道は書く価値がある

|大文字小文字(changecase)
|1動作(大小の入れ替え。1手で戻せる)。**5択は表のセル側だけ**
|Word は5択
|「どこで押すか」の型で、表側の頁と同じ1枚に書き分ける

|表の挿入(instable)
|**3×3 を末尾に挿入(選ぶ物なし)**
|升で行×列を選ぶ/数を入れる
|**行×列は選べない**(挿してから足す)、と正直に書く

|方程式を挿入(insequation)
|LaTeX の1欄(例: \frac{a+b}{2})
|Word: 数式エディタ(OMML)。E-O: StarMath
|**LaTeX で受ける**こと・Word の数式(OMML)は読み飛ばして unsupported に出ることを書く。※ラベルの「方程式」は Word 公式では「数式」— 名前の直しは別件

|ページ番号 / ページ数(pagenum / numpages)
|選ぶ物なし(ヘッダー/フッターに印を挿す。無ければフッターを自動で開く)
|Word: 位置・配置・書式の選択
|**位置はカーソルで決める**(選択肢は無い)、と書く

|日付と時刻(datetime)
|選ぶ物なし(今日の日付を YYYY年M月D日 の固定の字で挿す)
|Word: 形式の一覧+自動更新のチェック
|**形式の一覧と自動更新は無い**(固定の字)、と書く。自動更新が要る様式は雛形の差し込みで、と誘導

|記入欄(form-text ほか7種)
|選ぶ物なし(種類ごとのボタンで挿す)
|Word: コンテンツコントロール+プロパティ小窓
|種類の一覧はフォームの段の並びが正。名前は form-name で付ける(fill の鍵)

|コンボ / ドロップダウン(form-combo / form-dropdown)
|選択肢の1欄(カンマ区切り。例: 赤,青,黄)。欄の中に居るときは選び直し
|Word: プロパティで項目を1つずつ追加
|**カンマ区切りで一度に**書けることを書く

|記入欄の名前(form-name)
|名前の1欄(既定: 種類の既定名)
|Word: プロパティのタグ欄
|マクロの fill(名前, 値) の鍵になることを書く(w:tag に入る)

|書体(fontname)
|一覧+絞り込みの欄(日本語・正体のみ)
|一覧(全書体)
|**飾り書体は出さない**決めなら、その旨を書く

|文字サイズ(fontsize)
|6〜72 の17段+**文書の標準**(既定 10.5pt)
|同等の段+自由入力
|**自由入力は無い**、と書く。文書の標準が先頭に出ることを書く

|段落のスタイル(parastyle)
|6択: 標準 / 見出し1〜5
|スタイルのギャラリー(多数)
|**6つだけ**(意味の単位)なことを書く — 増やさない決めと繋がる

|検索と置換(replace)
|検索 / 置換後 / 範囲(この文書=既定 / このフォルダ)+ 次へ・置換・すべて置換
|+大文字小文字・完全一致・正規表現
|**正規表現などの条件は無い**、と書く。フォルダ横断は独自なので書く価値がある

|しおり(bookmark)
|名前の1欄+一覧(選ぶ・削除)
|Word: ブックマーク小窓(同等)
|そのまま

|透かし(watermark)
|文字の1欄(空にして閉じると外れる)
|Word: 文字・フォント・サイズ・色・向き
|**文字だけ**(飾りの選択は無い)、と書く

|コメント(co-addcomment)
|本文の1欄(空にすると外れる)
|同等
|そのまま

|バージョン履歴(co-history)
|一覧(最大9世代・押すと複製で開く)
|E-O: バージョンの保存・比較
|**複製で開く**(その場で戻さない)ことを書く

|用紙・余白・向き(pagesize / pagemargins / pageorient)
|選ぶ物なし(A4→B5→A3 / 20→12→30mm / 縦↔横 で回す)
|ページ設定の小窓(数で指定)
|**回して選ぶ**形なことと、細かい数はテンプレートで、と書く
|===

== この台帳から出た、手引き以外の直し(候補)

. **大文字小文字・罫線のように「どこで押すかで変わる」物**は、両方の動きを1枚に書き分ける(罫線の頁の型をそのまま使う)
. ラベル「方程式を挿入」は Word 公式の「数式」に直す候補(リボンと頁の名前の両方。訳の出どころの規則)
. 手引きの Python 断片が空: データ/重複の削除(dedup のパラメータをそのまま書ける)
. 実機と食い違っていないかは、頁を書いた後に隔離画面(:7)で1つずつ開いて見るのが確実(この台帳はコードから写したが、画面の文言の細部までは見ていない)
