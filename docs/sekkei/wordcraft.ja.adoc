= wordcraft との比較(2026-10-16)

発注者が見つけた wordcraft(https://github.com/storytold/wordcraft)を調べ、受け入れ試験の
docx 5 枚で、officework・ibis-office と並べて Word の PDF と比べました。

== wordcraft とは

* ArtCraft という画家・デザイナーの集まりが作っています。Photoshop や InDesign などの代わりも
  同じ形で作る「Crafting Apps」の 1 つで、Word だけを受け持ちます。表計算はありません。
* Rust で書き、画面は egui です。MIT か Apache-2.0 のライセンスです。
* 2026-10-07 に作られ、1 週間でスターが約 1 万 3 千、フォークが約 3,300 になりました。
  比べた版は 0.7.0(2026-10-14)の Linux 用 Flatpak です。
* docx の読み書きのほか、odt・rtf・html・md・tex を扱います。古い .doc は読むだけです。
* AI エージェントが進める前提で作られています(AGENTS.md)。何でも命令(422 個)として作り、
  リボン・キー・コマンドライン・MCP が同じ命令を使います。Word は動かして外から見るだけに
  しています(クリーンルーム)。
* 本人たちの「足りない所」の 1 番目は、実際の docx を Word と 1 ページずつ比べたことが無い
  ことです。ページの区切りが Word と違うことも書いています。
* 日本語は、ルビ・縦書き・文書のグリッド・禁則の機能があります。深さは測っていないと書いて
  います。書体の置き替えの表に、日本語の書体はありません。

== 同じ docx での比較

Word(16.0.20430)の PDF と比べました。wordcraft と officework は Debian で、置き替えの
書体を使っています。ibis は Windows の仮想マシンで、Windows の書体を使っています。

[cols="2,3,3,3"]
|===
|比べ方 |officework |ibis |wordcraft

|字の位置 6pt を超えた行 |0 |6 |29
|字の位置 2pt を超えた行 |17 |19 |46
|字の位置 1pt を超えた行 |19 |51 |48
|絵の違う区画(ΔE 12) |71 |52 |219
|===

* wordcraft は、議事録の表(幅 0 の列)を狭くし、字が 1〜2 字ずつ折れました。officework が
  2026-10-12 に直した違いと同じ種類です。
* 絵の比べ方では ibis がいちばん少なくなりました。ibis は Windows の本物の書体で描くので、
  字の形が Word と同じになるためです。

== officework に残っている違い(この比較で見つけた物)

* 開催通知の、`<w:b/>` が付いた BIZ UDP明朝 Medium の字を、Word は太字にしていません。
  officework と wordcraft は太字にし、ibis は太字にしていません。ECMA-376 の 17.3.2.1 では
  `b` は太字の意味なので、規約どおりなのは officework です。どちらに合わせるかは決めて
  いません。
* 議事録の箇条書きで、記号の後の空きが Word より狭い所があります。
