== 決め

. 新規の Doc(エンジンの `Doc()` と writer の新規の両方)は、この形の
  ひな型を持つ: 33 スタイル相当+docDefaults 10.5pt+テーマ+A4
- 余白だけは教師と違えて **20mm**(writer の決め済みの既定)
. **言語が日本語のときは、テーマの書体を BIZ UD 系にする**
  (発注者 2026-08-26)。本文(minor)= BIZ UDPゴシック、
  見出し(major)も BIZ UD 系。他の言語のときは
  `kumihan::font::set_default_language` の既定に従う —
  「標準フォントは OS と言語で変える」(ui/src/lib.rs の決め)と1本の道
. docProps に個人名を入れない(教師のファイルには作成者名が入っている —
  写さない)
. スタイルは 33 で閉じる。python-docx の 164 は真似ない(増やさない決め)
