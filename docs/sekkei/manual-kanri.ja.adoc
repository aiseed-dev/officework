== 管理の対象

当面、管理するのは**利用者向けの冊子の日本語と英語の対**だけです
(2026-08-26 発注者。三帳簿の見取り図は取り下げた)。
英語版が正本(primary)、日本語版が副。

英語版がまだ無い冊子と作る順:
docx-xlsx-tono-chigai → api-taiou → commands/(169枚。Opus の流し込みが
済んでから)。

設計(SEKKEI・sekkei/)と在庫の台帳(guide-tsukiawase-2)は作る側の資料で、
この管理の外です。docs/ に残っている corpus・engine・pysheet-gokan・
mac-signing も作る側の物ですが、**場所は動かしません** — PyPI の README など
公開済みのリンクが刺さっているためです。

articles/ は公開用の書き物で、この規則は掛かりません(その時点の事実と
見立てを残す物。挙動が変わっても遡って直さない。発注者の一人称で書く)。
