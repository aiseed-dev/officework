== 蒸留の作法

openpyxl のときと同じです。

* 写すのは、記法の意味と試験です。
* Ruby の実装は写しません。asciidoctor を実行時に同梱することもしません。
* 本家は「読む半分」と「出す半分」に分かれています。うちが写すのは読む半分だけです。HTML や DocBook の出し方は写しません。

本家の試験は HTML の文字列で答えを確かめます。
うちは run の並びで確かめます。
たとえば本家のこの試験は、

----
入力:  *a few strong words*
本家:  <strong>a few strong words</strong>
----

うちではこう読み替えます。

----
runs: [ bold "a few strong words" ]
書き戻し: *a few strong words*(入力と同じ字)
----

書き戻しの行は本家に無い確認です。
本家は adoc を読んで出すだけの一方通行ですが、writer は視覚エディタなので、読んだものを adoc に書き戻して字を変えないことが要ります。
写す試験には全部、この書き戻しの確認を足します。

== 本家の約束: 開きと閉じの位置

往復で字が変わる 78 枚の原因は、うちの読み手が `*` と `_` を見つけるたびに強調を入り切りしていることでした。
本家の約束は `lib/asciidoctor.rb` の `QUOTE_SUBS` にあります。
普通の言葉にすると次のとおりです。

一重の印(`*字*` `_字_` `` `字` `` `#字#`)は条件つきです。

* 開きの印の直前は、行の頭か、文字でない字です。`;` `:` `}` も直前には来られません。等幅だけは `"` `'` `` ` `` も直前に来られません
* 中身は空白で始まらず、空白で終わりません
* 閉じの印の直後は文字ではありません。等幅だけは `"` `'` `` ` `` も直後に来られません
* 「文字」は Unicode の word 文字です。日本語の字も文字です

二重の印(`**字**` `__字__` ```` ``字`` ```` `##字##`)は条件がありません。
どこにあっても、次の同じ二重の印までを囲みます。

上付き `^字^` と下付き `~字~` は空白をまたげません。

`\` を印の前に置くと、その印は字になります。

探す順も決まっています。
二重の太字、一重の太字、二重の等幅、一重の等幅、二重の斜体、一重の斜体、二重のマーク、一重のマーク、上付き、下付きの順です。
先に見つかった方が勝ちます。

役割は `[.名前]#字#` の形のほか、`[.名前]*字*` のように他の印にも付きます。
うちの `style_id` に載せます。

== うちの読み手がいま外していること

`engine/src/adoc.rs` の `parse_inline_cont` を本家の約束と比べました。

* 一重の `*` `_` を、直前と直後を見ずに入り切りしている。`README-de_DE` の `_` が斜体の開きになる
* `**` を「`*` が2回」として読み、入り切りが2回になって消える
* `#字#`(マーク)を読んでいない。`CharFormat::highlight` に載せられる
* `"`字`"` `'`字`'`(曲がった引用符の印)を読まず、中の `` ` `` を等幅の開きと取る
* `+++字+++` `++字++` `pass:[字]` を読まない。中の `*` が太字になる
* `\*` の逃がしは読めるが、`\**` の二重の逃がしは1字しか逃がさない
* mailto と裸のメールアドレスを読まない(字として残るので往復は壊れない)

書く側(`should_double` と `esc`)は本家の約束をすでに部分的に入れています。
読む側がそれに追いつけば、往復が閉じます。

=== 表の原文と、行の切り方(2026-09-03 後半)

本家の 176 枚で残っていた違いの多くは、**行の切り方**でした。本家の HTML は
段落の中の改行をそのまま持つので、行の切り方が変わると HTML の字も変わります。

* 表の原文: `|===` の中身を丸ごと控えに持ち、セルが1つも直されていない間は
  そのまま返す。1行に1セルずつ書いた表や、行の間の空行は模型に無いので、
  原文でしか返せない(1行目が複数行にまたがる表では、1行にまとめると見出しの
  行が生えてしまう)。控えの置き場は1つ目のセルの1つ目の段落の `raw_adoc`
  (セルの控えの前に付ける)。`Table` に欄を足すのが本来の形だが、doc.rs は
  別の作業が触っている途中なので、後の回に移す。照合の字は全セルの字と
  結合と見出しの有無
* 註記(`NOTE: 文`)にも続きの行を継ぐ(本家は空行まで1つの註記)。書くときは
  本文と同じく文の切れ目で行を分ける
* ラベル付きリストの説明と箇条書きの項目も、文の切れ目で行を分ける。読む側は
  続きの行を項目に継ぐので、往復で崩れない
* `:accept::` はラベル付きリストの項目で、属性の項目ではない(属性の値は空か
  空白で始まる)。頭の判定・本文の判定・項目の直後の判定の3か所を1つの
  `is_attr_entry` にまとめた
* 文の切れ目は `. ` の後ろが大文字のときに加えて `(` のときも

表は 92 → 98(残りは読めない CSV/DSV の 7 件だけ)。本家の 176 枚は同じ HTML が

`//= 題` のコメント、行の中の属性の参照とリンクの継ぎ目、`[.output]` の並びなど。
