= 移行: プログラム内を英語にする — Opus への作業指示

規約(2026-08-26 発注者「プログラム内はすべて英語。他国語はリソース
ファイルへ」「移行は一気にやっておかないと」「変な言葉が多すぎ」)の
実施です。段ごとに全試験を緑にしてコミットしてください。
**この移行中、他のセッションを並走させないこと。**

== 全量(測ってある)

* t! / tf! / item! の呼び出し: 2,616 か所(全部 en の表に載っている — 取りこぼし 0)
* 文言: 2,085 句 → 統合 16 組で **en 鍵 2,069**
* 日本語の識別子の宣言: 2,311(rs)+ 42(tools の py)
* 日本語の文字列を突き合わせる assert: 2,227

== 用意してある機械

* `tools/flip_i18n.py` — 鍵の裏返し。乾式が既定、`--go` で書き込み。
  対の読み取り・鍵の一意の検算・コードの書き替えまで実装済み
* `tools/flip_en_fixes.tsv` — 衝突 28 組の解消表(文脈は実地調査済み)。
  統合 16 組(3列目が正の日本語 — Excel の公式用語側に寄せてある:
  作成者・キャンセル・表示形式を標準に戻しました・左右反転 など)と、
  英語を分けた組(取り消し線=Strikethrough / 数式=Formula /
  方程式=Equation / 文字列操作=Text functions など)

== 段1: 鍵の裏返し

. **訳の番号の付け替え。** ui/i18n/<loc>.json は番号(i)で訳を持つ。
  統合 16 組で鍵が減るぶん、keys.json の番号がずれる — 旧番号 → 新番号の
  表を作り、13 言語の json の i を機械で付け替える(訳の字は触らない)
. **ja.json を新設。** en 鍵 2,069 → 正の日本語(flip_i18n.py の
  mapping() と canon が持っている)
. **ui/gen_lang.py に ja を足し、en を素通しにする。** tr(鍵) は表に
  無ければ鍵のまま返す作りなので、en は表なしで正しく出る。
  lang/src/i18n_en.rs は対の表としては消える(鍵の一覧は keys.json と
  ソースの走査が持つ)。i18n_edit.py / i18n_remap.py / i18n_soroi.rs の
  「en の表」を読む所を組み替える
. `tools/flip_i18n.py --go` でコードの鍵を書き替え、gen_lang で
  15 言語(ja を含む)を再生成
. **既定の言語。** いままで「無指定 = 日本語(素通し)」だった。裏返すと
  無指定 = 英語になる — **設定が無いときは OS のロケールに従い、日本語の
  機械では ja になる**ことを確かめる(発注者の画面が急に英語にならないこと)
. **assert 2,227 の書き替え。** 表の完全一致分は mapping で機械置換。
  contains 系の部分文字列は cargo test を回して出た赤から収束させる

== 段2: リボンのラベル

face/src/ribbon.rs の基底のラベルが日本語でコードの中にある。
基底を英語(いまの ribbon_en.rs の中身)にし、ribbon_ja.rs を vendor の
ja ロケール+材料の訳から生成する(gen_ribbon.py / gen_lang.py は
他言語で同じことを既にやっている)。品書き(ui::item!)は段1で済む。

== 段3: 識別子の英語化

* rs の日本語識別子 2,311 宣言。多い順: 字(31)名(22)前(16)元(14)…
  辞書を作って長い名前から置換 → cargo check で収束。**字は他の識別子の
  部分文字列になり得る** — 単語境界(非 ASCII の切れ目)で置換すること
* tools の py 42 件も同じ
* **sample/ と templates/ は対象外**(利用者向けの実例。日本語が正)

== 段4: 変な言葉の掃除

日本語が ja.json に降りたら、ja の文言を CLAUDE.md の表と「普通そう言うか」で
洗う(鍵に触らず訳だけ直せるようになっている — これがこの移行の配当)。
統合 16 組の正の日本語は解消表で選定済み。残りも同じ物差しで。

== 注意

* 段ごとに `cargo test --workspace` と i18n の見張り
  (i18n_soroi・ribbon_locale_check・i18n_onaji_go_check)を緑にしてから
  コミット
* 実機の文言確認は隔離画面で(:0 で押さない — tools/writer_sweep.py の頭)
* マクロの「リボン = {"ラベル": …}」の日本語キーは**利用者の書く物**なので
  対象外(前の版のキーも読む互換はそのまま)
