= Collabora Office の画面表示(2026-10-13)

発注者の決め(2026-10-13)により、Euro-Office に無い機能の画面は Collabora Office を
参考にします。Euro-Office のデスクトップ版はまだ無いので、画面の動きは Collabora の
デスクトップ版で確かめます。この文書は、Collabora の画面を調べた記録です。
officework の画面をどう変えるかは、ここでは決めていません。

== 動かし方

* 入れた物:Flathub の com.collaboraoffice.Office 26.04.3.3(2026 年 9 月)。利用者の
  領域に入れました(`flatpak install --user`)。ランタイムは org.kde.Platform 6.10 です。
* 設定は `~/.var/app/com.collaboraoffice.Office` にできます。
* Collabora が読めるフォルダーは xdg-documents だけです。この Debian ではそれが
  「~/ドキュメント」なので、試す文書のフォルダーは起動のときに渡します。
* 日本語のファイル名は開けません。URL が二重に変換され(`%E6` が `%25E6` になる)、
  「type detection failed」になります。英字の名前の写しで開きます。
* 撮るときは X11 で開きます。画面は Qt WebEngine の中の Web の画面なので、開発者ツールの
  入り口を手元だけに開けると、ボタンを押したり画面の写真を撮ったりできます。

----
flatpak run --user --nosocket=wayland --socket=x11 \
  --filesystem=<試すフォルダー> --env=QT_QPA_PLATFORM=xcb \
  --env=QTWEBENGINE_REMOTE_DEBUGGING=127.0.0.1:9222 \
  com.collaboraoffice.Office <文書>
----

* 文書は「Viewing」(表示だけ)の状態で開きます。右上の「Viewing」から
  「Editing Mode」を選ぶと編集できます。
* 画面の配色は、Debian のダーク表示に合わせて暗くなります。セルの地も紙の地も暗くなります。

== 表計算(xlsx)の画面

上から順に、メニューの行、Notebookbar、数式バー、シート、シートの見出し、ステータスバーです。

* タブ:ファイル・ホーム・挿入・ページレイアウト・Formulas・データ・検査・書式・表示・ヘルプ。
  選んだ物に応じて、Shape・画像・Chart・Table Design・スパークラインのタブが加わります。
* ホームのグループ:
** クリップボード:貼り付け、切り取り、コピー、書式のコピーと貼り付け、直接設定した書式の解除
** フォント:書体、大きさ、拡大と縮小、太字、斜体、下線、取り消し線、下付き、上付き、罫線、背景色、フォントの色
** 配置:上・上下中央・下の揃え、左から右と右から左、左・中央・右・両端の揃え、インデント、テキストを折り返す、Merge & Center
** 数値:表示形式、通貨、パーセント、小数点以下の桁の増減
** セル:行と列の挿入と削除
** スタイル:条件付き書式、セルのスタイル(標準・見出し 1・見出し 2・良い・中立・悪い)
** 編集:検索、置換、並べ替え、オートフィルター
* ステータスバー:シートの番号、選んだ範囲、言語、平均と合計、編集の状態、倍率。
* 訳が途中です。「Formulas」「Merge & Center」「Cells」「Editing」「Clipboard」などが英語のままです。

セルの表示で分かったこと(受け入れ試験の月次売上報告):

* 組み込みの表のスタイルの色(見出しと縞模様)を描きます。同じ core の LibreOffice 25.2 の
  PDF では描いていませんでした。
* 表の見出しのセルに、オートフィルターのボタン(▼)を出します。
* データバーは、グラデーションで描きます。最小の値の棒はほとんど 0 の長さで、OOXML の
  最小 10% にはしていません。
* 画像はセルの上に重なり、セルの字を隠します(Excel と同じです)。
* ウィンドウ枠の固定の線を、シートの幅いっぱいに引きます。

== 文書(docx)の画面

* タブ:ファイル・ホーム・挿入・レイアウト・参照・検査・書式・フォーム・表示・ヘルプ。
  選んだ物に応じて、テーブル・Shape・画像・Chart・数式のタブが加わります。
* ホームのグループ:クリップボード、フォント(文字間隔の調整と蛍光ペンを含む)、段落(箇条書き、
  番号付け、インデント、書式設定記号、揃え、行間、背景色)、スタイルの一覧、挿入(表、画像、
  改ページ、記号)、検索と置換。
* スタイルの一覧には、標準段落スタイル・本文・見出し 1〜4・表題・副題・引用文・整形済み
  テキストが、見本の形で並びます。
* 横と縦のルーラーがあります。
* コメントは、右の余白にカードの形で出ます(書いた人、本文、日付)。
* 回覧は 170% の倍率で開きました。
* ステータスバー:ページ、単語と文字の数、言語、編集の状態、表示の切り替え、倍率。
* 上付き(m²)と下付き(H₂O)は、小さくして上げ下げして描きます。

== officework の画面と並べて見たこと(2026-10-15)

同じ 2 つの文書(月次売上報告と回覧)を、officework と Collabora で開いて比べました。

表計算:

* グラフ:officework は、表題・目盛り・項目名・割合の字を描きます。Collabora はグラフの
  図形だけを描き、字を描きません。Excel は字を描きます。
* データバー:Collabora は、色から白へのグラデーションで描きます。officework の画面は
  単色で描いていたので、紙と同じ描き方に直しました。内側へのずらし(1.9pt)と長さは、
  画面と紙が同じ値を使います(`kumihan::look::BAR_INSET_PT` と `bar_share`)。
* データバーの長さ:officework は OOXML の既定(最小 10%、最大 90%)で描きます。
  Collabora は、最小の値の棒を 0 近くまで縮めます。
* 表の見出しのボタン:Collabora は、表の見出しのセルにオートフィルターのボタン(▼)を
  出します。officework は、シートのオートフィルターにだけ出し、表には出しません。
* 行の高さ:officework の画面は、高さを書いていない行を 24px で描き、シートの既定の
  高さ(この表では 18.75pt)を使いません。印刷はシートの既定の高さを使います。
* 表題:10 月 13 日に A1 を選んだ状態で見たときは、14pt の表題の上が欠けていました。
  10 月 15 日に A2 を選んだ状態で見たときは、欠けていませんでした。選んでいるときだけ
  欠けるのかは、まだ確かめていません。
* 画面の倍率:officework の画面は、列の幅と字を 96dpi で描き、行の高さだけを
  1pt = 1.6px で描きます。
* リボン:Collabora の表計算のリボンは、幅 2000px の窓でも右端が切れ、横の
  スクロールバーが出ます。

文書:

* コメント:Collabora は、右の余白にカードで出します(書いた人、本文、日付)。
  officework は、余白に印を付けて、左下のパネルに出します。
* officework のパネルの案内は「レビュー > コメント で編集」です。officework の文書の
  画面にレビューのタブは無く、コメントのボタンは共同編集のタブにあります。
* 回覧のコメントには日付(`w:date`)がありません。ECMA-376 では省いてよい属性です。
  Collabora は、日付を「0-00-00」と出します。
* ルーラー:Collabora は横と縦にあります。officework は横だけで、目盛りは mm です。
* スペルチェック:Collabora は「officework」に赤い波線を引きます。
