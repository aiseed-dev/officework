= Word・Excel との違いの分析(2026-10-16 から)

発注者の決め(2026-10-16):違いは数を集めるだけでは分からないので、1 つずつ見て原因を
突き止めます。重いのは、表示されない物、違う物、読みにくい物と、文書が指定した改ページを
守らないことです。書体の違いなどで少しずれることや、頁数の違いは、問題としては小さいと
します。

== 進め方

. `tools/pdf_eval.py` で、違いの入り口を見つけます(表示されない・改ページ・違う・読みにくい)。
. 同じ所を、Word・Excel の PDF と officework の PDF から切り出して並べ、目で確かめます。
  道具の誤りもここで見つけて直します。
. 元の docx・xlsx の XML で関わる所を見つけ、ECMA-376 で決まりを確かめます。決まりが無い
  ときは、Word・Excel に合わせます(AGENTS.md)。
. 下の表に 1 行ずつ書き、直したらコミットを書きます。

テンプレートは Microsoft の物なので、題だけを書き、中身は写しません。

== 評価の道具の誤り(見つけて直した物)

* Word・Excel で見えない字(白い字)を、「字が無い」と数えていた。Word・Excel の側の見えない
  字は、突き合わせる前に除く。
* 小さい「、」を見えないと判定していた。100dpi では画素が少ないので、字の色に近い画素が
  1 つあれば見えるとする。
* 太字を書体の名前で判定していた。officework は線を太くして太字にするので名前が変わらない。
  描かれた線の量で判定する。
* Excel が帯を画像で、officework が塗りで描くとき、画像が無いと数えていた。画像かどうかは
  読む人に関係無いので、色の面で比べる。
