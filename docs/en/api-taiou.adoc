= The button-to-API table

_日本語版(secondary): link:../ja/api-taiou.adoc[api-taiou.adoc]_

One page for looking up the code behind a button.

* From *the name of the button* you are pressing, find how to write it
* From *the python-docx or openpyxl call you already know*, find the
  officework one

The order matches the menus on screen: File, Home, Insert and so on. Find
the place you press and look there.

After the menus come *Quick access* (the top strip of the window), the
*side panels* (opened from the View tab), and the *status bar* along the
bottom.

The *Right-click* section lists only what exists nowhere else. Most of a
right-click menu repeats the ribbon (cut, copy, bold, alignment), so look
those up in the ribbon sections.

The same button sometimes appears in two places. Save is on the File page
and on the quick access strip. *Both are listed*, and the later one says
"Same as ...". They really are both on the screen, so we do not hide one.

== How to read the mark

The mark says one thing only: *whether a program can reach it*. The
button itself works from the screen whatever the mark says.

[cols="^1,3"]
|===
|Mark |Meaning

|✅ |*A program can call it.* The column to the right shows how
|✍ |*There is no dedicated call, but you can write it.* The column to the right shows how
|(blank) |*Not callable yet.* It is on the way
|❌ |*There is nothing to call.* The operation only changes what is on screen; neither the document nor the file changes
|===

== How to read the columns

The first two are *the name of the button*: what it says when the screen
is in English, and what it says in Japanese. Either one will find the
row. A `—` in the English column means that screen is not in English yet.

The `officework` column is how you write it here. The two columns to its
right are python-docx and openpyxl, showing *what each of them calls the
same operation*.

Where two forms are given as `A / B`, either works; which one depends on
whether you are in a document or a spreadsheet. A `—` means there is no
such call.

== Writing it makes it an API

A `✍` row can be wrapped in a function of your own and called by whatever
name you like.

[source,python]
----
def upper_case(paragraph):
    for r in paragraph.runs:
        r.text = r.text.upper()
    return paragraph
----

Package what you use often and hand it round the office. See "Adding a
package" in link:python-manual.adoc[the Python manual].
