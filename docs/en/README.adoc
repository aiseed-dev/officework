A ✅ in the *pip only* column means the booklet reads through on
`pip install officework` alone. The application (the writer and calc
windows) is not needed.

Booklets that exist in both languages are written in English first.

One is in Japanese only for now: the command manual
(link:../ja/commands/README.adoc[コマンドの手引き]), which is one page
per button.
