= 対応表 — メニュー・API・python-docx・openpyxl

引くための1枚です。同じ操作を4つの言い方で探せます。

*並びは画面のメニューのまま*です。ファイル・ホーム・挿入…の順に、
押すボタンがそのまま行になります。探すときは、画面で押している場所を思い出してください。

文章と表で同じ段は1つにまとめてあります(揃えた並び — 画面と同じ規則です)。

* `officework` の*呼び方*を引く
* python-docx / openpyxl の*覚えている書き方*から、こちらの書き方を引く
* 同じ操作を、*本家の2つがどう呼んでいるか*を見比べる

*列は「うち・本家」の組を2つ並べてあります。*
左の2列が文書(`officework` と python-docx)、右の2列が表(`officework` と openpyxl)です。
隣どうしを見れば移し替えが分かり、左右を見比べれば文書と表の違いが分かります。

本家の側は実際に呼んで確かめた名前です(python-docx 1.2.0 / openpyxl 3.1.5)。

// api:taiou:start(この間は tools/api\_taiou.py --write が書く)
1行が1つのボタンです。*並びは画面のメニューのまま*で、
`officework` の呼び方と、本家の呼び方が横に並びます。

*列は「うち・本家」の組を2つ*です。
左の2列が文書、右の2列が表。空いている所(—)は、その道がありません。

この節は `tools/api_taiou.py` が起こします。手で直さないでください。
