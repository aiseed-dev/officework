= 対応表 — メニュー・API・python-docx・openpyxl

引くための1枚です。同じ操作を4つの言い方で探せます。

* 画面で使っている*ボタンの名前*から、プログラムの書き方を引く
* `officework` の*呼び方*から、画面のどのボタンかを引く
* python-docx / openpyxl の*覚えている書き方*から、こちらの書き方を引く

本家の側は実際に呼んで確かめた名前です(python-docx 1.2.0 / openpyxl 3.1.5)。

// api:taiou:start(この間は tools/api\_taiou.py --write が書く)
1行が1つの操作です。画面のボタン・`officework`・本家のライブラリが横に並びます。
空いている所(—)は、その道が無いという意味です。

この節は `tools/api_taiou.py` が起こします。手で直さないでください。
