= シートを保護

シート見出しの右クリックにあります。

*状態: 実装済み* — いま使えます

== 何をするか

そのシートを保護します。保護すると、セルの中身を変えられなくなります。

もう一度押すと「保護を解除」に変わります。
いまの状態で文言が変わるので、押す前にどちらになるか分かります。

== ダイアログ

(ダイアログは出ません)

== プログラムから

[source,python]
----
s.protected = True
----

他のライブラリでは、こう書きます。

[cols="1,2"]
|===
|道具 |書き方

|openpyxl |`ws.protection.sheet = True`
|===
