= シートを保護

シート見出しの右クリックにあります。

*状態: 実装済み* — いま使えます

== 何をするか

そのシートを保護します。保護すると、ロックの掛かったセルの中身を変えられなくなります。

**セルは既定でロックされています。** 保護を掛けて初めてそのロックが効きます。
記入欄だけ開けた様式にするときは、開けたいセルのロックを先に外します。

もう一度押すと「保護を解除」に変わります。
いまの状態で文言が変わるので、押す前にどちらになるか分かります。

== ダイアログ

(ダイアログは出ません)

== プログラムから

[source,python]
----
s["B2"].protection = Protection(locked=False)   # ここだけ書けるようにする
s.protect()                                      # そのうえで保護する
----

`s.protection.sheet = True` と書いても同じです(openpyxl と同じ書き方)。
許す操作を選ぶときは `s.protect(allow=["sort", "autofilter"])` のように渡します。

保存すると xlsx の `sheetProtection` に書かれ、開き直しても残ります。

他のライブラリでは、こう書きます。

[cols="1,2"]
|===
|道具 |書き方

|openpyxl |`ws.protection.sheet = True`
