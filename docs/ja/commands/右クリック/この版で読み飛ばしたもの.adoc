== 何をするか

開いた docx の中で、このアプリが読めなかった部品を並べます。
画面に出ていないものが元のファイルに入っている、ということです。

**それぞれ、保存したときにどうなるかが書いてあります。**
「保存でも残る」ものと「保存で失われる」ものの両方が並びます。

[cols="1,2"]
|===
|出方 |意味

|保存でも残る |画面には出ませんが、書き戻すときに元のファイルから持ち越します
|保存で失われる |書き戻すと無くなります。*元のファイルの写しを取ってください*
|===

link:../ファイル/保存.adoc[保存]も合わせて読んでください。
