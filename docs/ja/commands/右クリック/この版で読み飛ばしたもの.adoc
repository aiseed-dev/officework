== 何をするか

開いた docx の中で、このアプリが読めなかった部品を、画面の下の状態行に
「 / 」で区切って並べます。画面に出ていないものが元のファイルに
入っている、ということです。読めなかった物が無ければ「読み飛ばした物は
ありません」と出ます。

部品の多くは、名前の後ろの括弧に、保存したときにどうなるかが書いてあります。

[cols="1,2"]
|===
|括弧の中 |意味

|保存でも残る、保存で残る |画面には出ませんが、書き戻すときに元のファイルから持ち越します
|保存で失われる |書き戻すと無くなります。*元のファイルの写しを取ってください*
|===

例: 「画像・図形(保存では残る)」「しおり(段落の外。保存で失われる)」。

フィールド(「フィールド(PAGE)」のように中身が付きます)と、ヘッダーや
フッターの中の部品、XML の読み取りエラーには、保存の扱いが付きません。
フィールドは保存で失われます。

link:../ファイル/保存.adoc[保存]も合わせて読んでください。
