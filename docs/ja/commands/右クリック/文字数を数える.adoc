= 文字数を数える

右クリックにあります。

*状態: 実装済み* — いま使えます

== 何をするか

字の数を数えて出します。空白を除いた数、空白込みの数、段落の数が出ます。

**単語の数は出しません。** 日本語は語の切れ目が空白ではないので、
単語で数えても意味のある数になりません。
