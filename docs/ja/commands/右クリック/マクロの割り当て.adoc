= マクロの割り当て

図形を右クリックすると出ます。

*状態: 未実装* — *まだ使えません。* これから作ります

== 何をするか

図形にマクロを結び付けて、押すと走るようにするためのものです。

*いまは灰色で、押せません。* 図形やボタンにマクロを結び付ける仕組みそのものが、まだありません。

いまマクロを走らせるには、マクロタブの link:../マクロ/一覧.adoc[一覧]から選んでください。
リボンにボタンとして出したいときは、link:../マクロ/リボンのマクロ.adoc[リボンのマクロ]があります。
