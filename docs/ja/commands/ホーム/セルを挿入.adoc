= セルを挿入

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ場所に空のセルを差し込みます。選んだ範囲の大きさぶん、周りのセルが動きます。

動いたセルを指していた数式の参照は、一緒に動きます。

== ダイアログ

一覧が開きます。4つから選びます。

[cols="1,2"]
|===
|選択肢 |どうなるか

|右方向にシフト |選んだ範囲と同じ行のセルを、範囲の幅ぶん右へ動かします
|下方向にシフト |選んだ範囲と同じ列のセルを、範囲の高さぶん下へ動かします
|行全体 |選んだ範囲の行数ぶん、行を差し込みます
|列全体 |選んだ範囲の列数ぶん、列を差し込みます
|===

「右方向にシフト」と「下方向にシフト」は、動くセルの並びを結合したセルがまたいでいると断ります。

== プログラムから

[source,python]
----
t.add_row() / s.insert_rows(行)
----

他のライブラリでは、こう書きます。

[cols="1,2"]
|===
|道具 |書き方

|python-docx |`t.add_row()`
|openpyxl |`ws.insert_rows(行)`
|===
