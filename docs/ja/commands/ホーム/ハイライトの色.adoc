= ハイライトの色

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ字に蛍光ペンの色を敷きます。

押すたびに、黄 → 緑 → 無しの順に変わります。
3回押すと外れます。

docx に保存され、Word でも同じ色に見えます。
