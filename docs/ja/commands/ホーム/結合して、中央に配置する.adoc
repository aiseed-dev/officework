= 結合して、中央に配置する

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだセルを1つにまとめ、中身を中央に置きます。

== ダイアログ

(ダイアログは出ません)

== プログラムから

[source,python]
----
cell.merge(相手)          # 文書の表(このセルから相手のセルまで)
s.merge_cells("A1:B2")   # 表計算
----
