= セルの書式設定

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

字・揃え・罫線・塗りを、1枚のパネルでまとめて決めます。

Excel の6タブのダイアログに当たるものですが、*開けたまま使えるパネル*です。
掛けながら表を見られます。カーソルのセルの近くに出ます。

== ダイアログ

パネルが開きます。もう一度押すか Esc で閉じます。

== プログラムから

[source,python]
----
c.font / c.alignment / c.border / c.fill
----

他のライブラリでは、こう書きます。

[cols="1,2"]
|===
|道具 |書き方

|openpyxl |`c.font / c.alignment / c.border / c.fill`
|===
