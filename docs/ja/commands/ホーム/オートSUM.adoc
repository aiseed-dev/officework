= オートSUM

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ範囲の下か右に、合計の数式を置きます。

* 縦に選んだときは、列ごとに範囲の1つ下のセルへ `=SUM(範囲)` を置きます。列を2つ以上選んでいれば、列の数だけ置きます
* 横1行を選んだときは、範囲の1つ右のセルへ置きます
* 1セルだけのときは、そのセルに、上に続いている数を対象にした `=SUM(…)` を入れます。上に数が無ければ `=SUM()` を入れるので、範囲を打ち足してください

置いた先に中身があれば上書きします。Ctrl+Z で戻せます。置いた後は、カーソルが最初に置いたセルへ移ります。

数式タブの平均・個数・最大・最小のボタンも同じ動きで、関数だけが変わります。
