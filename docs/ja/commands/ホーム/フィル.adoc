= フィル

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ範囲の上端にあるセルを読んで、下の残りを埋めます。

* 上端から続いている数(数式でないもの)が連続していれば、続きの数を埋めます。1つだけなら 1 ずつ増やします。2つ以上なら、その間隔で増やします(1, 2 なら 3, 4, 5。5, 10 なら 15, 20)
* 文字や数式は、上端のセルを下に写します。数式の相対参照は1行ずつずれ、`$` の付いた参照はそのままです。書式も一緒に写します
* 上端が空なら、空を配ります。中身は消え、書式は残ります

高さ1の範囲(1セルや横1行)では、1つ上の行を写します。1行目では、上が無いので断ります。

Ctrl+D(下へコピー)は、数が連続していてもいつも写します。フィルハンドルを引いたときの判定は、このボタンと同じです。
