= 文字の向き

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだセルの中の文字を、斜めや縦に向けます。

狭い列に長い見出しを入れるときに使います。

== ダイアログ

6つから選びます。いまの向きに ✓ が付きます。

[cols="1,2"]
|===
|選択肢 |どうなるか

|角度なし |横のままです
|左上がり 45度 |左上に向かって斜めになります
|右下がり 45度 |右下に向かって斜めになります
|上向き 90度 |下から上へ縦になります
|下向き 90度 |上から下へ縦になります
|縦書き(1字ずつ積む) |文字を1字ずつ縦に積みます
|===

== プログラムから

[source,python]
----
c.alignment = Alignment(text_rotation=90)
----

他のライブラリでは、こう書きます。

[cols="1,2"]
|===
|道具 |書き方

|openpyxl |`c.alignment = Alignment(text_rotation=90)`
|===
