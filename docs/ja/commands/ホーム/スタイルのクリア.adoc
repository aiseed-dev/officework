ホームにあります。

== 何をするか

選んだ所に掛けた書式を落として、元の姿に戻します。

== ダイアログ

(ダイアログは出ません)

== プログラムから

専用の呼び方はありません。書式を1つずつ None にすると、スタイルの値に戻ります。

[source,python]
----
for r in p.runs:
    r.bold = None
    r.italic = None
    r.underline = None
    r.color = None
----

`r.clear()` は字を消す処理で、書式は残ります。

他のライブラリでは、こう書きます。

|===
|道具 |書き方

|python-docx |`r.font.bold = None`
|===
