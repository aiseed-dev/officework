= 小数点以下の表示桁数を減らす

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだセルの表示形式を書き替えて、小数点以下の桁を1つ減らします。

*変わるのは見せ方だけです。* セルが持っている値は変わりません。

桁は 0 から 10 までです。0 より下へは減りません。
桁区切りのカンマが入っている表示形式なら、カンマは残ります。

== ダイアログ

(ダイアログは出ません)

== プログラムから

[source,python]
----
c.number_format = "0.00"
----

他のライブラリでは、こう書きます。
