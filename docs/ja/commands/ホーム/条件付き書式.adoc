= 条件付き書式

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

値によってセルの色や字を変えます。

== ダイアログ

出来合いのルールから選びます。

* 0未満を赤字
* 重複
* 一意
* 平均より上
* 平均より下
* データバー
* カラースケール
* アイコン

**条件と書式を自分で組む画面はありません。** Excel は「セルの値が」
「数式が」といった条件と、掛ける書式を自由に組み合わせられますが、
ここでは並んでいるルールから選びます。
