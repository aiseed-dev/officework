= セルを削除

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだセルを抜きます。空いた所へ、周りのセルが選んだ範囲の大きさぶん詰まります。

消えたセルを指していた数式の参照は `#REF!` になります。詰まって動いたセルを指していた参照は、一緒に動きます。

== ダイアログ

一覧が開きます。4つから選びます。

[cols="1,2"]
|===
|選択肢 |どうなるか

|左方向にシフト |選んだ範囲を消し、同じ行の右にあるセルを範囲の幅ぶん左へ詰めます
|上方向にシフト |選んだ範囲を消し、同じ列の下にあるセルを範囲の高さぶん上へ詰めます
|行全体 |選んだ範囲の行数ぶん、行を消します
|列全体 |選んだ範囲の列数ぶん、列を消します
|===

「左方向にシフト」と「上方向にシフト」は、動くセルの並びを結合したセルがまたいでいると断ります。

== プログラムから

[source,python]
----
s.delete_rows(行)
----

他のライブラリでは、こう書きます。

[cols="1,2"]
|===
|道具 |書き方

|===
