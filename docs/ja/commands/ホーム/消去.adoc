= 消去

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ所から、選んだ物を消します。既定の「数式と値」は中身だけを消し、書式は残します。

== ダイアログ

一覧が開きます。4つから選びます。

[cols="1,2"]
|===
|選択肢 |どうなるか

|すべて |中身も書式もコメントも消します。セルが無かったことになります
|書式 |書式だけを消します。値と数式は残ります
|数式と値 |値と数式だけを消します。書式は残ります(BackSpace や Delete と同じです)
|コメント |コメントだけを消します。範囲にコメントが無ければ、そう言って何もしません
|===

シートを保護しているときは、ロックされたセルを含む範囲では断ります。

== プログラムから

[source,python]
----
r.clear() / s['A1'] = None
----

他のライブラリでは、こう書きます。

[cols="1,2"]
|===
|道具 |書き方

|python-docx |`r.clear()`
|openpyxl |`ws['A1'] = None`
|===
