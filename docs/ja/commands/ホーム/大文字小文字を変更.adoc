= 大文字小文字を変更

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ英字を、大文字・小文字・先頭だけ大文字に変えます。

== ダイアログ

**どこで押すかで、選べるものが変わります。**

[cols="1,2"]
|===
|押した所 |何が起きるか

|表計算のセル |5つから選びます
|文書の本文 |*選ぶものはありません。* 大文字と小文字が入れ替わります
|===

セルで押したときに選べるのは次の5つです。

* 文の先頭だけ大文字
* すべて小文字
* すべて大文字
* 単語の先頭を大文字
* 大文字と小文字を入れ替え

== プログラムから

専用の呼び方はありません。こう書けば同じことができます。

[source,python]
----
r.text = r.text.upper()
----
