= セルのスタイル

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

字の太さ・大きさ・色・塗り・罫線をひとまとめにして、選んだセルに掛けます。

Ctrl+Z 一回で戻せます。

== ダイアログ

13 から選びます。

[cols="1,2"]
|===
|選択肢 |使いどころ

|標準 |書式を外して元に戻します
|見出し1・見出し2・見出し3・見出し4 |章と節を書き分けます。段が下がるほど字が小さく、線が細くなります
|表題 |表全体の題です
|良い・悪い・どちらでもない |判定の結果に色を付けます
|メモ |補足の行です
|計算 |式の入ったセルです
|通貨 |金額の列です
|パーセント |割合の列です
|===

色は Excel の写しではありません。この画面の見出しの緑に揃えてあります。

== プログラムから

[source,python]
----
b.add_named_style(スタイル)
----

他のライブラリでは、こう書きます。

[cols="1,2"]
