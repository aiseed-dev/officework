= ふりがな

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ漢字にふりがな(ルビ)を振ります。

まず機械の辞書で引きます。辞書で決まらないときは AI に聞きます。
読みが割れる語は、前後の文から選びます。

入るのは普通の字ではなく*ルビの書式*です。
本文では `ruby:漢字[かんじ]` の形になり、docx でも Word のルビとして残ります。

宛先は ファイル > 詳細設定 の「AI の宛先」で選びます。
繋がらないときは、その場で理由を言います。
