= 下揃え

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだセルの中身を、セルの下端に寄せます。

縦の位置は上揃え・上下中央揃え・下揃えの3つで、どれか1つが選ばれます。
何も指定していないセルは下揃えです。

xlsx に保存され、Excel で開いても同じ位置です。
