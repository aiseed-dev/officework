= 罫線

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

**どこで押すかで、掛かる相手が変わります。**

[cols="1,2"]
|===
|押した所 |何が起きるか

|文書の本文 |選んでいる*段落を枠で囲みます*。もう一度押すと外れます
|表計算のセル |選んでいる*セルに線を引きます*
|===

表計算の側は、*どこに引くか*(上・下・左・右・内側)と
*どんな線か*(太さ・種類・色)を別々に決めます。
組み合わせの型を選ぶ作りではありません。

== ダイアログ

(ダイアログは出ません)

== プログラムから

[source,python]
----
c.border
----

これは*表のセル*の線です。**段落を枠で囲むほうには、まだ呼び方がありません。**

他のライブラリでは、こう書きます。

[cols="1,2"]
|===
|道具 |書き方

|openpyxl |`c.border = Border(…)`
|===
