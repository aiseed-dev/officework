== 何をするか

複数の図形を1つにまとめます。まとめると、動かすのも大きさを変えるのも一度で済みます。

表の画面でも文章の画面でも、Ctrl+クリックで図形を足してから押します。
選んだ図形だけをまとめます。

文章の画面で図形を1つしか選んでいないときは、その図形と同じページにある図形を全部まとめます。
まとめてある図形を選んで押すと、まとまりを解きます。
同じまとまりの図形は、選んでいなくても一緒に解けます。

文章の画面では、選んでいる図形に緑の枠が出ます。
最後に押した図形の枠だけ太くなります。
図形の外を押すと、選択は全部外れます。

このボタンは図形のためのものです。
行や列をまとめるのは、データにある link:../データ/グループ化.adoc[グループ化]です。
