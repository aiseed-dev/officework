== 何をするか

複数の図形を1つにまとめます。まとめると、動かすのも大きさを変えるのも一度で済みます。

表の画面では、Ctrl+クリックで図形を足してから押します。

文章の画面では、図形を1つ選んでから押します。
選んだ図形と同じページにある図形を、全部まとめます。
文章の画面には図形を複数選ぶ仕組みがまだありません。
まとめてある図形を選んで押すと、まとまりを解きます。

このボタンは図形のためのものです。
行や列をまとめるのは、データにある link:../データ/グループ化.adoc[グループ化]です。
