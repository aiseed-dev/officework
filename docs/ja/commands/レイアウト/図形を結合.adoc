= 図形を結合

レイアウトにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ図形どうしを組み合わせて、新しい形を作ります。

押すたびに *結合 → 交差 → 減算* と回ります。
どれを掛けたかは状態行に「結合 / 交差 / 減算」の名前で出ます。

* *結合* は、2つを合わせた形にします
* *交差* は、重なっている所だけを残します
* *減算* は、先に選んだ方から後の方を引きます

減算で中を抜くと、穴のあいた形になります。

*結果は自由な形になります。* 元の形と回転には戻りません。

表の画面では、Ctrl+クリックで選んだ図形どうしを組み合わせます。

文章の画面では、選んでいる図形と、同じページにあるその次の図形を組み合わせます。
文章の画面には図形を複数選ぶ仕組みがまだありません。
