== 何をするか

見出しの字の色と紙の色を、組にして変えます。押すたびに6種を順に回ります。

標準・藍・緑・臙脂・藍と生成りの紙・墨と灰の紙の6つです。

*その時の色で塗ります。* テーマの部品を使わないので、Word で開いても同じ色に見えます。

Ctrl+Z 一回で戻せます。

calc では、表のテーマ色の組を入れ替えます。テーマ由来の色を使っているセルは、色がそのまま追従します。
