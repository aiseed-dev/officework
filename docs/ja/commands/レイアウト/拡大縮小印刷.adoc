= 拡大縮小印刷

レイアウトにあります。

*状態: 実装済み* — いま使えます

== 何をするか

印刷するときの倍率を変えます。押すたびに 100% → 90% → 80% → 70% → 50% → 100% と回ります。

*画面の見え方は変わりません。* 変わるのは紙に出したときだけです。

紙の枚数に合わせたいときは link:紙に収める.adoc[紙に収める]を使ってください。
