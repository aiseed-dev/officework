= 範囲を足す

レイアウトにあります。

*状態: 実装済み* — いま使えます

== 何をするか

いま選んでいる範囲を、印刷する範囲に足します。

link:印刷範囲.adoc[印刷範囲]が範囲を置き換えるのに対して、こちらは足します。
離れた場所を続けて印刷したいときに使います。

先に範囲を選んでください。選んでいないと、選ぶよう促して何もしません。
既に足してある範囲をもう一度足すことはしません。
