= ハイフン設定の変更

レイアウトにあります。

*状態: 実装済み* — いま使えます

== 何をするか

欧文の語を音節で折って、行末にハイフンを付けるかを決めます。文書全体の設定です(節では持ちません)。
状態行に「ハイフネーション: 入(英語の語を音節で折って - を付けます)」か「ハイフネーション: 切」と出ます。

*日本語には効きません。* 日本語は禁則で折るので、入れても切っても変わりません。
