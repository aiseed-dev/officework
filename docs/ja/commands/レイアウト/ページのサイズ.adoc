== 何をするか

紙の大きさを決めます。文書では、押すたびに A4 → B5 → A3 と回ります。表では A4 → A3 → B4 → B5 → A5 と回ります。向きは保ちます。

**文書では、カーソルのある節に掛かります。** 節が1つの文書では文書全体です。
途中から変えたいときは、挿入 > 区切り で節を分けてから、その節で押します
(link:../挿入/区切り.adoc[区切り]を見てください)。表では表全体に掛かります。
