== 何をするか

紙の大きさを決めます。文書では、押すたびに A4 → B5 → A3 と回ります。表では A4 → A3 → B4 → B5 → A5 と回ります。向きは保ちます。

**文書全体に掛かります。** 途中から変えたいときは節を分けてください
(link:../挿入/区切り.adoc[区切り]を見てください)。
