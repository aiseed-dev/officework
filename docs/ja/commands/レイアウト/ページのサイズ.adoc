= ページのサイズ

レイアウトにあります。

*状態: 実装済み* — いま使えます

== 何をするか

紙の大きさを決めます。向きは保ちます。

**文書では、カーソルのある節に掛かります。** 節が1つの文書では文書全体です。
途中から変えたいときは、区切り で節を分けてから、その節で押します
(link:../挿入/区切り.adoc[区切り]を見てください)。表では表全体に掛かります。

== ダイアログ

|A3 |297×420mm
