= 配置

レイアウトにあります。

*状態: 実装済み* — いま使えます

== 何をするか

図形の位置を揃えます。

表の画面では、複数の図形を Ctrl+クリックで選んでから押します。

文章の画面では、図形を1つ選んでから押します。
選んだ図形と同じページにある図形を、全部まとめて揃えます。
文章の画面には図形を複数選ぶ仕組みがまだありません。
図形が1つしか無いページでは、そう言って何もしません。

== ダイアログ

揃え方を一覧から選びます。

* 左
* 中央
* 右
* 上
* 中
* 下

左・中央・右は横の位置を、上・中・下は縦の位置を揃えます。
中央と中は、図形の並びの真ん中に寄せます。
