== 何をするか

図形の位置を揃えます。

表の画面でも文章の画面でも、複数の図形を Ctrl+クリックで選んでから押します。
選んだ図形だけを揃えます。

文章の画面で図形を1つしか選んでいないときは、その図形と同じページにある図形を全部揃えます。
図形が1つしか無いページでは、そう言って何もしません。

== ダイアログ

揃え方を一覧から選びます。

* 左
* 中央
* 右
* 上
* 中
* 下

左・中央・右は横の位置を、上・中・下は縦の位置を揃えます。
中央と中は、図形の並びの真ん中に寄せます。
