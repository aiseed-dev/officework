= 参照元のトレース

数式にあります。

*状態: 実装済み* — いま使えます

== 何をするか

いまのセルの数式が、どのセルを見ているかを矢印で出します。
矢印は、参照しているセルの中心から、いまのセルの中心へ引きます。
矢印の根元には小さな四角、先には矢じりが付きます。
参照しているセルの背景には、薄い青緑が付きます。

範囲の参照(A1:A5 など)は、範囲の中のセル1つずつから矢印を引きます。

いまのセルに数式が無いとき、または参照しているセルが無いときは、状態行にそう出ます。矢印は出ません。

隣の「参照先のトレース」は逆向きです。
いまのセルを見ている数式のセルへ、いまのセルの中心から矢印を引きます。
参照先のセルの背景には、薄い橙が付きます。

矢印は「トレース矢印の削除」で消えます。
画面の外にあるセルへの矢印は描きません。画面を動かすと、そのセルが入ったときに描きます。
