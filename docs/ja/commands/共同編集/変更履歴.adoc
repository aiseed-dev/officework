= 変更履歴

共同編集にあります。文書と表の両方にあります。

*状態: 実装済み* — いま使えます

== 何をするか(文書)

押すと記録が始まり、もう一度押すと止まります。

記録している間は、変わった段落の左に橙の棒が出ます。
記録するのは、押した時点との差です。直した所・足した所・消した所が分かります。

docx で保存すると、Word の本物の変更履歴になります。誰が・いつ・どこを直したかが付きます。

adoc の形式で保存するときは、git の差分で見られます。本文がテキストなので、どこが変わったかがそのまま読めます。

*記録をやめると、それまでの差分は捨てます。* 状態行にもそう出ます。

== 何をするか(表)

押すと記録が始まり、もう一度押すと止まります。

記録を始めると、その時点のセルの中身(数式は数式のまま)を控えます。
止めると、控えとの差をセルごとに記録に足します。
記録には、誰が・いつ・どのシートのどのセルを・何から何へ変えたかが入ります。

止めたときに差が1つも無ければ、記録は増えません。状態行にそう出ます。
記録が残っているブックでは、このボタンは記録の一覧を新しい順に開きます(最大 200 件)。
一覧の項目を選ぶと、そのセルへ移ります。
記録が残っているブックで記録をもう一度始めることは、いまはできません。

xlsx に保存すると、記録はブックの中に残ります。開き直しても一覧に出ます。
