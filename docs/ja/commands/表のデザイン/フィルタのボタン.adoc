= フィルタのボタン

表のデザインにあります。

*状態: 実装済み* — いま使えます

== 何をするか

カーソルのある表の見出しに、▼(フィルタのボタン)を出すかどうかを切り替えます。

押すたびに入切が変わります。

* 入れると、表の見出し行から最後の行まで(合計行があればその手前まで)に絞り込みが掛かり、見出しに ▼ が出ます
* 切ると、その表に掛かっていた絞り込みを外します

この入切は表の設定として保存されます。
xlsx に保存すると、表の定義に `<autoFilter>` が入ります。Excel で開いても ▼ が付いたままです。

カーソルが表の中に無いときは、状態行に「表の中にカーソルを置いてください」と出ます。
表は「挿入 > 表」で作れます。

データタブの「フィルタ」は、表でない範囲に絞り込みを掛けるためのボタンです。
こちらは表の設定を変えるボタンで、保存に残る点が違います。
