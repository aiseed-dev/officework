= 範囲を保護する

保護にあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ範囲を、シートの保護中でも編集できる範囲として登録します。同時にシートの保護も掛かります。
Excel の「範囲の編集を許可」と同じ意味です。

* 登録した範囲の中のセルは、保護中でも打つ・消すができます
* 範囲の外のセルは、セルのロックの設定どおりに止まります(link:保護.adoc[保護]・link:セルのロック.adoc[セルのロック])

登録した範囲は xlsx に残るので、Excel で開いても同じ範囲が編集できます。

同じ範囲をもう一度選んで押すと、登録が外れます。全部外してもシートの保護は残るので、外すときは link:保護.adoc[保護] をもう一度押してください。

*先に範囲を選んでください。* 選んでいないと「許す範囲を選んでください」と出て、何も起きません。

*パスワードは掛けません。* 誰でも外せます。
