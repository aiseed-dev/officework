= 保護

保護にあります。

*状態: 実装済み* — いま使えます

== 何をするか

文書やブックを、決めた操作しかできない形にします。

== 文章の画面では

保護の種類を一覧から選びます。
docx の `w:documentProtection` の `w:edit` と往復するので、Word でも同じ保護に見えます。
パスワードは掛けません。掛けた振りもしません。
外すときは、同じ一覧の「保護しない」を選びます。

記入欄と組み合わせると、配布用の様式になります。
「記入欄の記入だけ」にして配り、受け取った側は欄だけ記入します。

=== ダイアログ

一覧から1つ選びます。

* *保護しない* — 保護を外します
* *読み取り専用* — 打鍵も、文書を変えるボタンも止めます。見る・刷る・検索・コピーは通します(docx では `readOnly`)
* *コメントだけ* — 本文は変えられません。コメントの追加・削除・編集はできます(`comments`)
* *変更履歴つきの編集だけ* — 打てます。変更履歴の記録が始まり、保護を外すまで止められません(`trackedChanges`)
* *記入欄の記入だけ* — 記入欄の中だけ打てます。チェックボックスの切り替えと、コンボボックス・ドロップダウンの選び直しもできます。欄の外は変えられません。新しい欄は置けません(`forms`)

止めたときは、状態行でどの保護かを言います。

== 表の画面では

読み取り専用にします。
許可する操作をチェックで選びます。
link:../ファイル/保護する.adoc[保護する]と同じ一覧です。
