= ブックを保護する

保護にあります。

*状態: 実装済み* — いま使えます

== 何をするか

ブックの構造を守ります。シートの追加・削除・複製・並べ替え・名前の変更ができなくなります。
やろうとすると、状態行に「ブックの構造が保護されています」と出て、何も起きません。
シートを隠す・戻す、タブの色を変えることはできます。

もう一度押すと外れます。

*パスワードは掛けません。* 誰でも外せます。うっかり触るのを止めるための機能です。

*セルの中身は守りません。* セルを守るのは link:保護.adoc[保護](シートの保護)です。
