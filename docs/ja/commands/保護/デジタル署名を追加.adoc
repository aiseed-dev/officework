= デジタル署名を追加

保護にあります。

*状態: 実装済み* — いま使えます

== 何をするか

ファイルの隣に署名ファイルを置きます。名前は `文書.docx.sig` です。方式は Ed25519 です。

押すと、署名が有効ならその旨を報告します。
署名が無いときと、中身が変わっているときは、署名し直します。

署名の鍵は `~/.config/officework/sign.key` に自動で作られます。

*実体は、改ざんの検知と名前の証明です。* Word の署名欄に出る方式ではありません。

保存していないと押せません。先にファイルとして保存してください。
直したまま保存していないときも、保存を先にするよう言います。
