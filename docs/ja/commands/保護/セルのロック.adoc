= セルのロック

保護にあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだセルにロックの印を付けます。

選んだ所が全部ロック済みなら外し、そうでなければ掛けます。

*このボタンだけでは何も起きません。* ロックが効くのは、
link:保護.adoc[保護]でシートを保護したときです。

記入してもらう欄だけロックを外し、そのうえでシートを保護する、という使い方をします。

== ダイアログ

(ダイアログは出ません)

== プログラムから

[source,python]
----
c.protection = Protection(locked=False)   # ここだけ書けるようにする
s.protect()                               # そのうえで保護する
----

他のライブラリでは、こう書きます。
