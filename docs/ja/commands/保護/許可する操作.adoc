= 許可する操作

保護にあります。

*状態: 実装済み* — いま使えます

== 何をするか

シートを保護したまま、触ってよい操作を決めます。

== ダイアログ

押して入切するチェックの一覧が、14 個出ます。

* 図形・画像の操作
* ロックされたセルの選択
* ロックされていないセルの選択
* セルの書式設定
* 列の書式設定
* 行の書式設定
* 列の挿入
* 行の挿入
* ハイパーリンクの挿入
* 列の削除
* 行の削除
* 並べ替え
* オートフィルターの使用
* ピボットテーブルの使用

**保護していないときは効きません。** 先に保護を掛けてください。
