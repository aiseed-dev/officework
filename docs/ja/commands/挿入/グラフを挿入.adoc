= グラフを挿入

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ範囲からグラフを描いて、シートの上に画像として浮かべます。
描くのは Python の matplotlib です。

範囲の読み方は次のとおりです。

* 1列目が項目名になります
* 2列目から先が系列になります
* 先頭行が見出しなら、それが系列名になります

日本語のフォントは、その機械のものを登録して描きます。文字が豆腐になりません。

*挿した時の値の絵です。* 元のデータを直しても、グラフは追随しません。
描き直すには、もう一度押してください。

Python が見つからないときは、入れる手順を状態行で言います。

隣の「推奨チャート」も同じ仕組みです。

== 文章の画面では

カーソルを表の中に置いてから押します。
その表から縦棒グラフを描いて、表の外の段落の下に画像として入れます。
表の読み方は上と同じです(1列目が項目名、2列目からが系列、先頭行が文字なら系列名)。
数の無い表では、そう言って何もしません。

カーソルが表の外にあるときは、画像ファイルを選ぶ窓が出ます。

*挿した時の値の絵です。* 表を直しても追随しません。描き直すには、もう一度押してください。
Ctrl+Z 一回で戻せます。
