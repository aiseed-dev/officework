= SmartArtの挿入

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

図解を置きます。分類を選び、次に形を選びます。

*入るのは図形の集まりです。* 1つの部品ではありません。
各図形を選んで、文字を入れたり動かしたり消したりできます。

分類と並びと名前は Euro-Office の現物と同じです。

まとめて画像にするときは、選んでから右クリックの
link:../右クリック/画像として保存.adoc[画像として保存(SVG)]を使ってください。
束ねてあれば1枚にまとまります。

== 文章の画面では

図解の部品はありません。
押すと画像ファイルを選ぶ窓が出て、選んだ画像(PNG・JPEG・SVG)をカーソルの段落の下に入れます。
図解は Python(matplotlib など)で描いて SVG にしておき、それを選んで入れてください。

== ダイアログ

表の画面では、分類 → 形 の順に選びます。

文章の画面では、画像ファイルを選ぶ窓が出ます。
