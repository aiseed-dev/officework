= SmartArtの挿入

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

図解を置きます。分類を選び、次に形を選びます。

*入るのは図形の集まりです。* 1つの部品ではありません。
各図形を選んで、文字を入れたり動かしたり消したりできます。

分類と並びと名前は Euro-Office の現物と同じです。

まとめて画像にするときは、選んでから右クリックの
link:../右クリック/画像として保存.adoc[画像として保存(SVG)]を使ってください。
束ねてあれば1枚にまとまります。

== 文章の画面では

分類と形の一覧は表の画面と同じです。
形を選ぶと、Python(matplotlib)が図解を描いて、カーソルの段落の下に画像として入れます。
画像は本文の幅いっぱいに置きます。

図解の項目は、選んでいる段落の箇条書き(中黒か段落番号)の字です。
段落を選んでいないときは、カーソルの段落が属する箇条書きのひとかたまりを全部使います。
箇条書きが1つも無いときは、「項目 1」「項目 2」「項目 3」の見本で描きます。
このときは状態行でそう言います。

入るのは画像です。中の図形は選べません。
項目の字を直すには、箇条書きを直してからもう一度入れてください。

Python か matplotlib が無いときは、状態行に入れ方(pip のコマンド)が出ます。

== ダイアログ

表の画面でも文章の画面でも、分類 → 形 の順に選びます。分類は7つです。

* リスト: カード リスト・縦方向リスト・ピラミッド リスト
* 手順: 基本ステップ・プロセス・タイムライン
* 循環: 基本の循環・ブロック循環
* 階層: 組織図・階層
* 関係: 基本ベン図
* マトリックス: 基本マトリックス
* ピラミッド: 基本ピラミッド
