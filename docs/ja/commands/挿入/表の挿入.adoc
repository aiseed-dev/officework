= 表の挿入

挿入にあります。文書と表の両方にあります。

*状態: 実装済み* — いま使えます

== 何をするか(文書)

選んだ大きさの表を、本文の末尾に入れます。
セルをクリックすると中を書けます。

セルの中では、Tab で隣のセルへ、Shift+Tab で前のセルへ動きます。
動いた先のセルの字は選んだ状態になるので、打つと置き換わります。
行の右端で Tab を押すと、次の行の左端へ動きます。
最後のセルで Tab を押すと、行を1つ足してそこへ動きます(Word と同じ)。
最初のセルで Shift+Tab を押しても動きません。

== 何をするか(表)

選んだ範囲を表にします。表は名前の付いた範囲です。
1行目を見出し行にして、太字と色を掛けます。
2行おきに縞模様の色を敷き、外側に細い罫線を引きます。
見出し行にはフィルタのボタン(▼)が出ます。
表のデザインタブの「フィルタのボタン」で、▼ を消したり戻したりできます。

表の名前は「テーブル1」「テーブル2」のように、ブックの中の表の数で付きます。
範囲を選んでいないときは、「表にする範囲を選んでください」と状態行に出て、何もしません。
色の組を選んでから作るときは、「表として書式設定」を使います。

== ダイアログ

文書では、行数と列数を打つ欄が出ます。表では、ダイアログは出ません。

....
3,4
....

`3x4` や `3 4` と打っても同じです。
数が読めないときは、そう言って欄を開いたままにします。

**表の横幅は、文章が書ける幅になります。** 列数で等分するので、
列を増やしても紙からはみ出しません。

行は 200 まで、列は 50 まで打てます。
