= 表の挿入

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ大きさの表を、本文の末尾に入れます。
セルをクリックすると中を書けます。

セルの中では、Tab で隣のセルへ、Shift+Tab で前のセルへ動きます。
動いた先のセルの字は選んだ状態になるので、打つと置き換わります。
行の右端で Tab を押すと、次の行の左端へ動きます。
最後のセルで Tab を押すと、行を1つ足してそこへ動きます(Word と同じ)。
最初のセルで Shift+Tab を押しても動きません。

== ダイアログ

行数と列数を打つ欄が出ます。

....
3,4
....

`3x4` や `3 4` と打っても同じです。
数が読めないときは、そう言って欄を開いたままにします。

**表の横幅は、文章が書ける幅になります。** 列数で等分するので、
列を増やしても紙からはみ出しません。

行は 200 まで、列は 50 まで打てます。
