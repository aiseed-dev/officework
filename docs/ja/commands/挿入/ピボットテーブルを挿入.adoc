= ピボットテーブルを挿入

挿入とピボットテーブルの両方にあります。する事は同じです。

*状態: 実装済み* — いま使えます

== 何をするか

見出しの付いた表から、集計の表を作ります。

範囲を選ばずに押しても構いません。
カーソルを表の中に置いて押すと、表全体を自動で見つけます。
範囲を選ぶのは、絞りたいときだけです。

データの行が見出しの下に1行も無いときは、その旨を状態行で言って断ります。

集計するのは polars です。結果はその時の値として、元の表の右の空きに置かれます。
そこが埋まっていれば、さらに右へ置きます。黙って上書きはしません。

== ダイアログ

3つを順に聞きます。

. 行に並べる見出し(複数選べます)
. 列に広げる見出し(省略できます)
. 値と集計。合計・平均・個数・最大・最小の5つから選びます
