= テキストアートの挿入

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

飾り文字を置きます。太い字に縁取りを付けた形です。

*描くのは Python です。* 図形やグラフと同じ道で、画像として貼ります。

文字そのものではなく絵になるので、後から本文として検索することはできません。

== ダイアログ

文字を打つ欄が出ます。Enter で描いて入れます。Esc で閉じます。
空のまま Enter を押しても何も入りません。

文章の画面では、カーソルの段落の下に画像として入ります。
表の画面では、選んでいるセルの所に浮かべます。

Python か matplotlib が無いときは、入れ方を状態行で言います。
