= 図形を挿入

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

図形を置きます。

*描くのは Python です。* matplotlib などが描いて、画像として貼ります。
SVG なので、拡大しても粗くなりません。

表の画面では、置いた図形は選んで動かせます。中に文字も書けます。

== 文章の画面では

分類の一覧は表の画面と同じです。
分類を選ぶと、同じ場所に形の一覧が出ます。
形を選ぶと、Python(matplotlib)がその形を描いて、カーソルの段落の下に画像として入れます。
画像は幅 60mm で置きます。

入るのは画像です。図形としては選べません。
大きさを変えたり消したりするのは、画像と同じやり方です。

Python か matplotlib が無いときは、状態行に入れ方(pip のコマンド)が出ます。

== ダイアログ

分類を選んでから、形を選びます。分類は7つです。

* 基本図形
* ブロック矢印
* 数式図形
* フローチャート
* 星とリボン
* 吹き出し
* 線
