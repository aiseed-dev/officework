== 何をするか

図形を置きます。

*描くのは Python です。* matplotlib などが描いて、画像として貼ります。
SVG なので、拡大しても粗くなりません。

置いた図形は選んで動かせます。中に文字も書けます。

== 文章の画面では

分類の一覧はまだありません。
押すと画像ファイルを選ぶ窓が出て、選んだ画像(PNG・JPEG・SVG)をカーソルの段落の下に入れます。
図形は Python(matplotlib など)で描いて SVG にしておき、それを選んで入れてください。

== ダイアログ

* 基本図形
* ブロック矢印
* 数式図形
* フローチャート
* 星とリボン
* 吹き出し
