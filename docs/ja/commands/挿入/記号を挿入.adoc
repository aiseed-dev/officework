= 記号を挿入

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

キーで打てない記号を選んで入れます。

== ダイアログ

分類を選んでから、字のセルを選びます。

* *分類* — 最近使った字と、組ごとの一覧
* *Unicode を打つ* — 番号を直に打てます(例: `3012` と打つと `〒`)

**フォントの選択はありません。** Word は字ごとにフォントを選べますが、
ここでは文書のフォントで入ります。

== プログラムから

専用の呼び方はありません。こう書けば同じことができます。

[source,python]
----
r.text += '※'(字をそのまま打つ)
----
