= 区切り

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

押すと一覧が出て、3つから選びます。

[cols="1,3"]
|===
|項目 |どうなるか

|ページ |押した段落の前で紙が変わります(改ページ)。もう1度選ぶと外れます
|節(次のページから) |押した段落から新しい節が始まり、紙も改まります。新しい節は前の節と同じ用紙・向き・余白で始まるので、変えたいときはその節にカーソルを置いて レイアウト > 用紙・印刷の向き・余白 を押します
|節(続き) |押した段落から新しい節が始まりますが、紙は改まりません。段組みだけを途中から変えるときに使います
|===

節の区切りは、押した段落の1つ前の段落に付きます。押した段落が文書の先頭なら、空の段落を1つ前に足して、そこに付けます。

.adoc に保存すると、こう書かれます。

----
[page-size=A4, page-layout=landscape, page-margin=20mm]
<<<
----

`<<<` の無い行だけなら「節(続き)」です。頭の `:page-size:` `:page-layout:` `:page-margin:` は最初の節の用紙です。

== ダイアログ

== プログラムから

[source,python]
----
d.add_page_break()
d.add_section("newPage")      # 新しい紙から始める節
d.add_section("continuous")   # そのまま続ける節
----

|道具 |書き方

|openpyxl |`ws.row_breaks`
|===
