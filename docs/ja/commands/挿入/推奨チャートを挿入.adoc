= 推奨チャートを挿入

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ範囲の形を見て、合いそうなグラフの種類を一覧に並べます。
選ぶと、その種類のグラフが範囲の右隣に入ります。

範囲の読み方は「グラフを挿入」と同じです。
1列目が項目名、2列目からが系列です。
先頭行に文字があれば、その行を見出し(系列の名前)として使います。

範囲を選んでいないときは、状態行に「先に範囲を選んでください」と出ます。

== ダイアログ

ボタンの下に一覧が開きます。先頭が一番合う形です。
並べる種類と順番は、範囲の形で決まります。

[cols="2,3"]
|===
|範囲の形 |並ぶ種類(この順)

|1列目が全部数(項目名でなく X の値) |散布図を先頭に足し、その後ろに下のどれかの並び
|1列目が日付・年・月に見える、または 13 行以上 |折れ線、面、縦棒、横棒
|系列が1つで 2〜8 行、負の数が無い |円、縦棒、横棒、折れ線、面
|それ以外 |縦棒、横棒、折れ線、面
|===

横棒は 20 行までのときだけ並びます。
1列目が「2024」「4月」「Q1」「2024/04」のような字のとき、または日付の表示形式のとき、時系列と見ます。

種類は6つです。

* 縦棒グラフ
* 横棒グラフ
* 折れ線グラフ
* 面グラフ
* 円グラフ(1つ目の系列だけを描きます)
* 散布図(1列目を X の数として読みます)

描くのは Python の matplotlib です。入っていないときは、入れ方を状態行に出します。
