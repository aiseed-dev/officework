= ペン

描画にあります。

*状態: 実装済み* — いま使えます

== 何をするか

押すとペンになり、ドラッグした所に線が引けます。
細い黒の線です。

もう一度同じボタンを押すか、Esc を押すと、元の操作に戻ります。
状態行に「ペン: 表の上をドラッグで描く(もう一度押すか Esc で戻る)」と出ます。
writer では「紙の上をドラッグで描く」と出ます。

[cols="1,2"]
|===
|画面 |引いた線がどうなるか

|calc |普通の図形(折れ線)として保存されます。Excel でも線に見えます
|writer |画像(SVG)として、本文の隣の `images` フォルダに入ります。本文からは `image::` で指されます
|===

1筆が1手です。Ctrl+Z を押すと、1本ずつ戻ります。

writer では、線は紙の上の位置に固定されます。本文を編集しても動きません。
ただし保存すると、線は本文の流れの中の絵になります。
引いた高さのすぐ上の段落の後ろに入り、紙の上の左右の位置は残りません。

印刷(PDF)にも出ます。
