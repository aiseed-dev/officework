= 消しゴム

描画にあります。

*状態: 実装済み* — いま使えます

== 何をするか

押すと消しゴムになり、引いた線をなぞると消せます。

*消えるのは1筆ずつです。* 線の途中をなぞっても、その1本が丸ごと消えます。
状態行に「消しゴム: 線をなぞると1筆ずつ消える」と出ます。

もう一度同じボタンを押すか、Esc を押すと、元の操作に戻ります。

消えるのは link:ペン.adoc[ペン]と link:蛍光ペン.adoc[蛍光ペン]で引いた線だけです。
セルの中身や本文の文字は消えません。
