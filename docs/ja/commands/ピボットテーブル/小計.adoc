== 何をするか

かたまりごとの小計を出します。もう一度押すと消えます。

押すとピボットを作り直し、状態行に「小計: あり」または「小計: なし」と出ます。

*行の見出しが2つ以上のピボットでだけ効きます。*
1つしかないと「行の見出しが2つ以上のピボットで効きます(挿入で複数選ぶ)」と出ます。

表の端に出る総計は link:総計.adoc[総計]です。

データにある link:../データ/小計.adoc[小計]とは別のものです。
あちらは普通の表に =SUM の行を入れます。
