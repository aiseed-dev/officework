= 設定

右パネルにあります。右パネルの柱のいちばん上を押すと出ます。

*状態: 実装済み* — いま使えます

== 何をするか

カーソルのある場所の書式を変えます。文書全体ではなく、いま居る所に掛かります。

上に「設定。カーソルのある場所に掛かります」と出ます。

=== 文字

太字・斜体・下線・取り消し線が並びます。
その下に、いまの大きさと書体が出ます(「大きさ 10.5 pt / 書体 Noto Sans CJK JP」)。
小さく・大きく・色でその場を変えられます。書式を消すで元に戻します。

=== 段落

左・中央揃え・右・両端揃え・均等が並びます。
その下に、いまの行間と字下げが出ます(「行間 1 / 字下げ 0」)。
行間・字下げを減らす・字下げを増やす・箇条書き・番号・背景・囲みが続きます。

== ダイアログ

ボタンはリボンの同じ名前のものと同じ働きです。
色や行間のように選ぶものがあるボタンは、リボンから押したときと同じ一覧が出ます。

== プログラムから

パネルそのものを開く呼び方はありません。中のボタンが変える所は、
それぞれの書き方で変えられます。

[source,python]
----
r.bold = True                  # 文字を太字に
p.align = "center"             # 段落を中央揃えに
p.paragraph_format.line_spacing = 1.5
----

link:../../api-taiou.adoc[対応表]の「ホーム」に、同じ名前のボタンの行があります。
