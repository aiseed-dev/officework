= プロジェクトパネル

右パネルにあります。右パネルの柱のいちばん下(フォルダの絵)を押すと出ます。

*状態: 実装済み* — いま使えます

== 何をするか

いま開いているフォルダの中のファイルを並べます。

**フォルダが1つのプロジェクトです。** ここは、ほかの道具のファイル管理の
画面と同じことができます。

[cols="1,2"]
|===
|できること |やり方

|中を見る |フォルダを開くと、その中のファイルが並びます
|開く |ファイルを押します
|フォルダの中へ入る |フォルダを押します
|上へ戻る |いちばん上の `‹ 上へ` を押します
|新しく作る |`+ フォルダ` `+ 文書`(表計算では `+ 表`)
|名前を変える |行の右の `名前`
|消す |行の右の `消す`
|===

**この道具で開けない種類は、その機械で結び付けてある道具が開きます。**
`.ipynb` なら JupyterLab、というように機械の決めをそのまま使います。

== ダイアログ

作る・名前を変えるときは、名前を打つ欄が出ます。

**消すときは確かめます。** Enter で消し、Esc でやめます。
*ごみ箱には入りません。* 元に戻せません。

断るのは次のときです。
名前が空のとき、`/` や `\` が入っているとき、`.` で始まるとき。
同じ名前が既にあるとき(*上書きしません*)。
フォルダの中に物があるとき(先に中を空にしてください)。
いま開いているファイルを消そうとしたとき。

一覧に出るのは 200 件までです。それより多いときは、
「ほかに ◯ 件あります」と下に出ます。

== プログラムから

(専用の呼び方はありません)

ファイルを触るだけなら、Python で直に書けます。

[source,python]
----
from pathlib import Path

(Path("仕事") / "資料").mkdir()              # フォルダを作る
(Path("仕事") / "あ.adoc").rename("仕事/い.adoc")   # 名前を変える
(Path("仕事") / "い.adoc").unlink()          # 消す
----
