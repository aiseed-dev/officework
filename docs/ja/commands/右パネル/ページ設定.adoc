= ページ設定

右パネルにあります。右パネルの柱の上から2つ目を押すと出ます。

*状態: 実装済み* — いま使えます

**この画面は文書(writer)だけにあります。** 表(calc)の右パネルには
ページ設定がありません。表の紙の決めは、リボンのレイアウトの
向き・用紙・余白から変えます。

== 何をするか

紙の決めを変えます。**カーソルの場所ではなく、文書全体に掛かります。**

上に「ページ設定。文書全体に掛かります」と出て、その下にいまの値が並びます
(「210×297mm / 余白 20mm / 1段」)。

並ぶボタンは、向き・用紙・余白・段組み・縦書きです。
その下に「ヘッダーとフッター」があり、編集・ページ番号・透かしが並びます。
いちばん下がページの色です。

== ダイアログ

用紙・余白・段組みは選ぶ一覧が出ます。リボンのレイアウトから押したときと同じです。

== プログラムから

節の設定として読み書きします。

[source,python]
----
s = d.sections[0]
s.page_width                  # 紙の幅
s.left_margin                 # 左の余白
----

他のライブラリでは、こう書きます。

[cols="1,2"]
|===
|道具 |書き方

|python-docx |`section.page_width`
|===

表の紙の決めは、シートの設定として読み書きします。

[cols="1,2"]
|===
|道具 |書き方

|officework |`s.paper_size` / `s.orientation`
|openpyxl |`ws.page_setup.paperSize`
|===
