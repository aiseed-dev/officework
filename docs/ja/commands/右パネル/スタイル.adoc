= スタイル

右パネルにあります。右パネルの柱の上から3つ目を押すと出ます。

*状態: 実装済み* — いま使えます

== 何をするか

いまの段落のスタイルを選びます。

上に「スタイル。テンプレートを直します」と出て、その下に
「いまの段落: 本文」のように、いま当たっているスタイルが出ます。

選べるのは次のとおりです。

なし・本文・表題・見出し1・見出し2・見出し3・見出し4・見出し5・
引用・註記・ヒント・重要・警告・注意・塊の区切り・塊の中・等幅・塊の題・
説明のリスト・取り込み・チェック・指定の行・横の区切り線・覚え書き

**直すとテンプレートが変わり、同じスタイルの所が一度に変わります。**
1か所だけ変えたいときは、右パネルの「設定」で直してください。

== この面が出ないとき

**この道具で作った文書(adoc)のときだけ出ます。** docx や xlsx を開いて
いるときは、柱にスタイルの絵が並びません。互換の文書にはテンプレートが
無いので、押しても見せる物がないためです。
