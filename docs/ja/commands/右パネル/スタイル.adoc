= スタイル

右パネルにあります。右パネルの柱の上から3つ目を押すと出ます。

*状態: 実装済み* — いま使えます

== 何をするか

いまの段落のスタイルを選びます。

上に「スタイル。テンプレートを直します」と出て、その下に
「いまの段落: 本文」のように、いま当たっているスタイルが出ます。

選べるのは次のとおりです。

なし・本文・表題・見出し1・見出し2・見出し3・見出し4・見出し5・
引用・註記・ヒント・重要・警告・注意・塊の区切り・塊の中・等幅・塊の題・
説明のリスト・取り込み・チェック・指定の行・横の区切り線・覚え書き

名前を押すと着替えます。本文・表題・見出し1〜5・引用は段落の役割なので、
字を選んでいても段落に掛かります。それ以外の名前は、字を選んでいれば字に、
選んでいなければ段落に掛かります。字を選んでいれば「選んだ字: 名前」の行も
出ます。

その下に、いまのスタイルの中身と、直すボタンが並びます。

[cols="1,2"]
|===
|ボタン |すること

|新しく作る |名前の欄が開きます。名前を決めると、いまのスタイルの中身を写した定義がテンプレートに入り、選んでいる所がその名前を着ます。既にある名前なら、その定義をそのまま着ます
|名前の変更 |いまのスタイルの名前を変えます。テンプレートの節と、本文でその名前を指している段落と字が新しい名前になります。役割の名前(本文・表題・見出し1〜5・引用)は変えられません。既にある名前にはできません
|字を大きく / 字を小さく |大きさを 1pt ずつ動かします(4〜200pt)
|太字 / 斜体 / 下線 |付けたり外したりします
|左 / 中央 / 右 / 両端揃え |揃えを決めます
|行間を広く / 行間を狭く |行間を 0.25 ずつ動かします。1.0 より下には行きません
|後の空きを広く / 後の空きを狭く |段落の後の空きを 2pt ずつ動かします。0 より下には行きません
|===

**直すとテンプレートが書き替わり、同じスタイルの所が一度に変わります。**
書き先は開いている文書の隣のテンプレートです。配られたテンプレート
(`~/.config/officework/templates/` の物・この機械の標準・同梱の既定)を
着ているときは、文書の隣に写しを作って写しを直します。状態行で
「この文書だけの写しを … に作りました」と言います。
まだ保存していない文書では書けません。状態行で「先に保存してください」と
言います。
1か所だけ変えたいときは、右パネルの「設定」で直してください。

== この面が出ないとき

**この道具で作った文書(adoc)のときだけ出ます。** docx や xlsx を開いて
いるときは、柱にスタイルの絵が並びません。互換の文書にはテンプレートが
無いので、押しても見せる物がないためです。
