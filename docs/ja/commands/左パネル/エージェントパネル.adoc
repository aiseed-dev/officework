== プログラムから

このパネルを開く呼び方はありません。画面での会話だからです。

プログラムから AI を使いたいときは、自分で呼びます。
文書を読む・書く所は officework が受け持ちます。

[source,python]
----
from officework import doc

d = doc.Doc.open("報告書.docx")
moto = d.paragraphs[0].text          # AI に渡す文
# …ここで自分の使っている AI を呼びます…
d.paragraphs[0].text = naoshita      # 返ってきた文を入れる
d.save("報告書.docx")
----
