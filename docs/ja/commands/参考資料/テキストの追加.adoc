= テキストの追加

参考資料にあります。

*状態: 実装済み* — いま使えます

== 何をするか

カーソルのある段落を、目次に入れる見出しにします。

押すたびに、見出し1 → 見出し2 → 見出し3 → 本文 と回ります。
いま本文なら、見出し1になります。

入れたあとは link:目次の更新.adoc[目次の更新]を押すと、目次に出ます。
