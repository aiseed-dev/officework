= 脚注

参考資料にあります。

*状態: 実装済み* — いま使えます

== 何をするか

ページの下に注を付けます。

字を選んでいないときは、カーソルの所に脚注の印を入れ、注の文を打つ欄を開きます。
Enter で注の文が入ります。
Esc で閉じると、印は残り、注は空のままです。
Ctrl+Z 一回で印ごと消えます。

字を選んでいるときは、選んだ字を注の文へ移し、跡に印を置きます。
段落をまたいで選んでいるときは、そう言って何もしません。

注の番号は、本文に出てくる順で自動で付きます。

== ダイアログ

注の文を打つ欄が出ます(字を選んでいないときだけ)。
Enter を押すと、打った文が注になります。
Esc を押すと閉じます。印は残ります。
