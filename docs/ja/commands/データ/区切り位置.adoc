= 区切り位置

データにあります。

*状態: 実装済み* — いま使えます

== 何をするか

1つのセルの字を、区切りで分けて隣の列に配ります。

== ダイアログ

区切り文字を打つ欄が1つ出ます。複数の文字を入れられます。

**欄はこれだけ**です。Excel は3段のウィザードで、次を選べます。

. 元のデータの形式 — 区切り文字付き / *固定幅*
. 区切り文字 — タブ・セミコロン・コンマ・スペース・その他
. 列のデータ形式 — 列ごとに G/標準・文字列・日付 など

**固定幅で切る形と、列ごとの形式の指定はありません。**

列ごとの形式が要らないのは、*割った結果を字のまま置く*ためです。
`090-1234-5678` を `-` で割っても `090` のままで、頭の 0 は落ちません。
郵便番号も同じです。

== プログラムから

専用の呼び方はありません。こう書けば同じことができます。

[source,python]
----
s['B2'], s['C2'] = s['A2'].split(',')
----
