= テキストからデータ

データにあります。

*状態: 実装済み* — いま使えます

== 何をするか

テキストや CSV のファイルを読み込み、いまのシートに置きます。

== ダイアログ

まずファイルを選ぶ画面が出ます。選ぶと、読み方を選ぶパネルが出ます。
変えるたびに読み直すので、結果を見ながら決められます。

[cols="1,2"]
|===
|欄 |選べるもの

|文字コード |自動・UTF-8・Shift_JIS(CP932)・Latin-1
|区切り |自動・カンマ・タブ・セミコロン・コロン・空白・その他(1文字を打ちます)
|置き場 |読んだ表を置く左上のセルです
|===
