= 小計

データにあります。

*状態: 実装済み* — いま使えます

== 何をするか

同じ値のかたまりごとに、集計の行を挟みます。最後に総計の行を足します。

見出しの行を含めて範囲を選んでから押します。先に並べ替えておくと、かたまりがまとまります。

== ダイアログ

3つ順に聞かれます。

* *グループ化する列* — 見出しの名前を打ちます。状態行に見出しの一覧が出ます
* *集計する列* — 見出しの名前をカンマ区切りで打ちます。空のまま Enter を押すと、数の入っている列を全部集計します
* *集計方法* — 一覧から選びます。合計・平均・個数・最大・最小 の5つです

集計の行には選んだ関数の数式が入ります(合計なら `=SUM(範囲)`、平均なら `=AVERAGE(範囲)`)。総計の行は、合計なら小計の行を足す数式、それ以外なら明細の範囲を全部並べて同じ関数に掛ける数式です。

明細の行だけがグループ化されます。「詳細の非表示」で閉じると、集計の行と総計の行だけが残ります。全部まとめて Ctrl+Z の1手で戻せます。

**グループは1つだけ**です。Excel のように小計の中にさらに小計を作る、
多段の形はありません。

== プログラムから

専用の呼び方はありません。こう書けば同じことができます。

[source,python]
----
s['A9'] = '=SUBTOTAL(9,A2:A8)'
----
