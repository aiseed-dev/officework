= データテーブル

データにあります。

*状態: 実装済み* — いま使えます

== 何をするか

入力値を差し替えながら式の答えを求めて、表に埋めます。感度を見るための表です。

四角い範囲を選んでから押します。

表の形は Excel と同じです。

[cols="1,2"]
|===
|変数の数 |表の形

|1変数 |左の列に入力値、上の行に式、角は空
|2変数 |角に式、左の列と上の行に入力値
|===

計算はブックの複製の上で行うので、本物の入力セルは荒れません。

*埋まるのはその時の値です。* 入力を直したら、もう一度押してください。

== ダイアログ

2つを順に聞きます。

. 列の入力セル
. 行の入力セル。空のまま Enter を押すと1変数になります
