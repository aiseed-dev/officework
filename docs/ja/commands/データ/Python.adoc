== 何をするか

Python の1行を打って、その場で走らせます。

走るのはサンドボックスの中です。結果は1手として入り、Ctrl+Z で戻せます。

== ダイアログ

打つ欄が出ます。

[cols="1,2"]
|===
|打つもの |起きること

|Python の1行 |その場で走ります
|空のまま Enter |マクロの link:../マクロ/一覧.adoc[一覧]が開きます
|`@計算` |ブックを計算し直します
|===

*走らせられるのは置き場の .py だけです。* ここからファイルを選んで走らせることはできません。
外から受け取った物は、置き場に置いてから一覧で選びます。
