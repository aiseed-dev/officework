= データの入力規則

データにあります。

*状態: 実装済み* — いま使えます

== 何をするか

セルに入れてよい値を決めます。外れた値は止めます。

== ダイアログ

3つのタブがあります。**設定 / メッセージを入力 / エラー警告** です。

=== 設定

*許可* から5つのうち1つを選びます。

* すべての値
* 整数
* 小数
* リスト
* 文字列の長さ

「すべての値」以外を選ぶと、*データ* の比べ方を8つから選びます。

* 次の値の間
* 次の値の間以外
* 次の値に等しい
* 次の値に等しくない
* 次の値より大きい
* 次の値より小さい
* 次の値より大きいか等しい
* 次の値より小さいか等しい

*空白を無視* のチェックがあります。既定は入っています。

「リスト」を選んだときは *元の値* に、候補を直に書くか(`甲,乙,丙`)、
範囲を参照します(`=D2:D5`)。*セルの ▾ を出さない* のチェックも選べます。

=== メッセージを入力

セルを選んだときに出す *タイトル* と *メッセージ* を打ちます。

=== エラー警告

外れた値を入れたときの *スタイル* を3つから選び、
*タイトル* と *エラーメッセージ* を打ちます。

* 停止
* 警告
* 情報

**日付・時刻・カスタムは、この画面では選べません。** xlsx に入っていれば
そのまま残しますが、ここからは作れません。

**「情報」は Excel では「重要」です。** 同じものを指しますが、
Excel のヘルプで探すときは向こうの名前で引いてください。
