= ゴールシーク

データにあります。

*状態: 実装済み* — いま使えます

== 何をするか

式の答えが目標の値になるように、もとになるセルの値を逆に求めます。

== ダイアログ

2回に分けて聞きます。

[cols="1,2"]
|===
|欄 |入れるもの

|目標のセル=目標の値 |式の入ったセルと、そのセルにいくつになってほしいかを、`D6=765600` のように1つの欄に打ちます
|変えるセル |値を動かしてよいセルです(`B3` のように打ちます)
|===

答えが見つかると、変えるセルに値が入ります。見つからないときは、状態行にそう出ます。
