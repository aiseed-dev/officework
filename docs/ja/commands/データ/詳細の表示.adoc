== 何をするか

link:グループ化.adoc[グループ化]で閉じた行や列を開いて、明細を出します。

行の見出しを選んで押すと行に、列の見出しを選んで押すと列に効きます。

閉じた状態は xlsx に残ります。閉じた台帳は閉じたまま次の人に渡ります。
閉じた行と列は印刷(PDF)にも出ません。

かたまりの直後の見出しに出る +/− の丸印を押しても、同じことができます。
