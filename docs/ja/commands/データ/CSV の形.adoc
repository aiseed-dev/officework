== 何をするか

CSV を読み書きするときの区切りと文字コードを決めます。

書き出しは「ファイル > エクスポート > CSV」で使います。
読み込みは「ファイル > 開く」で `.csv` を選んだときに使います。

読み込んだ CSV は、値だけの新しいブックになります。シートの名前はファイル名です。
数に見える字は数として入ります。
開いたブックにはファイルの道を持たせません。Ctrl+S で CSV に上書きすることはありません。残すときは「名前を付けて保存」で xlsx か adoc にします。

選んだ文字コードで読めないときは、状態行に「この CSV は(形)では読めません」と出ます。
別の形を選んで、開き直してください。自動判定はしません。

== ダイアログ

形式を6つから選びます。

[cols="1,2"]
|===
|選べる値 |区切り

|UTF-8(BOM付き) |カンマ(*既定*)
|Shift_JIS(CP932) |カンマ
|UTF-8(BOMなし) |カンマ
|UTF-8(BOM付き) |タブ
|Shift_JIS(CP932) |タブ
|UTF-8(BOM付き) |セミコロン
|===

読み込みと書き出しで同じ6組を使います。
読み込みでは「UTF-8(BOM付き)」と「UTF-8(BOMなし)」は同じ読み方です。先頭に BOM があれば外します。
**列の型の指定はありません。** Excel は読み込むときに
「テキスト インポート ウィザード」の3段目で列ごとの形式を選べますが、
ここにはその画面がありません。文字コードや区切りを見ながら取り込むときは、データタブの「テキストからデータ」を使います。

**Excel とは既定が違います。** ここは UTF-8(BOM付き)から始まります。
Excel で「CSV (コンマ区切り)」を選ぶと、日本語版では Shift_JIS になります。
Excel 側で UTF-8 にしたいときは「CSV UTF-8」の形式を選んでください。
