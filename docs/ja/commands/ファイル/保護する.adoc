= 保護する

ファイルにあります。

*状態: 実装済み* — いま使えます

== 何をするか

文書やブックを、決めた操作しかできない形にします。

== 文章の画面では

保護タブの link:../保護/保護.adoc[保護]と同じです。
保護の種類を一覧から選びます。

* 保護しない
* 読み取り専用
* コメントだけ
* 変更履歴つきの編集だけ
* 記入欄の記入だけ

それぞれで何ができるかは、link:../保護/保護.adoc[保護]の頁にあります。

== 表の画面では

読み取り専用にします。記入欄だけ書ける形にして配れます。

=== ダイアログ

押して入切するチェックの一覧が、14 個出ます。

* 図形・画像の操作
* ロックされたセルの選択
* ロックされていないセルの選択
* セルの書式設定
* 列の書式設定
* 行の書式設定
* 列の挿入
* 行の挿入
* ハイパーリンクの挿入
* 列の削除
* 行の削除
* 並べ替え
* オートフィルターの使用
* ピボットテーブルの使用

**保護していないときは効きません。** 先に保護を掛けてください。
