== 何をするか

新しい文書の書体と大きさが、どこから決まっているかを見せます。

3段が上から順に並び、下の段ほど強く効きます。

[cols="1,2"]
|===
|段 |どこの決めか

|この文書 |いま開いている文書が持っている書体
|フォルダ |文書と同じフォルダに置いたテンプレート
|この機械 |`~/.config/officework/` に置いたテンプレート
|===

どこにも無い段は「指定なし」と出ます。
3段を重ねた結果として、いま実際に使っている書体と大きさも下に出ます。

「この機械の書体を選ぶ」を押すと、3段目を決められます。

言語ごとに本文の大きさの既定が違います。詳しくは
link:../../python-manual.adoc[Python の手引き]の「言語と既定の書式」にあります。

[source,python]
----
