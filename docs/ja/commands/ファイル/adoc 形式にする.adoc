= adoc 形式にする

ファイルにあります。
画面のボタンは「adoc 形式にする(本文と書式を分ける)」と出ています。

*状態: 実装済み* — いま使えます

== 何をするか

docx を、本文(`文書.adoc`)と書式(`文書.toml`)に分けます。*元に戻せません*。

2つとも元の docx の隣に書きます。名前は docx の名前から取ります。
本文の頭に `:template: 文書` が入り、隣の `文書.toml` を使います。
押した後は保存先が `文書.adoc` になり、Ctrl+S は元の docx を上書きしません。
元の docx はそのまま残ります。

`文書.adoc` が既にあるときは書きません。状態行で「既にあるので、保存すると
上書きします」と言います。まだ保存していない docx では、ファイルは書けません。
状態行で「先に保存してください」と言います。

段落ごとの書式に収まらない所(1語だけ色が違う、など)は落ちます。
その数を状態行で言います。
