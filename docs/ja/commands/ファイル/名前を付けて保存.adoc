= 名前を付けて保存

ファイルのページにあります。キーは `Ctrl+Shift+S` か `F12` です。

*状態: 実装済み* — いま使えます

== 何をするか

名前と場所を決めて保存します。*保存した先が、以後の保存先になります。*

書き戻すときに何が残って何が失われるかは link:保存.adoc[保存]と同じです。
docx で開いたものを docx で保存し直しても、元のファイルと同じ物には戻りません。

== ダイアログ

保存先を決める画面が出ます。選べる種類は次のとおりです。

[cols="1,2"]
|===
|種類 |拡張子

|officework の文書 |`.adoc`
|Word 文書 |`.docx`
|===

*拡張子で形が決まります。* `.adoc` を選べば AsciiDoc、`.docx` を選べば Word 文書になります。

== プログラムから

[source,python]
----
d.save("別の名前.docx")
----
