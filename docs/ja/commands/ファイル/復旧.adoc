= 復旧

ファイルにあります。

*状態: 実装済み* — いま使えます

== 何をするか

前に保存できずに終わったときの控えを開きます。控えが無いときは、そう出ます。

== ダイアログ

控えの一覧が出ます。押すと、その控えを開きます。
開いた物には元のファイルの場所を持たせません。
中身を確かめてから「名前を付けて保存」してください。

一覧の下に「壊れたまま拾って開く(読み取り専用)」があります。
押すとファイルを選ぶ窓が出ます。
選んだファイルから、読める字だけを拾って開きます。
docx なら、本文の部品(`word/document.xml`)の段落の字を拾います。書式・表の枠・画像は拾いません。
それ以外のファイルは、文字として読める行を拾います。
読める字が1つも無いときは、そう言って何もしません。

拾って開いた文書は読み取り専用です。直すときは、保護タブの「保護」で「保護しない」を選びます。
**拾って開いたものを保存しても、元のファイルは上書きしません。** 保存は「名前を付けて保存」になります。
何段落を拾ったかは状態行に出ます。
