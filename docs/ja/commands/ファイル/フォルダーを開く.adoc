= フォルダーを開く

ファイルのページにあります。

*状態: 実装済み* — いま使えます

== 何をするか

仕事のフォルダを開き直します。

**フォルダが綴りです。** 中の文書・表・見た目のテンプレートが、まとめて1つの仕事になります。
開くと、*右の一覧*にフォルダの中身が出ます。

**そのフォルダの `.venv` が、Python の第一候補になります。**
同じフォルダを JupyterLab やエディタでも開いているとき、3つとも同じ
Python を使います。マクロもセル関数も、その `.venv` に入れたものが効きます。

**次に起動したときに戻るのは、開いていたファイルの置き場です。**
ファイルを1つも開かずにフォルダだけ選んだときは、そのフォルダは
覚えていません。

== ダイアログ

フォルダを選ぶ画面が出ます。ファイルは選びません。

開いた後、一覧から押したものが編集画面に出ます。
**この道具で開けない種類(`.ipynb` `.py` など)は、その機械で
結び付けてある道具が開きます。** `.ipynb` なら JupyterLab、というように
機械の決めをそのまま使います。開ける道具が無いときは、そう言います。

== プログラムから

(専用の呼び方はありません)

プログラムはフォルダを開く必要がありません。径路を直に書けます。

[source,python]
----
from pathlib import Path
for p in Path("仕事のフォルダ").glob("*.adoc"):
    ...
----
