= URLを開く

ファイルのページにあります。

*状態: 廃止予定* — *なくす予定です。* 「開く」に混ぜます。

== 何をするか

`http://` か `https://` の住所を打って、その先の HTML を読みます。
読んだページは紙面に組まれ、記入欄があれば書き込んで送れます。

== ダイアログ

住所を打つ欄が出ます。

== なくす理由

「開く」と分ける理由がありません。
*径路か住所かは、打った字を見れば分かります。*
1つの入り口にまとめたほうが、探す場所が減ります。

*なくすのは、「開く」が住所を受け取れるようになってからです。*
いまの「開く」はファイルを選ぶ窓しか出しません。
この頁のボタンが無くなっても、住所からページを開く機能そのものは残ります。
