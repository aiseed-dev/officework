= URLを開く

ファイルのページにあります。

*状態: 廃止予定* — *なくす予定です。* 「開く」に混ぜます。

== 何をするか

`http://` か `https://` の住所を打って、その先の HTML を読みます。
読んだページは紙面に組まれ、記入欄があれば書き込んで送れます。

== ダイアログ

住所を打つ欄が出ます。

== なくす理由

「開く」と分ける理由がありません。
*径路か住所かは、打った字を見れば分かります。*
1つの入り口にまとめたほうが、探す場所が減ります。

なくした後も、**この機能は無くなりません** — 「開く」に住所を打ってください。
