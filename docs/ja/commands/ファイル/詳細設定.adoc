== 何をするか

設定の画面を、ファイルのページの右側に出します。

言葉・画面の文字の大きさ・コメントの作成者などを決めます。

表では、「AI の宛先」の行に、いま使う宛先の名前が出ます。
宛先は `~/.config/officework/settings.toml` の `\[[ai]]` に並べた物です。
左パネルの会話の欄の下に出る宛先と同じ物です。
押すと、次の宛先に替わります。
宛先が1つだけなら、替える先が無いと状態行に出ます。
一覧が空なら、`\[[ai]]` を書く案内が出ます。
