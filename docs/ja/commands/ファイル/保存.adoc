= 保存

ファイルのページと、窓の上の段にあります。キーは `Ctrl+S` です。

*状態: 実装済み* — いま使えます

== 何をするか

開いたファイルに書き戻します。
*ファイルの形式は変わりません* — docx で開いたものは docx で保存します。

**元のファイルとそっくり同じには戻りません。** docx を開くと、本文はこの
アプリの持ち方に移し替えます。保存するときは、その持ち方から docx を
組み直します。スタイル定義や画像などの部品は元のファイルから持ち越し
ますが、*本文に入っていて読めなかったものは戻りません*。

戻らないものは、この版では次のとおりです。

[cols="1,2"]
|===
|もの |どうなるか

|変更履歴 |*確定されます。* 直した跡は残らず、直した後の姿だけが残ります
|しおり |段落の外にあるものは失われます
|脚注・文末脚注の印 |段落の外にあるものと、id の無いものは失われます
|画像・図形 |ほとんどは残ります。中に書いてある名前が解けないものだけ失われます
|数式 |同じく、名前が解けないものだけ失われます
|===

開いている文書で何が読めなかったかは、右クリックの
link:../右クリック/この版で読み飛ばしたもの.adoc[この版で読み飛ばしたもの]
で見られます。ここに何か出ている文書を保存するときは、画面の下にも
「読めなかった要素は本文に戻りません」と出ます。

**大事な docx は、写しを取ってから開いてください。**

== ダイアログ

出ません。名前を決めたいときは「名前を付けて保存」を使います。

保存できないときは、画面の下に理由が出ます。
同じファイルを他の人が開いていると、上書きせずに止めます。

== プログラムから

[source,python]
----
d.save("報告書.docx")
b.save("売上.xlsx")
----
