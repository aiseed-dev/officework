= チェックボックス

フォームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

`☐` と `☑` を切り替える記入欄を置きます。

すでにチェックボックスの中にカーソルがあるときは、*その場で切り替えます*。
空白キーでも切り替わります(空白の字は入りません)。
新しく置きたいときは、欄の外にカーソルを出してから押してください。

docx には Word のチェックボックス(`w14:checkbox`)として入ります。
Word で開いても、うちで開き直しても、チェックボックスのままです。
入っているかどうかは欄の字(`☑`)で決まります。

保護タブの「保護」で「記入欄の記入だけ」を選ぶと、本文は変えられなくなり、この切り替えだけができます。
