= 複合フィールド

フォームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

住所のように、いくつかの部分でできている項目のための記入欄を置きます。

この版では、link:テキストフィールド.adoc[テキストフィールド]と同じ、字を書き込む欄です。
部分ごとに分けて記入する仕組みはまだありません。
docx には `jo:complex` の印(`w:tag`)を付けた文字の欄として入ります。
うちで開き直すと複合フィールドに戻ります。
