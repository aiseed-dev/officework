= ドロップダウン

フォームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選ぶだけの記入欄を置きます。打ち足すことはできません。
欄の中で字を打つと、打った字は入らず、状態行でそう言います。

link:コンボボックス.adoc[コンボボックス]との違いはそこだけです。
選択肢の決め方も、押すたびに次へ回るところも同じです。

保護タブの「保護」で「記入欄の記入だけ」を選ぶと、本文は変えられなくなり、選択肢を回すことだけができます。

== ダイアログ

選択肢をカンマ区切りで打つ欄が出ます。例: `赤,青,黄`

== プログラムから

[source,python]
----
mcp.doc_fill({名前: 値})
----
