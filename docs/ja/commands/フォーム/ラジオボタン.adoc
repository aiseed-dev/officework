= ラジオボタン

フォームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

選択肢を1つだけ選ぶ欄を置きます。

見た目と切り替え方は link:チェックボックス.adoc[チェックボックス]と同じです。
同じボタンか空白キーで `☐` と `☑` が切り替わります。

「同じ組では1つしか選べない」という決まりはまだ効きません。
組で1つに絞りたいときは、マクロで書いてください。

Word にはラジオボタンの部品がありません。
docx には Word のチェックボックス(`w14:checkbox`)として入り、`jo:radio` の印(`w:tag`)で種類を残します。
Word ではチェックボックスに見えます。
うちで開き直すとラジオボタンに戻ります。

保護タブの「保護」で「記入欄の記入だけ」を選ぶと、本文は変えられなくなり、この切り替えだけができます。
