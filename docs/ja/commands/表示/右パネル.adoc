= 右パネル

表示にあります。

*状態: 実装済み* — いま使えます

== 何をするか

画面の右にパネルを出します。もう一度押すと閉じます。

パネルの右端に柱があり、絵を押すと中身が入れ替わります。

文書(writer)では4つあります。

[cols="1,2"]
|===
|中身 |すること

|link:../右パネル/設定.adoc[設定] |カーソルのある場所の書式を変えます
|link:../右パネル/ページ設定.adoc[ページ設定] |文書全体の紙の決めを変えます
|link:../右パネル/スタイル.adoc[スタイル] |いまの段落のスタイルを選びます(adoc のときだけ)
|link:../右パネル/プロジェクトパネル.adoc[プロジェクトパネル] |フォルダの中のファイルを扱います
|===

表(calc)では3つです。

[cols="1,2"]
|===
|中身 |すること

|セルの設定 |カーソルのあるセルの書式を変えます
|図形と画像 |選んでいる図形や画像の大きさと位置を変えます
|link:../右パネル/プロジェクトパネル.adoc[プロジェクトパネル] |フォルダの中のファイルを扱います
|===

表にはページ設定とスタイルの画面はありません。紙の決めはリボンのレイアウトから変えます。

== ダイアログ

(ダイアログは出ません)

== プログラムから

パネルを出す呼び方はありません。画面の表示だからです。
中身のうち、文書を変える所はそれぞれの頁に書き方があります。
