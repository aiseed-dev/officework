== 何をするか

画面の下に端末(シェル)のパネルを出します。もう一度押すと閉じます。閉じてもシェルは終わらず、次に開くと続きから使えます。

シェルは開いているファイルのフォルダで始まります。この機械の普通のシェル(Linux と macOS は `$SHELL`、Windows は PowerShell)です。

パネルを押すと打鍵が端末へ行きます。文書や表に戻るには、本文を押します。

貼り付けは Ctrl+Shift+V です。マウスのホイールで前の出力をさかのぼれます。

Python から officework を操るときは、ここで `python` を起こして `from officework import calc as xw` のように使えます。AI の道具(`claude` など)もここで動かせます。
