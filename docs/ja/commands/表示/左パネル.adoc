= 左パネル

表示にあります。

*状態: 実装済み* — いま使えます

== 何をするか

画面の左にパネルを出します。もう一度押すと閉じます。

パネルの左端に柱があり、絵を押すと中身が入れ替わります。4つあります。

[cols="1,2"]
|===
|中身 |すること

|link:../左パネル/見出し.adoc[見出し] |文書の見出しを並べます。押すとそこへ飛びます
|link:../左パネル/コメント.adoc[コメント] |文書に付いたコメントを並べます
|link:../左パネル/検索.adoc[検索] |字を探して、置き換えます
|link:../左パネル/エージェントパネル.adoc[エージェントパネル] |選んだところについて AI に聞けます
|===

== ダイアログ

(ダイアログは出ません)

== プログラムから

パネルを出す呼び方はありません。画面の表示だからです。
中身のうち、文書を読む所はそれぞれの頁に書き方があります。
