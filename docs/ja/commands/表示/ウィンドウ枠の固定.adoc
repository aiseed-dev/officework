= ウィンドウ枠の固定

表示にあります。

*状態: 実装済み* — いま使えます

== 何をするか

見出しの行や列を、画面を動かしても残します。

== ダイアログ

一覧から選びます。

[cols="1,2"]
|===
|項目 |すること

|いまの位置で固定(上と左が留まる) |カーソルの上の行と左の列を留めます
|最上行の固定 |1行目だけを留めます
|最初の列の固定 |A 列だけを留めます
|固定した枠に影を付ける |留めた所の境に影を出します。押すたびに入切します
|===

固定しているときは、一覧の先頭に「固定の解除」が出ます。

== プログラムから

----
s.freeze_panes
----
