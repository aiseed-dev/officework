== 何をするか

`~/.config/officework/plugins` に置いた .py を並べて、選ぶと走ります。

走るのはサンドボックス(bubblewrap)の中です。
文書やブックの複製の上で動き、成功したら結果が1手として入ります。
Ctrl+Z 一回で戻せます。

置き場に .py が1つも無いときは、その置き場の場所を状態行で言います。

*走らせられるのは、この置き場の .py だけです。*
外から受け取った .py は、置き場に置いてから一覧で選びます。
置く手が1つ挟まるのが、読んでから走らせるための仕組みです。

== ダイアログ

置き場の .py が名前で並びます。選ぶと走ります。Esc で閉じます。
