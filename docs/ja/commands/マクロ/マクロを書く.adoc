= マクロを書く

マクロにあります。

*状態: 実装済み* — いま使えます

== 何をするか

やりたいことを言葉で書くと、AI がマクロの .py を書きます。

*答えは文書には入りません。* マクロの置き場に .py として置かれます。
読んで確かめてから、link:一覧.adoc[一覧]で選んで実行してください。
自動では走りません。

宛先は ファイル > 詳細設定 の「AI の宛先」で選びます。
使えない宛先のときは、その場で理由を言います。

== ダイアログ
