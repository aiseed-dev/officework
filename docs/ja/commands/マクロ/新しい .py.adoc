== 何をするか

式から呼ぶ関数(UDF)の下書きを作って、編集の道具で開きます。

置き場は `~/.config/officework/funcs` です。
名前は `新しい道具1.py`、`新しい道具2.py` と、空いている番号が付きます。

*マクロの置き場とは別です。* こちらに置いた関数は、`=関数名(…)` として式から呼べます。
式から呼べる物は、人が押さなくても再計算のたびに走ります。
ブックは関数の名前を運ぶので、受け取ったブックを開くとこちらの .py が走ります。
だから、式から呼ばれてよい物だけをこの置き場に置きます。
