= 操作を記録

マクロにあります。

*状態: 実装済み* — いま使えます

== 何をするか

押すと記録が始まり、もう一度押すと止まります。
その間の操作が Python のスクリプトになります。

書き出す先は *記録の置き場* `~/.config/officework/records` です。
名前は `記録1.py`、`記録2.py` と、空いている番号が付きます。
書けたら、その機械の編集の道具で開きます。行数も状態行に出ます。

*マクロの置き場とは分けてあります。* 記録は下書きで、マクロは これでよいと決めた物です。
同じ置き場に落とすと、読む前・直す前のスクリプトが link:一覧.adoc[一覧]に並んでしまいます。
使うと決めたら、自分で `plugins` へ移してください。
