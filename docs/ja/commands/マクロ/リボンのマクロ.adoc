= リボンのマクロ

マクロにあります。

*状態: 実装済み* — いま使えます

== 何をするか

自分のマクロを、リボンのボタンとして出します。

置き場は `~/.config/officework/ribbon` です。
ここの .py には、ラベル・アイコン・タブの3つを書きます。
link:一覧.adoc[一覧]の .py と違って、この3つを書く必要があります。

* *ラベル* は、ボタンに出る言葉です。訳しません
* *アイコン* は、アイコンの名前です。知らない名前を書くと、既定のアイコンになります
* *タブ* は、どのタブに出すかです。省くと「マクロ」に入ります

この宣言は読むだけで、走らせません。ボタンを押したときに初めて走ります。

== ダイアログ

3段に分かれた一覧が出ます。

. 宣言したマクロ
. 「見本を作る」。手で書かなくても、ここから始められます
. 同梱のスクリプト(読むだけ)。選ぶと控えが開くので、何をしているか読めます

置き場が空でも一覧は出ます。そこから作り始められるようにするためです。
