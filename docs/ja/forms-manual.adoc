= 様式の手引き(データから様式を埋める)
:toc:

_元は英語版(link:../en/forms-manual.adoc[forms-manual.adoc])です。こちらは日本語訳です。_

履歴書、申請書、届出書などの様式を作り、データから埋める人のための手引きです。
様式は、値を入れる所に印を置いたシートか文書です。データは表のブックです。
ここに書いたことは、いまの `officework` でできることだけです。例は、書いたとおりに動かして確かめてあります。

== 2 つのファイル

[cols="1,2,2"]
|===
|ファイル |中身 |書き方

|様式
|埋める紙です。値を入れるセルや段落に `{屋号}` のような印を置きます
|表の様式:`名前.form.adoc`(見た目は `名前.tmpl.adoc`)か、セルに印を打った `.xlsx`。文書の様式:本文に印を打った `.docx`

|データ
|値です。「名前・値」の 2 列の表と、見出しの行がある表を並べます
|表のブック `名前.sheet.adoc`
|===

様式とデータを分けておくと、1 つのデータで何枚もの様式を埋められます。屋号・所在地・代表者を 1 回書けば、それを聞くどの申請書も埋まります。

== 印

印は、値を入れる所に書く、中括弧で囲んだ名前です。
1 つのセルや段落に、印をいくつ置いてもかまいません。印の外の字はそのまま残ります。

[cols="2,3",options="header"]
|===
|印 |入る値

|`{屋号}`
|データの「名前・値」の表で、屋号の行の値

|`{開業日.年}` `{開業日.月}` `{開業日.日}`
|`2026-10-01`(または `2026/10/1`)と書いた日付の年・月・日

|`{届出日.元号}` `{届出日.和暦年}`
|日付の元号(令和)と、その元号での年(8)。元号の最初の年は「元」と書きます

|`{通勤時間.時間}` `{通勤時間.分}`
|`1時間10分` と書いた値の、「時間」の前の数と「分」の前の数

|`{年齢}`
|データの生年月日と日付から計算した年齢

|`{事業所.2.所在地}`
|表「事業所」の 2 行目(見出しの次から数えます)の、「所在地」の列

|`{本人希望.2}`
|複数の行で書いた値の 2 行目

|`{青色申告:する・しない}`
|選択肢。選択肢を印に書いたとおりに(空白も含めて)出し、データの値と同じ方を丸で囲みます。`する ・ しない` と書けば空白も残ります

|`{区分=開業}`
|チェックボックス。データの「区分」が「開業」なら ■、違えば □ を出します。同じ名前のチェックボックスは、まとめて 1 つの選択肢になります
|===

名前には、`{`、`}`、`.`、`:`、`=` 以外の字を使えます。

== データ

データは表のブックです。表は 2 種類です。

* 「名前・値」の 2 列の表は、名前で印に答えます。`{屋号}` には、屋号の行の値が入ります。
  このような表はいくつあってもかまいません。その名前を持つ最初の表が答えます
* 見出しの行がある表は、行の印に答えます。`{事業所.2.所在地}` には、事業所の 2 行目の「所在地」の列が入ります。
  表の名前は、表の題(`.事業所`)です

日付は `2026-10-01` の形で書きます。複数の行で書く値は、最後の行を除いて、各行の終わりに ` +` を付けます。

|===

|屋号 |みほん商店
|事業の概要 |文房具の小売

|青色申告 |する
|区分 |開業
|===

.事業所
|===

== 埋めたときの決まり

* データが答える印は、その答えに置き換わります
* *データに答えの無い印は空になります。* 様式がデータより多く用意した行は、空のまま残ります
* 名前がデータに 1 つも無いとき(行も表も無いとき)は、書き間違い(「電話」を「電話番号」と書いたなど)とみなします。
  ほかと同じく空にしたうえで、知らせます。`fill` は警告を出し、その名前を `missing` に並べます。
  名前はあって値が空のとき(`|性別 |`)と、表の終わりより先の行は、知らせません
* 選択肢は、選ばれた方を楕円で囲みます。
  囲む位置は組んだページから測ります。楕円はブックや文書の図形として入るので、PDF にも xlsx にも docx にも出ます
* *表の行が様式の行より多いときは、入らなかった行を「別紙」に同じ列で続けて書きます。*
  表の様式では、「別紙」という名前のシートを足します。各列の幅・書式・行の高さは、様式のその列のセルと同じにします。
  文書の様式では、改ページして別紙の表を足します。各列の幅は、様式の表のその列の幅と同じにします。
  別紙には「別紙」、表の名前と「（続き）」、列の見出し、行の順に書きます。
  どの表が別紙に回ったかは `bessi` に (表の名前, 別紙の最初の行, 最後の行) で並びます
* 表の様式の図形は、写真の欄にできます。図形の表の `field` の項目に欄の名前を書きます(`|I3 |field |写真`)。
  データでその名前に書いた画像のファイル(データのファイルと同じフォルダーから探します)を、縦横の比を保って図形の中に置き、図形の中の文字を消します。枠の線は残します

=== 文書の様式では

* Word が書式の区切りで途中から分けた印も、1 つの印として読みます
* 下線を付けた空白の空欄(氏名＿＿＿＿)は、長さを保ちます。空欄の空白を消さずに、頭に印を打ちます(`{氏名}＿＿＿＿`)。
  埋めるときは、答えの幅の分だけ空白を減らします。全角は 2、半角は 1 と数え、下線が続くかぎり後ろの書式の区切りにも進みます。
  空白が足りないときは、下線が足りない分だけ伸びます。
  下線の無い所では空白を減らしません(`{宛名}　様` の空白は残ります)
* 印を埋めるのは、段落、表のセル、テキストボックスです。ヘッダーとフッターは埋めません

== Python から

[source,python]
----
from officework import sheet, doc

# 表の様式
form = sheet.Book.open("開業届.form.adoc")
data = sheet.Book.open("開業データ.sheet.adoc")
b = sheet.Book.fill(form, data)
b.save("開業届.pdf")          # .xlsx と .png にも書き出せます
b.missing                     # データに 1 つも無い名前: []
b.bessi                       # 別紙に回った表: [('事業所', 3, 3)]

# 文書の様式
d = doc.Doc.fill_form(doc.Doc.open("送達場所等の届出.docx"), data)
d.save("届出.pdf")           # .docx にも書き出せます
d.missing
d.bessi

# 欄を直して、もう一度埋める
data.set_field("屋号", "みほん文具店")
b = sheet.Book.fill(form, data)
----

[cols="2,3",options="header"]
|===
|呼び方 |すること

|`sheet.Book.fill(様式, データ)`
|様式にデータを入れた新しいブックを返します。画像はデータのファイルと同じフォルダーから探します。`missing` の名前があれば警告を出します

|`doc.Doc.fill_form(様式, データ)`
|文書の様式で同じことをします。データは `sheet.Book` です

|`b.missing`、`d.missing`
|データに 1 つも無い名前の並び

|`b.bessi`、`d.bessi`
|別紙に回った表。(表の名前, 最初の行, 最後の行) で、行は見出しの次から数えます

|`データ.set_field(名前, 値)`
|データに値を入れます。行の印の名前(`事業所.3.所在地`)なら、その行と列に入れ、足りない行は足します。それ以外の名前は、「名前・値」の表のその名前の行に入れ、無ければ最初のそのような表に行を足します。表に無い列を指したときは、エラーで断ります

|`様式.fields()`
|表の様式で印を持つセルの一覧。(シート, セル, 印の名前の並び)

|`b.draw_list()`、`d.draw_list()`
|ページをデータとして返します(下の節)
|===

== 描画一覧

`draw_list()` は、ページを辞書で返します。ほかの仕組み(Flet の Canvas など)で描くときと、欄の位置を知るときに使います。
`version` は `0.1` です。0.x の間は形が変わることがあります。

[source,json]
----
{
  "version": "0.1",
  "fonts": [{"id": 0, "name": "BIZ UD明朝", "file": "…/BIZUDMincho-Regular.ttf",
             "index": 0, "ascent": 0.88, "descent": 0.12}],
  "missing": [],
  "pages": [{
    "size": [595.28, 841.89],
    "items": [
      {"type": "fill", "rect": [x, y, w, h], "color": "#FFFFFF", "alpha": 1},
      {"type": "line", "from": [x, y], "to": [x, y], "width": 0.75, "color": "#000000", "alpha": 1, "dash": []},
      {"type": "path", "d": [["M", x, y], ["L", x, y], ["C", x1, y1, x2, y2, x, y], ["Z"]],
       "fill": null, "even_odd": false, "stroke": "#000000", "width": 0.75, "dash": [], "alpha": 1, "clip": []},
      {"type": "text", "x": 120.5, "baseline": 210.0, "top": 192.4, "text": "みほん商店",
       "font": 0, "size": 11, "width": 55.0, "color": "#000000", "bold": false},
      {"type": "image", "rect": [x, y, w, h], "mime": "image/jpeg", "base64": "…", "clip": [x, y, w, h]}
    ],
    "fields": [
      {"name": "屋号", "kind": "text", "rect": [x, y, w, h], "value": "みほん商店"},
      {"name": "青色申告", "kind": "choice", "options": ["する", "しない"], "rect": [x, y, w, h], "value": "する"}
    ]
  }]
}
----

* 長さの単位は pt です。原点はページの左上で、y は下向きです
* `items` は描く順に並んでいます。ページの色、塗り、図形と画像(重なりの順)、罫線、文字、文字の上の罫線、透かしの順です
* 文字は、ベースラインの位置と上端(`top`。上端で文字を置く仕組みのため)を持ちます。`width` は組版が決めた幅、`font` は `fonts` の `id` です。
  無いこともある項目:`italic`、`rotation`(度。x とベースラインの点を中心に左回り)、`letter_spacing`(pt)、`scale_x`
* 色は `#RRGGBB`、`alpha` は 0〜1、破線の刻みは pt の長さの並びです
* 画像は、ファイルのバイト列の base64 です(PNG か JPEG)。`rect` へ伸ばして描きます。
  図形を塗る画像は、図形の四角より大きく伸ばすことがあります(docx や xlsx の `a:fillRect`)。そのときは `clip` に図形の四角が入り、その外は描きません。
  `clip` が無ければ切りません
* `fields` は、そのページにある欄です。欄はデータの項目ごとに 1 つです。`{届出日.年}` `{届出日.月}` `{届出日.日}` は、種類 `date` の欄「届出日」1 つになります。`{本人希望.1}`〜`{本人希望.4}` は、種類 `multiline` の欄「本人希望」1 つになります。
  種類は `text`、`multiline`(折り返して全体を表示するセルも)、`date`、`choice`(`options` つき)、`image` です。
  `rect` は、表の様式では欄のセル(結合したセルは結合の範囲)を全部含む四角、文書の様式では答えの字を含む四角です。文書で答えが空のときは、その後ろの 1 字の四角です。
  `value` はデータに書いてある値です(日付は `2026-10-01` の形)。`{年齢}` は計算で出すので欄になりません
* 様式から作った描画一覧は、いちばん上に `missing` を持ちます
