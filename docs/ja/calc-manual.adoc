= calc の手引き

_元は英語版(link:../en/calc-manual.adoc[calc-manual.adoc])です。こちらは日本語訳です。_

officework の表の編集画面の手引き。
ブック(.sheet.adoc)も xlsx も、開いて、直して、保存できます。
式も計算します。

このマニュアルには**いま動くことだけ**を書く。
リボンにグレー表示で並んでいるコマンドは未実装で、押せない(できないものを、できるように見せない)。
グレー表示のものと Python での代替はlink:#未実装のものグレー表示と代替[巻末]に。

3つの約束:

* *書式は据え置き。* 開いた帳票の罫線・結合・列幅・図形・テーマは、保存しても壊れない(理解しない部品は原文のまま持ち越す)
* *どの操作も1手で戻せます。* 迷ったら Ctrl+Z を押してください
* *黙って落としません。* 読めないものと、保存で失われるものは、ステータスバーで言います

== 起動

[source,bash]
----
./target/release/officework            # 前回の姿で開く(初回はフォルダを選ぶ)
./target/release/officework 帳票.xlsx  # ファイルを指定して開く
----

日本語フォントが機械に無いと起動しません(`fonts-noto-cjk` か ``fonts-ipaexfont`` を入れてください。
`OFFICE_FONT=/path/to/font.ttf` で明示も可)。

== 画面

画面の枠はデスクトップ版の形。
**1段目**が保存・印刷・戻す・やり直しとブック名(未保存は \* 印。
この行を掴むと窓が動く)、**2段目**が白地のタブ(現在地は緑の下線。
右端の 🔍 = 検索と置換)。
リボンのボタンは本家と同じで、アイコンボタンが一段に並びます。
主要なボタンにはラベルが付きます。
ボタンに乗ると、名前が下のステータスバーに出ます。
ホームだけが2段です。

*ファイルタブは全面のページ*です。
左にメニューが並びます(新規作成・開く・最近開いた・保存・名前を付けて保存・印刷・保護する・詳細情報・ファイルの場所を開く・終了)。
右は「ブックの情報」で、統計と xlsx の情報(作成者・タイトルなど)が出ます。
欄を押して打ち、Enter で控えます。
保存すると xlsx の docProps に入るので、Excel でも見えます。

*作成者は何人でも書けます。*
「＋ 著者を追加」で1人ずつ足し、名前の右の × で外します。
xlsx では `;` で継いだ1つの欄になります。
Excel の書き方と同じです。

その下のカスタムプロパティは、決まった欄で足りないものを自分で足す所です。
「プロパティを追加」を押すと、名前・型・値の順に訊きます。
型は文字・数・日付・はい/いいえ の4つです。
空のまま Enter を押すと文字になります。
値まで打って初めて足すので、途中でやめれば何も残りません。
外すのは行の × です。
他所で付けた見慣れない型の値も、消さずにそのまま持ち越します。
鎖の印が付いた項目は Excel の「内容にリンク」です。
こちらは繋ぎ直しませんが、外しもしません。

「最近開いた」には12件が残ります。

タブの並びは Euro-Office と同じです。
ファイル・ホーム・挿入・描画・レイアウト・数式・データ・ピボットテーブル・表のデザイン・共同編集・保護・表示・マクロの13です。
このうちマクロは、Euro-Office では「プラグイン」という名前です。

表示タブの*インターフェイステーマ*で、画面を暗くできます。
セルは白のままです。
画面と紙で同じ見え方にするためです。

窓の下端がステータスバーです。
シートタブ、操作の結果、警告、エラーがここに出ます。
範囲を選ぶと、合計・平均・個数もその場で出ます。
保護したシートのタブには 🔒 が付きます。

*表示タブ*は本家のデスクトップ版に合わせてあります。
拡大・縮小は 50〜200% です。
セルも文字も一緒に伸び縮みしますが、紙は変わりません。
数式バーの表示と非表示、枠線表示、見出し(行番号・列名)もここにあります。
見出しを消すと、表だけの見た目になります。
「0を表示する」は 0 の値を隠します。
*見え方だけで、値は 0 のまま*なので、式にも効きます。
枠の固定、シートの表示(隠しシートを戻す・隠す)、インターフェイステーマもここです。

=== マウス

* クリックで選択、ドラッグで範囲選択、Shift+クリックで起点から拡張
* 行番号・列名の見出しをクリックで行・列ごと選択
* 見出しの境界をドラッグで列幅・行高の変更
* ハイパーリンクは Ctrl+クリックで開く
* テキストボックス(と文字を入れた図形)は、選ぶと、図形の設定パネルに「中の文字」の段が出ます。中身は、横の揃え(左/中央/右)、縦の位置(上/中央/下)、箇条書き(なし/・/1.)、縦書き、取り消し線、上付き・下付き。xlsx と往復するので Excel でもそのまま見えます。*タブ位置は無い*(文字を1枚の面で出しているので、位置を守って描けない)
* 図形はドラッグで移動、右下の角で大きさ変更、*枠の上の丸をドラッグで回転*(Shift で15度刻み)。選ぶと右に**図形の設定**のパネル(塗り・線の色と太さ・不透明度・回転/反転・影)。*Ctrl+クリックで複数選択* →右クリック→整列で 揃え(2個から)・分布(3個から)。右クリックには切り貼り・配置(前面/背面)・SVG で保存もできます。Del は選んだ分まとめて削除

== 式と関数

`=` で始めると式。
四則(`+ - * /`)、比較(`= <> > >= < <=`)、範囲(`A1:B3`)、絶対参照(`$A$1`)、定義した名前が使えます。
編集すると自動で再計算され、循環参照は検出してエラーになる(黙らない)。

*串刺し集計*: `=SUM(4月:6月!B2)` で、**ブックの並び順**で2枚の間にある全シートの同じ場所を集める(タブを並べ替えれば集める範囲も変わる)。

*別のシートの参照*: `=4月!B2` のように直接書ける(範囲は `=SUM(4月!B1:B5)`、空白や記号を含む名前は `='4月 実績'!B2`)。
知らないシート名は *#REF!* になります。黙って自分のシートと読むことはしません。
別シートの値は**その時の値を写す**ので、参照先を直したら再計算(F9)で追いつく。
シート名を変えると、式の中の ``古い名前!`` も書き換わります。
ただし `INDIRECT("古い名前!A1")` の文字列の中は追随しません。Excel も同じです。INDIRECT は動かない参照を作る道具だからです。
追随しなかった数は、改名のときに状態行で言います。手で直せます。

実装済みの関数は 403 です(古い名前と新しい名前の両方を含みます)。

エラー(`#N/A` など)は、引数から式へそのまま伝わります。
ただし IFERROR は第1引数のエラーを受けて第2引数に落ち、IF は選ばなかった側のエラーを踏まない(`=IFERROR(VLOOKUP(…),"")` で「見つからない」を空欄にできる)。
知らない関数名は *#NAME?* になります。黙って 0 と計算することはありません。

これに加えて、*`=PY(…)` で自分の関数を Python で書けます。* link:#セル関数を-python-で書く-pyudf[Python の章]をご覧ください。

数式タブの道具: オートSUM、*関数の挿入*(分類 → 関数)、分類別の関数一覧、*計算方法*(自動 ⇔ 手動。
手動は大きな表で待たされない)、*ウォッチウィンドウ*(選んだ式のセルを見張り、値を下のステータスバーに出す)、名前の管理、参照元・参照先のトレース(いまのセルと該当セルの間に矢印を引きます。
「トレース矢印の削除」で消える)、数式の表示。

*名前の定義*: 選択してホーム(または数式)の「名前の定義」。
名前は英数字と `_`(先頭は文字。
セル参照の形は不可)。
式の中で使えます。

== 書式

* 文字: 太字・斜体・下線・取り消し線・*下付き*・文字色・書体・大きさ
* *書体の欄はコンボ*: 押すと一覧が開き、開いた時は今の書体の位置にあります。打つほど絞られ(日本語名でも英語名でも引ける)、↑↓で選び Enter で確定、Esc で閉じます。一覧の各項はその書体で描くので、見た目で選べます。一覧の頭には、最近使った書体が出ます。一覧に無い書体名も打って確定できる(リボンの書体一覧は**この機械にあるフォント**)
* *大きさの欄もコンボ*: 一覧は 6〜72pt の17段。自由に数を打つと4〜409pt・0.5 刻みに**黙って丸めて**掛かる(丸めは画面の入力だけ —よそで作った半端な大きさはそのまま往復する)。*大きく/小さく*(+/−)は一覧の値を1段ずつ辿る(半端な大きさは隣の一覧値へ寄り、端では止まる)
* セル: 塗りつぶし(単色のほかに柄6種とグラデーション4向き。塗りのパレットの下にあります。*色を選ぶとべた塗りに戻る*。柄の地の色は「柄の地の色…」で。Excel の柄は 18 種あり読み書きはどれも通るが、画面で描き分けられない柄(横線・縦線など)は一覧に出していない —そういう帳票を開いたときは濃さで見せる)、罫線(上下左右を独立に)、縦横の揃え(**両端揃え**を含む)、折り返し、*文字の向き*(一覧から 角度なし / 左上がり45度 / 右下がり45度 / 上向き90度 / 下向き90度 / 縦書き を選びます。日本の帳票の縦の見出しに)
* *図形の足し引き*: 2つ選んで(Ctrl+クリック)右クリック→「図形を結合」から結合・交差・減算。減算は**主(先に選んだ方)から控えを引く**。中を抜くと穴のあいた形になります。*結果は自由な形になり、元の形と回転は戻りません*(押したときにそう出ます)。輪郭を点で取れない形(吹き出しなど)は断ります
* *ポイントの編集*: 点で作る図形(自由な形・ペンの線・スパークライン)は、右クリック→「ポイントの編集」で頂点をつまんで動かせます。Ctrl+クリックで頂点の追加と削除、ダブルクリックで角と曲線の切り替えができます。曲線にすると制御点の丸が出て、つまむと曲がり方が変わります。自由な形は 挿入→図形→線→「自由な形(点で作る)」から。xlsx にベジェのまま残るので Excel でも曲線
* *スパークライン*: 選ぶと図形の設定パネルで色・線の太さのほか、*点の印*(高点・低点・最初・最後)を入切できます。空セルの扱いと縦軸のそろえはありません。この線は挿したときの数を焼き付けているので、元データを引き直す設定は掛かりません(パネルにもそう出ます)
* *コメント*: 右クリックから「コメントを追加」を押します。付いたセルを右クリックすると、「返信を追加」と「解決済みにする」が押せます(コメントの無いセルでは灰色です)。返信も解決の印も xlsx に残るので、Excel でもスレッドとして見えます。誰がいつ書いたかも往復します
* *右横書き*(ホーム): セルの中を1字ずつ右から並べます。*日本語の右横書き*(昔の看板や横額)のための機能です。ラテン文字の双方向(bidi)は扱いません
* *シートの方向*(レイアウト): 列を右から左へ並べる(右横書きの帳面)
* *セルのスタイル*(ホーム): 見出し・表題・良い/悪い/どちらでもない・メモ・計算・通貨・パーセント。選ぶと選択に書式が掛かる(Ctrl+Z で戻る)
* *テーマ色*: 今どきの Excel は色を「テーマの何番目 + 明るさの加減」で持つことがあります。それを読んで実際の色に解くので、*色が消えない*。*配色の変更*(レイアウト)で色の組(Office / 暖色 / 寒色 / 墨)を入れ替えると、テーマ色を使っているセルの色が**そのまま追従する*
* 表示形式: 桁区切り・小数桁の増減・% ・通貨
* セル結合(左上以外の値は消えます。隠れた値が SUM に効かないようにするためです。Ctrl+Z で戻せます)
* *消去*(ホーム): 一覧から すべて / 書式 / 数式と値 / コメント を選びます。BackSpace と Delete は「数式と値」と同じです
* *オートSUM*(ホーム): 範囲を選んで押すと、その下(横1行なら右)に =SUM の式を置きます。1セルだけなら、上に続く数を対象にした式が入ります
* *フィル*(ホーム): 上に並ぶ数が連続していれば続きの数を埋めます(1つだけなら 1 ずつ)。文字と式は写します。Ctrl+D はいつも写します
* *条件付き書式*: 「〜より大きい / 小さい / 等しい」で文字色・塗りを変える(cellIs 型。xlsx と往復する)
* *データの入力規則*(データタブ): リスト型。候補は直書き(`甲,乙,丙`)か範囲参照です(`=D2:D5`。参照先を書き換えれば候補も追従します)。規則に合わない入力はセルに入らず Esc で戻ります。別シート参照など解決できない規則ではブロックしない(通して警告しない)。list 以外の型は読めない旨を報告する
* *表のデザイン*(表のデザインタブ): 範囲を選んで1手ずつ掛ける道具です。ヘッダー行(1行目に色を敷く)・縞模様の行 / 列・最初 / 最後の列(太字)・*合計行*(下に =SUM の行を足す。式なので元が変われば追従。下に中身があれば断る)・フィルタのボタン(表の▼を入切します。xlsx にも残ります)。表は*表オブジェクト**(名前の付いた範囲)として持つので、*範囲に変換する*(表を外す。見出し行の色や縞模様の書式と式はそのまま残る — Excel と同じ)と**テーブルのサイズ変更**(ダイアログで A1:C9 のように新しい範囲を打つ)もできます。表は xlsx の table として保存され、Excel でも表として見えます。まとめて掛けるなら挿入タブの「表の挿入」(表オブジェクトも一緒に作る)

== シート・データの操作

* *複数シート*: 追加・削除・名前の変更・切り替え
* *行・列の非表示*: 見出しを右クリック →「非表示」。戻すときは**隠れた分を挟むように**見出しを選んで「再表示」。隠した状態は xlsx に残るので、隠したまま次の人に渡ります(グループ化と同じ仕組みです)。*使っている分を全部は隠せません。* 戻す道が見えなくなるので断ります
* *枠の固定*(表示タブ): 一覧から「カーソルの上と左を固定」「先頭行」「先頭列」を選びます。外すときは同じ一覧の「固定の解除」を選びます
* *セルの挿入・削除*(ホーム): 一覧から 右(左)方向にシフト / 下(上)方向にシフト / 行全体 / 列全体 を選びます。選んだ範囲の大きさぶん動き、動いたセルへの参照も付いて動きます
* *フィルター*: セルの値で絞る(見た目だけ。中身は変わらない)。解除も1手
* *並べ替え*: 列単位の昇順・降順。見出し行は据え置き
* *重複削除*(データタブ): 比べる列と「先頭行は見出し」(既定で入っています)を一覧で決めて「削除」を押します。消した後に件数を出します
* *テキストからデータ*(データタブ): CSV/TSV をいまのセルから流し込む。文字コード(CP932 含む)と区切りは自動判定。ファイル > 開く で .csv を選ぶと、データ > CSV の形 で決めた文字コードと区切りで読み、値だけの新しいブックにします
* *外部リンク*(データタブ): 他のブックの値を、値として取り込みます。参照は張りません。リンク切れの帳票を作らないためです
* *データテーブル*(データタブ): 入力値を差し替えながら式の答えを表に埋める感度表。四角い範囲を選んで押すと、列の入力セル → 行の入力セル(空 Enter = 1変数)を聞く。*表の形は Excel と同じです。* 1変数は「左の列に入力値・上の行に式・角は空」、2変数は「角に式・左の列と上の行に入力値」。計算はブックの複製の上でやるので本物の入力セルは荒れません。**その時の値**を埋めるので、入力を直したらもう一度押す
* *ゴールシーク*(データタブ)
* *ソルバー*(データタブ): ONLYOFFICE と同じ「ソルバーのパラメータ」のダイアログ。目的のセル(最大/最小/値)・変数セル(範囲かカンマ区切り、最大64個)・制約(左辺セル / <= = >= / 右辺の数かセル)を決めて「解を求める」。解法は**単体法 LP**(scipy で解く)。係数は表の複製から測り、*線形でなければ断る*(本家と同じ)。解は変数セルに書かれ、Ctrl+Z の1手で戻ります
* *小計*(データタブ): 見出し付きの表を範囲で選んで押すと、区切りの見出し(例: 部署)→ 合計する見出し(空 Enter = 数の列全部)→ 集計方法(合計・平均・個数・最大・最小)の順に聞かれ、区切りごとに「〜 小計」(選んだ関数の式)の行と最後に総計の行が入り、明細だけがグループ化されます。*詳細の非表示で閉じると、小計と総計だけが残ります。* 式なので、明細を直せば追従します。先に並べ替えておくと区切りがまとまります(Excel と同じです)。全部まとめて Ctrl+Z の1手で戻せます
* *グループ化*(データタブ): 行の見出し(番号)をなぞって選んでから「グループ化」を押します。「詳細の非表示」で閉じ、「詳細の表示」で開きます。何も選んでいないときは、カーソルの行が属するひとつながりが対象です。列の見出しを選べば列にも効きます。もう一度グループ化すると深さが増えます(7段まで)。深さと閉じた状態は xlsx の outlineLevel と hidden に往復するので、Excel で開くと普通のアウトラインに見えます。閉じた行と列は印刷(PDF)にも出ません。絞り込みと違って*保存に残ります*。閉じた台帳は閉じたまま渡ります。閉じたときに合計を見せたいなら、手で行を選ぶより上の「小計」が早いです。かたまりの直後の行の見出しには +/− の丸印が出ます。押すだけで閉じたり開いたりできます(Excel のアウトラインの縁と同じです)
* *ピボットテーブル*(ピボットテーブルタブ): 見出し付きの表を範囲で選んで「挿入」を押すと、行に並べる見出し(複数可)→ 列に広げる見出し(省略可)→ 値と集計(合計/平均/個数/最大/最小)の順に聞かれます。polars が集計し、結果はその時の値として元の表の右の空きに置かれます。埋まっていればさらに右へ置きます。黙って上書きはしません。定義はブックに控えるので(独自部品 xl/joPivot.xml)、元の表が変わったらピボットの上にカーソルを置いて「更新」(すべて更新はブック全部)。*総計*(行と、列に広げていれば列も)・*小計*・*空行*(行の見出しが2つ以上のとき)・*レポートのレイアウト*(表形式 ⇔ コンパクト)は押すたびに切り替えて置き直す。計算の種類は そのまま/比率(総計を100%とした %)/累計/前との差 の4択 — *累計と差は小計・総計を落とす*(積み上げの途中に総計が挟まると読み違えるため)。選択するはピボット全体の選択。集計はどの操作でも polars が元データからやり直すので、平均の総計も正しい(行の平均の平均ではない)。どれも Ctrl+Z の1手。Excel で保存し直すと定義の部品は消える — その後は「更新」できない、ただの値の表になる(正直な劣化)
* *コメント*: セルに1件だけ付きます。空で Enter すると消えます。保存すると xlsx に残ります

== 挿入

* *表の挿入*: 罫線と見出し付きの表の枠を一括で作る
* *画像*: PNG / JPEG。図形は**分類から選ぶ2段の一覧**(基本図形・ブロック矢印・数式図形・フローチャート・星とリボン・吹き出し・線の7分類、全 37 種。中に文字も書ける)、記号、テキストボックス、スパークライン。Excel で作った帳票の図形も、こちらが作図を持つ形はその形で出ます。持たない形は四角で見せ、*開いたときの報告でそう言う*(保存では元の形のまま)
* *グラフ / 推奨チャート*: 選択範囲をmatplotlib が描いて、画像としてシートに浮かべる。推奨チャートは、範囲の形(行数・系列の数・1列目が数か日付か・負の数があるか)から合う順に 縦棒・横棒・折れ線・面・円・散布図 を並べ、選んだ物を描く(1列目が項目名、2列目以降が系列。先頭行が見出しなら系列名になる)。日本語フォントは機械のものを登録するので豆腐になりません。Python が見つからないときはステータスバーが手順を言う
* *SmartArt*: 分類(リスト・プロセス・循環・階層・関係・マトリックス・ピラミッド)を選び、次に形を選びます。分類・並び・名前は Euro-Office の現物と同じ。入るのは図形の集まりなので、各図形を選んで Enter で文字、ドラッグで移動、Del で削除ができ、全部まとめて Ctrl+Z の1手で戻ります。xlsx へは普通の図形として入る(Excel でも図形として見えます。本物の SmartArt 部品ではない — そのぶん、どの道具でも開いて直せる)。一覧には**この方式で組める形だけ**を出している
* *テキストアート*: 飾り文字。文字を打つと太字+縁取りで描いて、画像としてシートに浮かべる(matplotlib)
* 描画タブの*ペン・蛍光ペン・消しゴム*: 押してツールを出し、表の上をドラッグすると線が引ける(ペンは細い黒、蛍光ペンは太く薄い黄)。消しゴムは、線をなぞると1筆ずつ消せます。もう一度同じボタンか Esc でセルの操作に戻ります。線は普通の図形(折れ線)として保存されるので、Excel でも線に見え、Ctrl+Z で1手ずつ戻り、印刷(PDF)にも出ます
* *チェックボックス*: 空のセルに置くと ☑/☐ になり、*空白キーで切り替わる*(値は TRUE/FALSE です。式から `=E4` や `=COUNTIF(E:E,TRUE)` で普通に使えます)。TRUE/FALSE の値を持つセルはどれも ☑/☐ で見えます。中身のあるセルは潰しません。Excel で開くと TRUE/FALSE の値で見える(部品の書式は書かない)
* *スライサー*: カーソルの列の値がボタンで並ぶパネル。押すとその値の行だけに絞れる(≡ で複数選択、✕ で解除、Esc で閉じる)。絞り込みと同じく見え方だけです。保存される中身は変わりません
* *方程式*: 数学の式の清書です。セルの計算式とは別物で、計算はしません。TeX の書き方で打つと(例: `\frac{a}{b}`、`\sum_{i=1}^n i^2`)、calc の中の組版の部品(typst)が清書して画像として置く。Python は要りません。行列や場合分けの列も揃います。読めない式は、そう言って断ります。Microsoft 日本語版の「数式」と同じ機能で、名前はEuro-Office の訳語(方程式)に合わせている
* *ハイパーリンク*: 右クリックまたは挿入タブ。空で Enter すると消える

== 左右のパネル(表示タブ)

*右 = いま選んでいる物の設定、左 = 相談する相手*、と場所で分けています。
どちらも**開きっぱなし**で、格子が細くなるだけ(重なって隠すことはしません)。

**パネルの外側にはアイコンの柱**が立っていて、押すと面が替わります(左: AI と相談する / コメント、右: セルの設定 / 図形と画像)。
*コメントを選んだときは、柱だけになります。* コメントはセルの吹き出しで見えるのでパネルが要らず、そのぶん表が広く使えます。
絵の上に指を置くと名前が出ます。

=== 右パネル「セルの設定」

小窓や一覧に散っていた物を1枚に寄せました。
**開いたまま連打で効く**のが値打ちで、とくに罫線は「ペンを選んだまま何箇所にも引く」が続けてできます。

* *文字*: 太字 / 斜体 / 下線
* *揃え*: 左 / 中央 / 右 / 折り返す
* *表示形式*: 標準 / 通貨 / 桁区切り / パーセント / 品番(0000)/ 日付(その他は今までどおり一覧から)
* *罫線*: 決めることは2つです。ペン(細・中・太・破線・二重)と、引く場所(格子・外枠・上下左右・消す)です。本家の型スタンプは持ちません。ペンを選んでから場所を押す、の1本だけです
* *塗り*: 色見本を直に並べています。押すとその場で塗ります(柄・グラデーションは一覧の側に残しています)
* *字下げ*: − と + で1段ずつ。*ここで初めて掛けられるようになりました*(xlsx の読み書きは前からできていたのに、掛ける道がありませんでした)
* *文字の向き*: 角度なし / 45度 / 90度 / 縦書き
* *条件付き書式*: **値を訊かないもの**だけ(0未満を赤字・重複・一意・平均より上/下・データバー・色の濃淡・アイコン・消す)。「値より大きいと…」のように打ち込みの要る規則は一覧の側にあります

=== 左パネル「AI と相談する」

次の節。

== 自分の AI から calc を操る(MCP)

**向きが逆の道**もあります。
calc が AI を呼ぶのではなく、*あなたが使っている AI*(Claude Code / Claude Desktop など、MCP を話す物なら何でも)がcalc を道具として使う形です。

----
pip install "officework[mcp]"
----

AI の客に `officework-mcp` を登録すると、こう言えます:

[NOTE]
====
「いま開いている表の B 列を合計して、下に置いて。見出しは太字にして」
====

*officework が動いている必要があります。* 動いていなければ、そう言って断ります。

表の道具は8つです。
ブックの様子・使っている範囲・値を読む・式を読む・値を書く・書式を掛ける・幅を合わせる・保存です。

*文書の道具もあります*(名前が `doc_` で始まる7つ)。

[NOTE]
====
「申込書の氏名を山田太郎、住所を松山市にして、PDF にして」
====

文書の様子 / 本文を読む / 本文を入れ替える / 記入欄の名前 / 差し込みの穴の名前 / 穴を埋める / PDF に書き出す。
文書の道具を呼んだのに表が前に出ているときは、そう言って断ります。

* *任意のコードを走らせる道具は置いていません。* 「Python を実行」を1つ置けば何でもできてしまい、許した範囲を越えます
* ファイルを開く道具もありません。何を開くかは、人が calc の側で決めます
* 保存は頼まれたときだけ。勝手に上書きしません

この道なら、**AI の枠を使うのはあなたとその AI の製品の間**の話になり、officework は表計算の道具を差し出すだけです。

== AI — 左パネルで相談する

*AI のボタンは、左パネルの会話にまとまっています。* 10 個のボタン(要約・書き直す・敬語にするなど)は、左パネルの会話に置き換わっています。
「この表を売上の多い順に並べて」と打てば済みますし、ボタンでは作れない頼み方(「表にして、列は日付と金額で」)もできるからです。

開き方: *表示タブ > 左パネル*。

* **選んでいる範囲が相談の相手**になります(選んでいなければ、範囲の要らない用件として通ります)
* *表を直す頼みは、AI がそのまま実行します。* 範囲への書き込み・書式・列幅の調整は、その場でブックに入ります。実行した行には「1手」の印が付き、**Ctrl+Z 一手**で戻せます。事前の「よろしいですか」は出しません
* *込み入った頼みは、AI がマクロ(.py)を書いて走らせます。* ファイルはブックの隣に置かれ、後から読めます。走るのはサンドボックスの中です。誤りが出たらその文が会話に戻り、AI が直して走らせ直します
* 表を直さない頼み(意味を訊く・式を1つ教える)は、そのまま答えます
* *人が押すのは保存だけです。* AI が保存を頼んできたときは、確認のボタンが出ます
* *やりとりは続きます。* 「さっきのを今度は昇順に」が通ります。「新しい会話」を押すまでの会話を全部添えて頼んでいるからです
* 「新しい会話」で話を終わりにできます(表は触りません)
* *会話の記録は、ブックの隣の `<名前>.agent.txt` に残ります。* 何を頼んで何が変わったかが、後から読めます。名前の無い新しいブックには残りません
* **宛先は欄の下**に出ます。押すと一覧が出て、選べます

一覧には4種類が並びます。自分で書いた宛先(下の `\[[ai]]`)、**鍵の環境変数が入っている提供元**(`ANTHROPIC_API_KEY` なら Anthropic、`OPENAI_API_KEY` なら OpenAI、ほかに Google・OpenRouter・Groq・Mistral・xAI。設定は要りません)、**動いている手元のモデル**(Ollama・llama.cpp・LM Studio。いつもの港が開いていれば出ます)、そして **Claude Code**(この機械に `claude` が入っていれば出ます。Claude の定額(Pro / Max)で使えます。改変していない Claude Code をそのまま呼ぶだけで、ログインは端末で `claude auth login` を済ませておきます。officework はログインの情報に触りません)。

自分で書く宛先は `~/.config/officework/settings.toml` の `\[[ai]]` に並べます。

[source,toml]
----
# 宛先を1つ書きます(何個でも並べられます)
[[ai]]
name = "会のサーバー"
url = "https://ai.example.org/v1/chat/completions"
model = "gpt-oss-120b"
key_env = "OFFICE_API_KEY"   # 鍵の入っている環境変数の名前
----

`\[[ai]]` が無ければ、下の `ai_url` / `ai_model` を1つの宛先として使います。それも無ければ環境変数 `OFFICE_URL` の先です。
ファイル > 詳細設定 の「AI の宛先」の行にも、同じ一覧の宛先の名前が出ます。一覧が空なら、`\[[ai]]` を書く案内が出ます。

つながらない宛先なら**その場で理由**を言います。

=== 会のサーバーを1台立てる(API キーを1本にまとめる)

*既定の「手元のモデル」の宛先は、自由に変えられます。* 会で1台だけサーバーを立てて全員がそこを向けば、API キーの管理も請求も1箇所で済みます。
その先で何を動かすか(手元のモデルでも、どこかの API への中継でも)は運用する人が決めることで、officework は **OpenAI 互換の口**を叩くだけです。

`~/.config/officework/settings.toml` に1行:

[source,toml]
----
ai_url = "https://ai.example.org/v1/chat/completions"
ai_model = "gpt-oss-120b"
----

* *`https://` にすると暗号が掛かります。* 会の外へ出す文書を平文で流さないでください(`http://` は手元の 127.0.0.1 のときだけ)
* API キーが要るサーバーなら、*環境変数 `OFFICE_API_KEY`* に置きます(設定ファイルにも文書にも API キーは書きません)
* `ai_url` も `\[[ai]]` も無いときは、環境変数 `OFFICE_URL` の先が宛先です
* いまの宛先と「外へ出るかどうか」は、この画面の**手元のモデルの宛先**の行に出ています

よく使われる置き場の例: Ollama は `11434`、llama.cpp server は `8080`、LM Studio は `1234`。
どれも `/v1/chat/completions` です。

繋がらなければ「できません」と言います(黙って空にしません)。
*API キーはブックに書きません。* 読むのは、上に書いた環境変数だけです。

== セルの文字は AsciiDoc

文字列のセルは、AsciiDoc として描かれます。writer の本文と同じ書き方なので、覚えるのは1つです。
セルが持つのは平文のままで、解釈するのは画面に描くときだけです。

----
これは**太字**です                    → これは太字です
__斜体__ ``等幅`` [.line-through]##取消線##
https://…[こちら] を見て              → 青い下線のリンクになる
= 見出し   == 中見出し   === 小見出し
* 甲      . 一つめ(番号は書かない — 続けて打つと 1. 2. と出る)
----

* *リボンのボタンで足ります。* 何も選ばずに押すと、セル全体に効きます。編集中に字を選んで押すと、その字だけに効きます。選んだ所に印が入り、もう一度押せば外れます。印を自分で打っても同じです
* **印は二重が確実です。** 一重(`*太字*`)は語の外でしか効かないので、語の間に空白の無い日本語の文中では効きません(欧文の `this is *bold*` は効く)
* `=` の後ろに空白が無ければ式です(`=SUM(A1)`)。空白があればセルの見出しです(`= 大`)
* セルが持つのは、いつも平文です。数式バーにも Python にも、印ごとそのまま見えます
* *xlsx へは平文のまま入る*。平文なので、往復しても打った記号がそのまま残ります。Excel では記号がそのまま見えます
* *選んでいるセルは生の文字を見せる*(打ち直せるように)
* 見出しや箇条書きを縦に積むには、セルを**折り返し**にする(折り返しの無いセルでは、今までどおり改行が空白になります)
* 和文の書体は斜体の面を持たないので、`__斜体__` は日本語では傾かない(印は外れます。欧文は傾く)
* *見出しの大きさは型紙で決まります。* ブックの名前付きセルスタイル「見出し 1 / 2 / 3」を見ます。型紙(.xltx)に定義しておけば、そこから作ったブック全部に効く(Excel で編集しても追随する)。無ければ既定の1.6 / 1.35 / 1.15 倍・太字。*見出しを打つと行が広がる*(狭めはしない)

*表を壊さない線引き*: 書式と読めるものが1つも無ければ何もしません。
`2*3*4`(掛け算)・`2**10`(冪)・`ABC_001`(名前)・`-100`・`1.5`・`2026-08-09`・`商品名*`(片方だけの印)は、今までどおりそのまま出ます。
印が語の中にあるとき、そして囲みの中身が数字だけのときは、書式にしません。

== Python — マクロの代わりに

コードの書き方(*範囲⇄配列*・API・=PY の引数と返り値)の説明はlink:python-manual.adoc[Python の手引き]。
この章は操作の側から。

*VBA 型のマクロはありません。* データとプログラムを1つのファイルに入れる仕組みを**持たない**。
VS Code と Excel を合わせたものだとお考えください。
表は .xlsx、コードは .py で、どちらも別々のファイルです。

* 人とやり取りするのは**データだけ**。受け取ったブックにコードは入っていない
* 関数は `~/.config/officework/funcs/*.py`、手続き(マクロ)は``~/.config/officework/plugins/*.py`` に置く。*1機械1回の据え付け*
* だから「開いただけで他人のコードが走る」が原理的に起こらない
* コードが自分のものだけなので、サンドボックスは使わない(VS Code でスクリプトを走らせるのと同じ扱い)

=== 準備

* Python: `JO_PYTHON` → `.venv/bin/python` → `python3` の順で探す
* `officework` パッケージを calc の実行ファイルの隣に置く。あるいは``pip install officework`` で入れます。calc は自分の居場所を `sys.path` に足して``from officework import sheet`` するので、要るのは **`officework/` のディレクトリ**であって裸の `.so` ではありません。この木から作るなら``maturin build -m pysheet/Cargo.toml --release`` の wheel を入れる
* 置き場は2つ(無ければ作る):
** `~/.config/officework/funcs/` は、*セルの式から呼ぶ関数*(UDF)の置き場です
** `~/.config/officework/plugins/` は、*人が押して走るマクロ*の置き場です

=== 置き場を2つに割った理由(2026-08-16)

前は1つでした。
すると、マクロの補助関数まで表の式から呼べる関数になっていました。
`def 補助():` と書いたつもりの物が、`=補助()` で呼べてしまいます。
危うさが違います:

[cols="1,1,1"]
|===
| |関数(funcs) |マクロ(plugins)

|呼ぶ人 |*式*(`=税込(A1)`) |*人*(一覧から選ぶ)
|いつ走る |ブックを開くたび・再計算のたび |押したときだけ
|誰の判断で |セルに残った式(書いた本人が居なくてもよい) |そのときの人
|引数 |値だけ |ブック丸ごと
|===

*式に残るものは、人の押す手を通らずに走り続けます。* だから置き場を分け、「式から呼べる」は funcs に置いた物だけにしました。

既に plugins に関数を置いている場合は、funcs へ移してください(空のまま plugins に .py があると、起動時にそう言います)。

=== セル関数を Python で書く

`~/.config/officework/funcs/道具.py` に**普通に def を書くだけ**:

[source,python]
----
def 倍(x):
    return x * 2

def 縦横(表):
    return [[v * 10 for v in row] for row in 表]
----

セルには普通の関数として書く。
*デコレータも登録も要らない*:

----
=倍(A1)              → 42(A1 が 21 のとき)
=縦横(A1:B2)         → 右下へ 2×2 に広がる
----

* 関数の名前は**日本語でよい*
* *引数が変われば裏で計算し直す*(`@計算` を押さなくていい)。計算は別スレッドでまとめて回り、答えが揃ってから1手で書き戻ります
* 引数は式を**いま評価した値**で渡す(範囲は行×列の2次元リスト)
* 返り値が2次元なら右下へ**スピル**(1次元は縦に展開)。展開先に他人のデータや式があれば `#SPILL!` で止まります。潰しません。結果が縮んだら前回の面の残りは消える
* 組み込みの関数名(SUM など)は譲りません。同じ名前の def は見送る
* 同じ名前が2つの .py にあるときだけ `=道具.倍(A1)` とモジュール名を付ける
* .py を書き換えると calc が気づいて計算し直す
* 一度も計算していないセルは `#PY?`。Excel で開くと `#NAME?` になる(保存された値は Excel が再計算するまでは見える)
* 古い書き方 `=PY("倍", A1)` も動く
* **数式 > Python の関数**を押すと、funcs にある関数が一覧で出ます。選ぶとその .py が編集の道具で開きます

*セル関数から AI を呼ばないでください。* 式は再計算のたびに走ります。
1万行に入れれば1万回走り、開き直すたびに答えが変わります。
何回走ったかも見えません。

*AI はマクロから呼びます。* 押したときだけ1回走り、結果は普通の値としてセルに入ります。
以後は揺れません。
取り消しの1手で戻せます。

これは手元で動くモデルでも同じです。
料金と「字が外へ出る」心配は減りますが、答えが揺れることと、走る回数が見えないことは変わりません。

=== 手続き(マクロの置き換え)

`~/.config/officework/plugins/取り込み.py`:

[source,python]
----
from officework import calc as xw

def 貼り付け():
    s = xw.Book.caller().sheets.active
    s["A1"].value = [["受信", "名前"], ["2026-08-09", "山田"]]
----

データ > Python の入力欄に `@取り込み.貼り付け` と打つと動く。
*動いているブックをそのまま操る*(一時ファイルの複製ではない)。
何回セルを書いても **Ctrl+Z 一回**で手続きの前に戻ります。

=== 一行のコードを回す(データ > Python)

`b` = ブック、`s` = いまのシート、が変数済み。

[source,python]
----
s["A30"] = "サンプル商事株式会社"        # 書式は据え置きで値だけ入る
----

* 空のまま Enter → .py ファイルを選んで回す
* これは複製の上で走ります。失敗しても表は無傷です。成功したら、結果を1手として適用します。複数のシートに触っても Ctrl+Z 一回で戻ります
* polars・scipy など、この機械に入っているものは全部使える

=== @コマンド

[cols="1,1"]
|===
|打つもの |動き

|`@モジュール` |`~/.config/officework/plugins/モジュール.py` を上から下まで走らせる
|`@モジュール.関数` |その .py の関数だけを呼ぶ
|`@edit 名前` |*その .py を calc の中で開いて編集する*(無ければ下書きを作る)
|`@list`(または `@`) |funcs と plugins の .py と、その中の def の一覧
|`@計算` |セル関数の計算を手で回す(普段は自動なので要らない)
|`@export 名前` |**古い**ブックに載っているコードを .py に取り出す(実行はしない)
|`@del 名前` |古いブックに載っているコードを外す
|===

`@名前 net` は要らなくなった(サンドボックスを使わないので網の区別が無い)。
打つと、そう言われます。

=== .py を calc の中で編集する

`@edit 道具` と打つと、`道具.py` が表の上に開きます(plugins にあればそれを、無ければ funcs の方を)。
無ければ下書き(関数が1つ入ったもの)を作ります。

* 行番号つき。`def` の名前・キーワード・文字列・コメントに色が付く

* Enter は前の行の字下げを引き継ぐ(`:` で終わっていれば1段深く)。Tab は空白4つ(Python は字下げが構文なので、タブ文字は入れない)
* Home は「字の始まり ⇄ 行頭」を行き来する
* Esc で閉じます。*書きかけがあれば一度断る*(もう一度 Esc で捨てて閉じる)
* 開いている間、Ctrl+A / Ctrl+Z / Ctrl+C / Ctrl+V は**コードに効きます**(表には触りません)

== 共同編集タブ

サーバーは使わありません。

* *共同編集モード*: いまの編集権(=ロック)の持ち主を確かめます。先客が去っていれば編集権を取り直す
* *コメントを追加 / 削除 / 表示*: セル単位。表示を消しても付いたまま
* *チャット*: ブックの隣のチャットファイル(`名前.xlsx.chat.txt`)へ、名前付きで追記します。生放送ではありません。ファイル越しの伝言です

* *バージョン履歴*: 上書き保存のたびに `.jo-history/名前/日時.xlsx` へ控えが残る(9世代まで)。一覧から選ぶと**名前のないコピー**として開く —元へ戻すなら同じ名前で保存(黙って書き戻さない)

== フォルダから探す(2026-08-17)

ファイル > *フォルダから探す*。
指定した場所を辿って、複数のファイルを串刺しで探す。

* *.xlsx の中身(セルの字)も探せます。* 開かずに、どのブックに何があるかが分かります
* 普通の字(.txt / .md / .csv / .py …)もそのまま
* `*.xlsx` の形で名前を絞れる(`;` で複数)
* 場所は**開いているブックの隣**が既定(前に選んだ場所があればそちら)
* 隠しフォルダは辿りません。多すぎるときは途中で止め、*止めたと言う*

当たりはファイルごとに、行番号つきで並ぶ(xlsx は「シート名の下に1行=1行」として数えた行)。
選ぶと**下に出るだけで、開かない**。
開くのは下の**「読み込み」**を押したとき。

*calc が開けるのは表だけ。* 普通の字が当たったら「writer で開いてください」と言う(黙って壊れた言い分を出さない)。

== マクロタブ

この段は1本にまとめてあります。前は「Python」と「プラグイン」の2段に割れていて、置き場の .py を2通りに並べていました。同じ物です。

* *操作を記録*: 手でやった操作が Python の行として溜まります。止めると``~/.config/officework/records/`` に .py として落ちます。*中身は記録だけ* —ブックを開く行は付きません(どのブックに掛けるかは、記録した人が決めます)

=== 記録は何を書くか(2026-08-16)

*記録中は下のステータスバーに赤い「● 記録中 N 行」が出ます。* 押すと止まります。
リボンの「操作を記録」も赤くなります。

書かれるのは、押した命令の名前ではなく**掛かった結果**です:

[cols="1,1"]
|===
|したこと |残る行

|A1 を選ぶ |`s["A1"].select()`
|太字 |`s["A1"].font.bold = True`
|中央揃え |`s["A1"].align = "center"`
|パーセント |`s["A1"].number_format = "0%"`
|並べ替え・消去・貼り付け |`s["A1:B3"].value = [[…], […]]`
|余白を変える |`s.set_page_setup(margins_mm=(10, 10, 10, 10))`
|リボンに足したマクロを押す |`xw.run_macro("締め")`
|===

*入切の物は「押した回数」ではなく行き着いた姿を書きます。* 太字を2回押したら `= True` と `= False` の2行になります。
巡回する余白のボタンも同じで、最後に行き着いた mm が入ります。

選択の行は、**何かを記録する直前に**前と変わっていたときだけ入ります(矢印キー1回ごとに書くと記録が洪水になるため)。

=== まだ書けない操作

罫線・図形・グラフのように Python から使う方法がまだ無い操作は、記録に

    # この操作はまだ Python で書けません: テキストボックスの挿入(instext)

と残ります。
*黙って落としません。* この行がそのまま、Python から使う方法の宿題の一覧になります。
書式の一部だけ書けた場合も、この註が出ます —半分だけ走るマクロは、走らないマクロより悪いからです。

* *新しい .py*: 置き場に新しいスクリプトを作って開く
* *一覧*: `~/.config/officework/plugins` の .py を並べ、*選ぶと走る*。直すのは「置き場を開く」か `@edit 名前`
* **ファイル > マクロ**からも同じ一覧が出ます(本家と同じ場所)
* *置き場を開く*: `~/.config/officework/plugins` をファイル管理で開く

置き場の名前は `plugins` のままです。
既に置いてある人の物を迷子にしないためで、画面の言葉だけを「マクロ」に揃えました。

=== リボンにボタンとして出す(2026-08-16)

*`~/.config/officework/ribbon/` に置き、名乗った .py はリボンのボタンになります。* マクロタブの「リボンのマクロ」で今出ている物を見られます。

[source,python]
----
リボン = {"ラベル": "月次の締め", "アイコン": "py-run", "タブ": "マクロ"}

from officework import calc as xw

s["A1"].value = "締めました"
----

*手で書かなくても、見本から始められます。* マクロ > 「リボンのマクロ」の一覧に「見本を作る」があります。
選ぶと、そのまま動く .py を置き場に作って開きます。

* *ラベル* は、ボタンに出る言葉です。*訳しません。* あなた自身の言葉だからです
* *アイコン* は、アイコンの名前です。知らない名前を書くと、既定のアイコンになります
* *タブ* は、どのタブに出すかです。省くと「マクロ」に入ります

宣言は読むだけで、走らせません。ボタンを押したときに初めて走ります。

=== 3つの置き場(まとめ)

[cols="1,1,1"]
|===
|置き場 |呼ぶ人 |いつ走る

|`funcs/` |*式*(`=税込(A1)`) |開くたび・再計算のたび
|`ribbon/` |*リボンのボタン* |押したときだけ
|`plugins/` |*一覧から人が選ぶ*(`@名前`) |選んだときだけ
|`records/` |— (置くだけ) |*走りません*
|===

`records/` は**操作の記録の落ちる先**です(マクロ > 操作を記録)。
記録は下書きなので、置いただけでは一覧に出ませんし走りません。
読んで、直して、これでいいと決めたら `plugins/` か `ribbon/` へ移します。

ピボットテーブル・グラフ・ソルバーなどは**同梱の側**にあたります(中身はpolars と matplotlib の Python)。
同じ一覧の下の方に「同梱: chart(読むだけ)」として並んでいます。選ぶと控えが開くので、何をしているか読めます。

*ただし契約が違います。* 同梱のスクリプトは「指図(JSON)を受け取って答えを返す」純関数で、*ブックに触りません*(呼ぶ側の calc が範囲を読んで渡します)。
あなたのマクロは逆に、押されたら動いているブックを直に操ります。
だから同梱のスクリプトを置き場へ写しても、そのままでは同じようには走りません。
読む対象であって、写す雛形ではありません。

=== 走らせられるのは置き場の .py だけ

*calc から起動できるマクロは `~/.config/officework/plugins` の .py に限ります*(2026-08-16)。
前は「ファイルから」でどこの .py でも選べ、データ > Python の空 Enter でも同じことができました。
どちらも閉じました。

外から受け取った .py は、**置き場に置いてから**一覧で選びます。
*置く手が1つ挟まります。* 置く前に読んでください。
普通の Python で、中身は読めば分かります。

Python が走る道は、これで3つです:

[cols="1,1"]
|===
|道 |何が走るか

|マクロ > 一覧、セルの `@名前(...)` |*置き場の .py だけ*
|データ > Python(打ち込む) |*その場で打った字*。ファイルは読みません
|左パネルの会話 |*AI が書いたマクロ*。ブックの隣の .py に置かれ、サンドボックスで走ります
|===

どれも人が選ぶ・打つ・押すのが入口です。
*ブックはコードを運びません* —開いただけで何かが走ることはありません。

== 保護タブ

* *範囲を保護する*: シートの保護中でも編集できる範囲を登録します(Excel の「範囲の編集を許可」と同じ意味。xlsx の protectedRanges と往復)。範囲の外はセルのロックどおりに止まります。同じ範囲でもう一度押すと外れます。パスワードは掛けません
* *保護*: いまのシートを読み取り専用にする(編集をブロック。同じボタンで解除)。*パスワードは掛けませんし、掛けた振りもしません。* xlsx の sheetProtection と往復するので、Excel でも保護されたシートに見えます
* *暗号化する*: パスワードを決めると次の保存から **AES-256(Agile。Excel 2013+ の既定)**で包む。Excel や LibreOffice でも開けます。空にして Enter で暗号化をやめます。開くときはパスワードのダイアログ(伏せ字)。*開く側は古い AES-128(2007 の Standard)も Agile も両方読める*
* *デジタル署名を追加*: *隣に置く署名ファイル*(`名前.xlsx.sig`、Ed25519)。押すと、署名が有効なら報告、無い・中身が変わったなら署名し直す。Excel の署名欄に出る方式ではありません。実体は改ざん検知と名前の証明です

== 印刷と PDF

レイアウトタブで設定し、ファイル > 印刷 で PDF に書き出す。

* 用紙: A4 / A3 / B4 / B5 / A5。*B は JIS*(日本の事務様式の実情に合わせる)
* 向き・余白(既定 20mm / 狭い 10mm / 広い 30mm)・拡大縮小(100→90→80→70→50%)
* 印刷範囲(選択して指定。もう一度で解除)、改ページ、タイトル行の繰り返し、枠線も印刷、見出し(行番号・列名)も印刷
* これらは xlsx にも保存されるので、Excel で開いても同じ印刷設定になります。理解しない属性は消しません
* PDF には値・書式・罫線・塗りと、図形・画像が写ります。図形と画像は、このアプリで挿した物も、xlsx がもともと持っていた物も出ます。Excel がテキストボックスの中に持っている数式は、式として清書して出します
* *横に大きい表は横へページを送る*: 紙の幅で列を束に割り、束ごとに全行を出してから次の束へ(Excel の既定と同じ「縦 → 横」の順)。束の頭には列名の見出しとタイトル行も出ます。**1列だけで紙より広い列**は割りようが無いので切れ、その本数をステータスバーで言う(幅を詰めるか用紙を大きく)。図形・画像は最初の束の紙にだけ出ます

== 保存

* Ctrl+S で上書き(先客のロックがあれば止まる)。名前がなければダイアログ
* 原本の部品(グラフ・図形・テーマ・理解しない XML)は**原文のまま持ち越す*
* 未保存の変更があればステータスバーに出て、終了時に「保存して終了しますか?」と聞く
