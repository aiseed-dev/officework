= 対応表 — メニュー・API・python-docx・openpyxl

画面のボタンと、プログラムの書き方を引く1枚です。

* 画面で押している*ボタンの名前*から、プログラムの書き方を引く
* python-docx / openpyxl の*覚えている書き方*から、officework の書き方を引く

並びは画面のメニューと同じです。ファイル・ホーム・挿入…の順に並んでいるので、
画面で押している場所を思い出して探してください。

メニューの後ろに、*クイックアクセス*(窓の上の段)・*左右のパネル*(表示タブで出す)・
*下端*(ステータスバー)も並べてあります。

*右クリック*の段には、そこにしか無いものだけを並べました。
右クリックの中身はほとんどがリボンと同じ命令なので(切り取り・コピー・太字・揃えなど)、
それらはリボンの段で引いてください。

同じボタンが2か所にあることがあります(「保存」はファイルとクイックアクセスの両方にあります)。
*両方とも載せて*、後から出るほうに「◯◯と同じ」と書いてあります。
画面には本当に両方あるので、隠しません。

== 印の読み方

印が言うのは*プログラムから呼べるか*だけです。
ボタンのほうは、印が何であっても画面から使えます。

[cols="^1,3"]
|===
|印 |意味

|✅ |*プログラムから呼べます。* 右の列がその書き方です
|✍ |*専用の呼び方はありませんが、書けばできます。* 右の列がその書き方です
|(空) |*まだ呼べません。* これから用意します
|❌ |*呼ぶ相手がありません。* 画面の見え方が変わるだけで、文書もファイルも変わらない操作です
|===

== 列の読み方

`officework` の列が、この道具の書き方です。
その右の2列が python-docx と openpyxl の書き方で、*同じ操作を何と呼ぶか*が並びます。

`A / B` と2つ書いてあるときは、どちらでも書けます(文章のときと表のときで変わります)。
`—` はその書き方がありません。

*オブジェクト*の列は、どの物に対する操作かです
(`Doc` は文書、`Paragraph` は段落、`Run` は字、`Cell` はセル、`Sheet` はシート)。
*どこでも*と書いてあるものは、選んでいる物を選びません — 字でも、セルでも、画像でも同じです。

== 書けば API になります

✍ の行は、その書き方を関数にまとめれば、自分の呼び方で使えます。

[source,python]
----
def 大文字にする(段落):
    for r in 段落.runs:
        r.text = r.text.upper()
    return 段落
----

よく使うものはパッケージにして、職場で配れます
(link:python-manual.adoc[Python の手引き]の「パッケージを足す」)。
