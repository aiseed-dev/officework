= 原稿の手引き — 書いて、4つの形で出す

_元は英語版(link:../en/genkou-manual.adoc[genkou-manual.adoc])です。こちらは日本語訳です。_

officework で原稿を書き、AsciiDoc・Word 文書(docx)・Web ページ(HTML)・PDF の
4つの形で出すまでの手引きです。

書くのは1つ、出すのは4つ、という形です。
同じ原稿から4つとも出せるので、渡す相手ごとに作り直す必要がありません。

[cols="1,2"]
|===
|形 |主な使い道

|AsciiDoc(`.adoc`) |原稿そのもの。テキストなので、差分も検索も効きます
|Word 文書(`.docx`) |相手に渡すとき
|Web ページ(HTML) |社内のページに載せるとき
|PDF |印刷するとき、体裁を固定して渡すとき
|===

== 原稿は2つのファイルでできています

[cols="1,2"]
|===
|ファイル |持つもの

|`報告書.adoc` |*中身*。見出し・本文・表・箇条書き
|`既定.tmpl.adoc` |*見た目*。書体・文字の大きさ・用紙・余白・スタイル
|===

中身と見た目を分けておくと、*見た目を変えるときに本文を触らずに済みます*。
同じ原稿を、社内用の体裁と提出用の体裁で出し分けられます。

見た目のファイルはフォルダに置きます。
フォルダに `.tmpl.adoc` が1つだけあれば、そのフォルダの原稿すべてに使われます。
書き出し先ごとに分けたいときは、`web.tmpl.adoc` `print.tmpl.adoc` のように名前を付けます。

== 書く

officework で `.adoc` のファイルを開くと、編集画面が出ます。
見出しや太字はリボンのボタンで付けられます。詳しくは link:writer-manual.adoc[writer の手引き] を見てください。

原稿は普通のテキストなので、テキストエディタで開くこともできます。

....
= 2026 年度 第2四半期報告書

== 概要

本報告書は、第2四半期の進捗をまとめたものです。

|===
|品名 |数量 |金額

|ボールペン |12 |1,440
|コピー用紙 |5 |2,450
|===
....

== 数字の出どころを、原稿に残す

報告書の数字について、後から「これはどこから来たのか」と聞かれることがあります。
*原稿の中に、取ってきた方法を書いておけます。*

....
[source,python]
----
# 売上の表は、経理の台帳から取りました(2026年8月24日)
import polars as pl
売上 = pl.read_excel("経理/売上台帳.xlsx", sheet_name="2026")
----
....

これは*記録として持つだけ*です。原稿を開いても実行されません。
書いてある内容は、原稿と一緒に相手にも渡ります。

[NOTE]
====
編集画面では、この部分は*見えますが直せません*。
直すときはテキストエディタで開いてください。
====

== 表を入れる

表は原稿の中に直接書きます。

....
|===
|月 |売上

|4月 |1,200,000
|5月 |1,450,000
|===
....

編集画面では「挿入」タブの「表の挿入」から作れます。
セルの中では、行の中で `Tab` で右へ、`Enter` で下へ移動します。

大きな表や計算のいる表は、表計算の画面(calc)で作って `.sheet.adoc` として保存し、
そちらで管理する方法もあります。

== 4つの形で出す

「ファイル」タブから出します。

[cols="1,2,2"]
|===
|形 |どこから |出るもの

|AsciiDoc |保存 / 名前を付けて保存 |`.adoc` のファイル1つ
|Word 文書 |名前を付けて保存(`.docx` を選ぶ) |docx のファイル1つ
|Web ページ |Web の形で書き出す(HTML) |HTML 1枚(スタイルは中に入ります)
|PDF |印刷 |PDF のファイル1つ
|===

どの形でも、見た目はフォルダのテンプレートが決めます。

=== Word 文書で受け取った原稿を、原稿の形にする

docx で受け取った文書は、そのまま開いて読めます。
これを AsciiDoc の原稿にするには、「ファイル」タブの
「adoc 形式にする(本文と書式を分ける)」を押します。

本文が `.adoc` に、書体や余白が `.tmpl.adoc` に分かれます。
*この操作は元に戻せません*。押すまでは何も起きないので、
写しを取ってから試してください。

== Python から原稿を作る

決まった形の書類を大量に作るときは、Python から呼べます。

[source,python]
----
from officework import doc

d = doc.Doc.open("報告書の雛形.docx")
d.fill("宛先", "サンプル商事株式会社")
d.fill("金額", "1,440,000")
d.save("報告書_サンプル商事.docx")
----

雛形の中の `{名前}` を、まとめて差し替えることもできます。

[source,python]
----
d.render({"宛名": "サンプル商事株式会社", "合計": "1,440,000"},
         rows={"明細": [{"品名": "ボールペン", "数量": "12"},
                        {"品名": "コピー用紙", "数量": "5"}]})
----

`{明細.品名}` を含む表の行は、データの数だけ増えます。

詳しくは link:python-manual.adoc[Python の手引き] を見てください。

== 困ったとき

[cols="1,2"]
|===
|様子 |どうするか

|保存したら書体が変わった |フォルダのテンプレートが効いています。テンプレートを直してください
|`.adoc` で保存したら書式が消えた |文字ごとの書式は `.adoc` に持てません。スタイルで指定してください
|Word で開いたら体裁が違う |Word 側にその書体が入っていない場合があります。テンプレートで書体を指定してください
|表の列幅が保存されない |列幅は見た目なので、テンプレートの持ち物です
|===

保存のときに落ちたものがあれば、画面の下に何が落ちたか出ます。
黙って落とすことはありません。
