= 列で計算する

_元は英語版(link:../en/df-manual.adoc[df-manual.adoc])です。こちらは日本語訳です。_

*状態: 未実装* — *まだ使えません。* この手引きはこれから作る物を書いた物で、
実装はこれを読んで作ります。

数式はふつう、1つのセルに属します。この冊子で説明する `df` は、数式を列に
属させる書き方です。見積書・注文書・帳簿のように、どの行も同じやり方で
計算する表を持っている人に向けた冊子です。

== 何をするか

数式を1回書くと、列が埋まります。

単価の列と数量の列がある売上の表を考えます。どの行も、金額は単価×数量です。
いまは、その数式を1つのセルに書いて下へ写します。`df` では1回だけ書きます。

    =df(売上[金額] = 売上[単価] * 売上[数量])

これで、表に金額の列ができます。

[cols="2,1,1,1"]
|===
|品名 |単価 |数量 |金額

|A4 コピー用紙 |420 |30 |12600
|トナー |8900 |2 |17800
|ファイル |180 |50 |9000
|===

1回書くことから、3つのことが出てきます。

読む数式が1万個ではなく1本になります。同じ数式を1万のセルに写すと、誰かが
1行だけ手で書き替えても見つかりません。列に1本なら、読むのも確かめるのも
1回で済みます。

行を足すと、列は自分で埋まります。数式を下へ写し直す手間がありません。

数式がセルの番地ではなく列の名前を指します。`売上[単価]` はその値が何かを
言います。`C2` は場所しか言いません。

== 書き方

`df` の中に等号を1つ書きます。

    =df(<表>[<列>] = <数式>)

左辺が、定義する表と列の名前です。右辺が、その列の数式です。数式の中では、
どの表の列でも同じ `<表>[<列>]` の形で参照できます。

数式はシートのどのセルに書いても構いません。左辺に表の名前まで入っているので、
どこに書いても同じ定義として読めます。

== 書き替えではなく、定義です

`=df(売上[金額] = 売上[単価] * 売上[数量])` は「売上の金額は単価×数量である」
と言っています。どこか離れた場所のセルに値を書き込むのではありません。

だから、どのセルに書いても構いません。離れた表を書き替えるセルの数式は、
後から探すのが大変です。定義は、名前を書いた列に属します。

角かっこの形は Excel の構造化参照そのものなので、知っている書き方のまま
書けます。Excel との違いは、等号の左に置くと列の定義になる点だけです。

== いくつも並べて書く

読点で区切って並べます。

    =df(売上[金額] = 売上[単価] * 売上[数量],
        売上[税額] = 売上[金額] * 税率)

両方の列が表に足されます。

== 自分で決めた名前を使う

列にならない値にも名前を付けて、数式の中で使えます。

    =df(税率 = 0.1,
        売上[税額] = 売上[金額] * 税率)

これは Excel の「名前の定義」と同じ仕組みです。定義した名前は、ふつうの
セルの数式でも使えます。

== 計算の順番

順番は、何が何に依存するかで決まります。書いた順ではありません。

    =df(売上[税額] = 売上[金額] * 0.1,
        売上[金額] = 売上[単価] * 売上[数量])

税額を先に、金額を後に書いていますが、税額は金額を必要とするので、金額から
計算します。どちらの順で書いても答えは同じです。

== 断るとき

*同じ列を2回定義したとき。* `売上[金額]` を定義する式が2つあると、どちらも
使わずにエラーを出します。文言は列の名前と、2つの式の場所を言います。
どちらかを消せるようにするためです。

*ぐるぐる回るとき。* 金額が税額を必要とし、税額が金額を必要とすると、
エラーを出します。文言は、依存する順に列の名前を並べます。どこで輪が
閉じているかを読めるようにするためです。

*無い表や無い列を指したとき。* 見つからなかった名前を言ってエラーを出します。

エラーの文言は、セルの番地ではなく列の名前で言います。`売上[金額]` が
書いた物なので、文言もそれについて言います。

== 数式に入れられる値

数式が扱う値は4種類です。1つの値・列・表・関数の4つです。組み合わせ方の
規則は1つだけです。*どの関数の戻り値も、ほかのどの関数の引数にもなれます。*

だから `df` は定義した表を返し、その表をそのまま別の関数に渡せます。表を
平らに崩してから渡す、という段はありません。

== Python で書くと

1つの定義が、1つの `with_columns` になります。1対1です。

[source,python]
----
import polars as pl

売上 = pl.DataFrame({
    "品名": ["A4 コピー用紙", "トナー", "ファイル"],
    "単価": [420, 8900, 180],
    "数量": [30, 2, 50],
})
売上 = 売上.with_columns((pl.col("単価") * pl.col("数量")).alias("金額"))
----

名前の定義は、Python のふつうの変数になります。

[source,python]
----
税率 = 0.1
売上 = 売上.with_columns((pl.col("金額") * 税率).alias("税額"))
----

シート全体は「名前 = 数式」と「表[列] = 数式」の定義の集まりで、動く順番は
依存関係だけで決まります。表計算の再計算の考え方を、セルから列と名前へ
広げた形です。

== まだ決まっていないことが2つあります

*数式の中の累計。* 帳簿には残高の列があり、これは上の行までの金額の累計です。
`df` の数式の中でどの集計が使えるか、どう書くかは決まっていません。

*別の表から値を引き当てること。* `仕訳[科目名] = 科目表[名前]` と書くには、
2つの表をどのキーでつなぐかの決めが要ります。この決めはまだありません。

どちらも、帳簿の見本を作るときに現物で決めます。
