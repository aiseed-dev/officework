= 列で計算する

_元は英語版(link:../en/df-manual.adoc[df-manual.adoc])です。こちらは日本語訳です。_

*状態: 実装済み*

数式はふつう、1つのセルに属します。この冊子で説明する `df` は、数式を列に
属させる書き方です。見積書・注文書・帳簿のように、どの行も同じやり方で
計算する表を持っている人に向けた冊子です。

== 何をするか

数式を1回書くと、列が埋まります。

単価の列と数量の列がある売上の表を考えます。どの行も、金額は単価×数量です。
いまは、その数式を1つのセルに書いて下へ写します。`df` では1回だけ書きます。

    =df(売上[金額] = 売上[単価] * 売上[数量])

これで、表に金額の列ができます。

[cols="2,1,1,1"]
|===
|品名 |単価 |数量 |金額

|A4 コピー用紙 |420 |30 |12600
|トナー |8900 |2 |17800
|ファイル |180 |50 |9000
|===

1回書くことから、3つのことが出てきます。

読む数式が1万個ではなく1本になります。同じ数式を1万のセルに写すと、誰かが
1行だけ手で書き替えても見つかりません。列に1本なら、読むのも確かめるのも
1回で済みます。

行を足すと、列は自分で埋まります。数式を下へ写し直す手間がありません。

数式がセルの番地ではなく列の名前を指します。`売上[単価]` はその値が何かを
言います。`C2` は場所しか言いません。

== 書き方

`df` の中に等号を1つ書きます。

    =df(<表>[<列>] = <数式>)

左辺が、定義する表と列の名前です。右辺が、その列の数式です。数式の中では、
同じ表のほかの列を、同じ `<表>[<列>]` の形で参照します。

数式はシートのどのセルに書いても構いません。左辺に表の名前まで入っているので、
どこに書いても同じ定義として読めます。表は、そのシートにある表オブジェクトです
(「テーブルとして書式設定」で作った表)。

書いたセルには、定義した列の名前が出ます。`売上[金額]` のように出て、
2つ定義したなら `売上[金額], 売上[税額]` と並びます。値は表の側に入ります。

列が表に無ければ、表の右端に足します。見出しの行に列の名前を書き、表の
範囲を1列広げます。列が既にあれば、その列の各行を数式の値で埋めます。
その列にあった値や数式は、定義の値で置き替わります。

== 書き替えではなく、定義です

`=df(売上[金額] = 売上[単価] * 売上[数量])` は「売上の金額は単価×数量である」
と言っています。どこか離れた場所のセルに値を書き込むのではありません。

だから、どのセルに書いても構いません。離れた表を書き替えるセルの数式は、
後から探すのが大変です。定義は、名前を書いた列に属します。

角かっこの形は Excel の構造化参照そのものなので、知っている書き方のまま
書けます。Excel との違いは、等号の左に置くと列の定義になる点だけです。

== いくつも並べて書く

読点で区切って並べます。

    =df(売上[金額] = 売上[単価] * 売上[数量],
        売上[税額] = 売上[金額] * 税率)

両方の列が表に足されます。

== 自分で決めた名前を使う

列にならない値にも名前を付けて、数式の中で使えます。

    =df(税率 = 0.1,
        売上[税額] = 売上[金額] * 税率)

定義した名前は、同じ `df` の中の数式で使えます。ふつうのセルの数式や、
別のセルに書いた `df` からは使えません。

== 計算の順番

順番は、何が何に依存するかで決まります。書いた順ではありません。

    =df(売上[税額] = 売上[金額] * 0.1,
        売上[金額] = 売上[単価] * 売上[数量])

税額を先に、金額を後に書いていますが、税額は金額を必要とするので、金額から
計算します。どちらの順で書いても答えは同じです。

== 断るとき

*同じ列を2回定義したとき。* `売上[金額]` を定義する式が2つあると、どちらも
使わずにエラーを出します。文言は列の名前と、2つの式の場所を言います。
どちらかを消せるようにするためです。

*ぐるぐる回るとき。* 金額が税額を必要とし、税額が金額を必要とすると、
エラーを出します。文言は、依存する順に列の名前を並べます。どこで輪が
閉じているかを読めるようにするためです。

*無い表や無い列を指したとき。* 見つからなかった名前を言ってエラーを出します。

*列を足す場所が空いていないとき。* 表の右隣の列に値か数式があると、列を
足せません。その列の名前と、空いていない列(D 列など)を言ってエラーを
出します。

*エラーになった列を使ったとき。* 上のどれかでエラーになった列を右辺に
書いた定義も使いません。文言は、その列の名前を言います。

エラーの文言は、セルの番地ではなく列の名前で言います。`売上[金額]` が
書いた物なので、文言もそれについて言います。二重の定義だけは、消す方を
選べるように2つのセルの番地も言います。

[cols="1,2"]
|===
|場面 |文言

|二重の定義 |`売上[金額] を2回定義しています(F1 と F3)`
|循環 |`定義が循環しています(売上[金額] → 売上[税額] → 売上[金額])`
|無い表 |`表 仕入 が見つかりません`
|無い列 |`売上[原価] が見つかりません`
|足す場所が空いていない |`売上[金額] を足す場所(D 列)が空いていません`
|エラーになった列を使った |`売上[税額] は、エラーになった 売上[金額] を使っています`
|===

== 数式に入れられる値

右辺には、ふつうのセルの数式と同じ物を書けます。数・文字・セルの参照・
関数・同じ表の列です。同じ表の列は、その行の値として読みます。
`売上[単価]` は、2行目を計算するときは2行目の単価です。

`df` は定義した列の名前をセルに見せます。`df` の結果を別の関数に渡すことは
できません。

== Python で書くと

1つの定義が、1つの `with_columns` になります。1対1です。

[source,python]
----
import polars as pl

売上 = pl.DataFrame({
    "品名": ["A4 コピー用紙", "トナー", "ファイル"],
    "単価": [420, 8900, 180],
    "数量": [30, 2, 50],
})
売上 = 売上.with_columns((pl.col("単価") * pl.col("数量")).alias("金額"))
----

名前の定義は、Python のふつうの変数になります。

[source,python]
----
税率 = 0.1
売上 = 売上.with_columns((pl.col("金額") * 税率).alias("税額"))
----

シート全体は「名前 = 数式」と「表[列] = 数式」の定義の集まりで、動く順番は
依存関係だけで決まります。表計算の再計算の考え方を、セルから列と名前へ
広げた形です。

== まだ決まっていないことが2つあります

どちらも、帳簿の見本を作るときに現物で決めます。決まるまでは、書くと
エラーの文言で断ります。

*数式の中の累計。* 帳簿には残高の列があり、これは上の行までの金額の累計です。
`df` の数式の中でどの集計が使えるか、どう書くかは決まっていません。
今回は、右辺に `SUM` や `AVERAGE` のような集計の関数を書くと、
`df の中の集計はまだ使えません(売上[累計] の SUM)` と言って断ります。

*別の表から値を引き当てること。* `仕訳[科目名] = 科目表[名前]` と書くには、
2つの表をどのキーでつなぐかの決めが要ります。この決めはまだありません。
今回は、右辺に左辺と別の表の列を書くと、
`別の表の列はまだ引けません(科目表[名前])` と言って断ります。
