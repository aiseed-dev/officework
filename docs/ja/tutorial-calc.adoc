= 実例で覚える — Python で表計算を作る

コードを打てば、そのまま動きます。この頁のコードは test/ の受け入れ試験と
同じ物なので、**動かなくなったら検査が先に気づきます**。

officework の書き味は openpyxl と同じです。違いは import の1行だけ。
そして openpyxl にできないことが1つできます — **式の計算**です。

[source,python]
----
import openpyxl                  # openpyxl なら(式は計算されない)
wb = openpyxl.Workbook()

from officework import sheet     # officework なら(式を計算できる)
wb = sheet.Book()
----

== 第1回: 見積の計算をさせる

セルに値と式を入れ、計算させて、xlsx で保存します。

[source,python]
----
from officework import sheet

wb = sheet.Book()
ws = wb[0]
ws.title = "見積"

# 見出しの行
for j, label in enumerate(["品名", "数量", "単価", "金額"], start=1):
    ws.cell(1, j).value = label

# 明細 — 金額は式
items = [("ペン", 5, 100), ("ノート", 3, 150), ("消しゴム", 10, 80)]
for i, (name, qty, price) in enumerate(items, start=2):
    ws.cell(i, 1).value = name
    ws.cell(i, 2).value = qty
    c = ws.cell(i, 3)
    c.value = price
    c.number_format = "#,##0"
    ws.cell(i, 4).value = f"=B{i}*C{i}"

# 合計と消費税
ws.cell(6, 3).value = "小計"
ws.cell(6, 4).value = "=SUM(D2:D4)"
ws.cell(7, 3).value = "税込"
c = ws.cell(7, 4)
c.value = "=ROUND(D6*1.1, 0)"                 # お金は丸める
c.number_format = '"¥"#,##0'

wb.recalc()                                   # ここが openpyxl との違い
print("税込:", ws.cell(7, 4).value)           # → 1925

wb.save("見積.xlsx")
----

保存した 見積.xlsx には**式も計算した値も両方**入っています。
Excel で開けばそのまま式が生きていて、openpyxl で
`load_workbook("見積.xlsx", data_only=True)` と読めば値が取れます —
openpyxl 自身は計算できないので、値まで欲しいときにこの組み合わせが
効きます。

=== 覚えること3つ

. **セルは `ws.cell(行, 列)`。値も式も `.value` に入れる** — 式は
  `"=B2*C2"` のように `=` から書きます
. **`wb.recalc()` で計算する** — 式を入れ替えたら、もう一度呼びます
. **表示形式は `.number_format`** — `"#,##0"` で桁区切り、
  `'"¥"#,##0'` で円の印。**電話番号や品番は `"@"`**(文字列)にすると
  頭の 0 が守られます

=== よくあるつまずき

* 式を入れた直後に `.value` を読むと、まだ計算前です —
  先に `wb.recalc()` を呼んでください
* 行を挿すと式は自動で追います(`=SUM(D2:D4)` は挿した分だけずれます)。
  自分で書き替える必要はありません
* 小数の掛け算は、末尾に細かい誤差が付くことがあります
  (`1750*1.1` → `1925.0000000000002`)。**お金の式は `ROUND(式, 0)` で
  丸めてください** — 見た目だけ丸めて中身がずれたまま、を防ぐ
  事務の作法でもあります

== 第2回: 書式で整えて、様式の顔にする

第1回の見積に、題と罫線と色を付けて「渡せる紙」にします。
書式の道具(Font・Border・PatternFill・Alignment)は openpyxl と
同じ名前・同じ形です。

[source,python]
----
from officework import sheet
from officework.sheet import Font, Border, Side, PatternFill, Alignment

wb = sheet.Book()
ws = wb[0]
ws.title = "見積"

# 列の幅
for col, w in zip("ABCD", (16, 8, 10, 12)):
    ws.column_dimensions[col].width = w

# 題 — 3列を1つに結合して、大きく中央に
ws.merge_cells("A1:D1")
c = ws.cell(1, 1)
c.value = "御 見 積 書"
c.font = Font(size=16, bold=True)
c.alignment = Alignment(horizontal="center")

# 見出しの行 — 塗りと白抜きの太字と罫線
box = Border(top=Side(style="thin"), bottom=Side(style="thin"),
             left=Side(style="thin"), right=Side(style="thin"))
for j, label in enumerate(["品名", "数量", "単価", "金額"], start=1):
    c = ws.cell(3, j)
    c.value = label
    c.font = Font(bold=True, color="FFFFFF")
    c.fill = PatternFill("solid", fgColor="1B6E3C")
    c.alignment = Alignment(horizontal="center")
    c.border = box

# 明細 — 数字は右に寄せ、罫線で囲む
items = [("ペン", 5, 100), ("ノート", 3, 150), ("消しゴム", 10, 80)]
for i, (name, qty, price) in enumerate(items, start=4):
    ws.cell(i, 1).value = name
    ws.cell(i, 2).value = qty
    c = ws.cell(i, 3)
    c.value = price
    c.number_format = "#,##0"
    c = ws.cell(i, 4)
    c.value = f"=B{i}*C{i}"
    c.number_format = "#,##0"
    for j in range(1, 5):
        ws.cell(i, j).border = box

ws.cell(8, 3).value = "税込"
c = ws.cell(8, 4)
c.value = "=ROUND(SUM(D4:D6)*1.1, 0)"
c.number_format = '"¥"#,##0'
c.font = Font(bold=True)
c.border = Border(bottom=Side(style="double"))   # 締めは二重線

wb.recalc()
wb.save("見積2.xlsx")
----

=== 覚えること3つ

. **書式はセルに「物」を入れる** — `c.font = Font(...)`、
  `c.fill = PatternFill("solid", fgColor="1B6E3C")`、
  `c.border = Border(...)`。openpyxl と同じ書き方です
. **結合は `merge_cells("A1:D1")`** — 値と書式は左上のセルに付けます
. **罫線は場所ごとに** — `Border(top=…, bottom=…)` と `Side(style=…)` の
  組み合わせ。線の種類は thin・medium・thick・double・dashed などです

=== よくあるつまずき

* 色は `"1B6E3C"` のような 6桁の16進数で書きます(`#` は付けません)
* 結合した範囲の中のセルに書いても表示されません — 左上のセルに
  書いてください

== 第3回: 入力規則 — 打ち間違いを入り口で止める

台帳が汚れる一番の原因は打ち間違いです。セルに「入れてよい物」を
決めておけば、間違いは入る前に止まります。

[source,python]
----
from officework import sheet
from officework.sheet import DataValidation

wb = sheet.Book()
ws = wb[0]
ws.title = "受付"

for j, label in enumerate(["日付", "区分", "数量"], start=1):
    ws.cell(1, j).value = label

# 区分は一覧から選ばせる
kinds = DataValidation(type="list", formula1='"見積,注文,納品,請求"',
                       allow_blank=True)
kinds.promptTitle = "区分"
kinds.prompt = "一覧から選びます"
kinds.errorTitle = "区分が違います"
kinds.error = "見積・注文・納品・請求のどれかにしてください"
kinds.add("B2:B100")
ws.add_data_validation(kinds)

# 数量は 1〜999 の整数だけ
qty = DataValidation(type="whole", operator="between",
                     formula1="1", formula2="999")
qty.errorTitle = "数量が違います"
qty.error = "1 から 999 の整数で入れてください"
qty.add("C2:C100")
ws.add_data_validation(qty)

wb.save("受付.xlsx")
----

出来た 受付.xlsx を開くと、B列は▼から選べて、C列に 0 や 1000 を打つと
决めた文言で断られます。Excel でも aiseed office でも同じに効きます。

=== 覚えること3つ

. **規則を作って、範囲に掛けて、シートに載せる** — `DataValidation(…)` →
  `add("B2:B100")` → `ws.add_data_validation(…)` の3手。
  **範囲を決めてから載せます**(順が逆だと断られます)
. **一覧は `type="list"`** — 選択肢は `'"見積,注文,納品,請求"'` のように
  **全体を引用符で囲んだ1つの字**で渡します
. **入り口の文言も規則の物** — `prompt`(選ぶ前の案内)と `error`
  (断るときの文言)。黙って断らない様式は、それだけで使いやすくなります

=== よくあるつまずき

* `formula1='"見積,注文"'` の**外側の ' と内側の " は両方要ります** —
  内側の " が無いと、セルの範囲の名前と読まれます
* 規則は「これから入れる値」に効きます — 既に入っている値は
  そのままです(Excel と同じ)
