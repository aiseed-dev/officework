= 表の挿入

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

選んだ大きさの表を、本文の末尾に入れます。
セルをクリックすると中を書けます。

== ダイアログ

升が開きます。**上を動かして行×列を選びます。** 8行×8列まで選べます。

これより大きい表が要るときは、挿してから行や列を足してください。

== プログラムから

[source,python]
----
d.add_table(行, 列) / s.add_table(…)
----

他のライブラリでは、こう書きます。

[cols="1,2"]
|===
|道具 |書き方

|python-docx |`d.add_table(行, 列)`
|openpyxl |`ws.add_table(…)`
|===
