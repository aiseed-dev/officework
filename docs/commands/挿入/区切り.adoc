= 区切り

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

ここでページを分けます。押した段落の前で紙が変わります。

**節の区切りではありません。** Word や本家の「区切り」には、
ヘッダーや用紙の向きを途中から変えるための*節の区切り*も入っていますが、
このボタンが入れるのはページの区切りだけです。

節を足すのは、いまのところプログラムからだけです。

[source,python]
----
d.add_section("newPage")      # 新しい紙から始める節
d.add_section("continuous")   # そのまま続ける節
----
