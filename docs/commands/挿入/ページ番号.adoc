== 何をするか

いまのページ番号を差し込みます。紙にしたときに実際の数字になります。

== ダイアログ

選ぶものはありません。押した所にページ番号の印が入ります。

ヘッダーやフッターを開いていないときは、フッターが自動で開きます。

**位置や書式の選択はありません。** Word は挿す場所を選び、
「ページ番号の書式設定」で番号の形を変えられますが、
ここでは*カーソルのある所*に、そのままの数で入ります。
