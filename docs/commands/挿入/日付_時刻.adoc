= 日付/時刻

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

いまの日付か時刻を差し込みます。*打った時の字で固まります*。

== ダイアログ

選ぶものはありません。今日の日付が `2026年8月25日` の形で入ります。

**形式の一覧と自動更新はありません。** 打った時の字で固まります。
開くたびに日付が変わる様式が要るときは、
link:../ファイル/データを差し込む.adoc[データを差し込む]で入れてください。

== プログラムから

専用の呼び方はありません。こう書けば同じことができます。

[source,python]
----
p.text = date.today().strftime('%Y年%m月%d日')
----
