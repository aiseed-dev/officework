= 日付/時刻

挿入にあります。

*状態: 実装済み* — いま使えます

== 何をするか

今日の日付を、選んだ形で入れます。

== ダイアログ

形の一覧が出ます。西暦と和暦の両方から選べます。

....
2026年8月25日
2026/08/25
2026-08-25
令和8年8月25日
R8.8.25
....

**自動更新はありません。** 選んだ形の*固定の字*が入ります。
印刷した日に文書の日付が変わると、控えと合わなくなるためです。

日ごとに変わる日付が要る様式は、
link:../ファイル/データを差し込む.adoc[データを差し込む]で入れてください。

== プログラムから

専用の呼び方はありません。こう書けば同じことができます。

[source,python]
----
p.text = date.today().strftime('%Y年%m月%d日')
----
