= エクスポート

ファイルのページにあります。

*状態: 未実装* — *まだ使えません。* これから作ります。
いまは「名前を付けて保存」「印刷」「Web の形で書き出す(HTML)」に分かれています。

== 何をするか

いまの中身を、別の形にして書き出します。
*保存とは別の操作*です — 保存先は変わりません。

== ダイアログ

出る形を選びます。**選べるものは、いま見ている節の種類で決まります。**

[cols="1,2,2"]
|===
|形 |文章の節 |表の節

|`docx` |*出ます* — Word へ渡す |—
|`xlsx` |— |*出ます* — Excel へ渡す
|`html` |*出ます* — Web に載せる |*出ます*
|`pdf` |*出ます* — 刷る・体裁を固定して渡す |*出ます*
|`text` |*出ます* — 字だけ要るとき |—
|`csv` |— |*出ます* — 表を他の道具へ
|===

*一度に並ぶのは4つ*です。文章の節に xlsx は要らず、表の節に docx は要りません。

形を選ぶと、次に保存先を聞きます。

`.adoc` はここに出ません。*保存の側*だからです(この道具の元の形です)。
