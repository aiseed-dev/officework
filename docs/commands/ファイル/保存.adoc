= 保存

ファイルのページと、窓の上の段にあります。キーは `Ctrl+S` です。

== 何をするか

開いたファイルに書き戻します。
*開いたときの形のまま*保存します(docx で開いたものは docx のまま)。

**触っていない所は元のままです。** 読めなかった部品も、スタイルも、図形も、
変更履歴も、開いたファイルから持ち越します。

== ダイアログ

出ません。名前を決めたいときは「名前を付けて保存」を使います。

保存できないときは、画面の下に理由が出ます。
同じファイルを他の人が開いていると、上書きせずに止めます。

== プログラムから

[source,python]
----
d.save("報告書.docx")
b.save("売上.xlsx")
----
