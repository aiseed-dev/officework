= データを差し込む

ファイルのページにあります。
画面のボタンは「データを差し込む(CSV)」と出ています。

*状態: 実装済み* — いま使えます

== 何をするか

雛形に CSV の中身を流し込みます。
請求書や納品書のように、*頭と足は決まっていて明細の行数だけが変わる*書類で使います。

雛形にはこう書いておきます。

....
{宛名} 御中

|===
| 品名 | 数量 | 金額
| {明細.品名} | {明細.数量} | {明細.金額}
|===

合計 {合計} 円
....

`{名前}` はそのまま置き換わり、`{群.項目}` を含む*表の行は、データの数だけ増えます*。

== ダイアログ

CSV のファイルを選ぶ画面が出ます。

選ぶ前に、雛形の中の差し込む所を数えます。

* 差し込む所が無いときは、そう言って止めます
* 差し込む所が2つ以上あるときも止めます。*どれに流すかは決められません*

差し込んだ後、いくつの行を増やしたかが画面の下に出ます。
データに無い名前があったときは、その名前も出ます — *空にはしません*。

**元に戻せます。** `Ctrl+Z` で差し込む前に戻ります。

== プログラムから

まず、雛形にどんな名前があるかを引きます。

[source,python]
----
from officework import mcp

mcp.doc_merge_fields()      # ['宛名', '合計', '明細.品名', …]
----

名前と値の組を渡すと、開いている文書に入ります。

[source,python]
----
mcp.doc_fill({"宛名": "日本フネン株式会社", "合計": "1,440"})
----

1行につき1枚ずつ作りたいときは、繰り返しをプログラムの側に書きます。

[source,python]
----
for 行 in 明細:
    mcp.doc_fill(行, path="雛形.docx")
----
