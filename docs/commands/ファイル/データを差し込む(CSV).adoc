= データを差し込む(CSV)

ファイルのページにあります。

*状態: 実装済み* — いま使えます

== 何をするか

雛形に CSV の中身を流し込みます。
請求書や納品書のように、*頭と足は決まっていて明細の行数だけが変わる*書類で使います。

雛形にはこう書いておきます。

....
{宛名} 御中

|===
| 品名 | 数量 | 金額
| {明細.品名} | {明細.数量} | {明細.金額}
|===

合計 {合計} 円
....

`{名前}` はそのまま置き換わり、`{群.項目}` を含む*表の行は、データの数だけ増えます*。

== ダイアログ

CSV のファイルを選ぶ画面が出ます。

選ぶ前に、雛形の中の差し込む所を数えます。

* 差し込む所が無いときは、そう言って止めます
* 差し込む所が2つ以上あるときも止めます。*どれに流すかは決められません*

差し込んだ後、いくつの行を増やしたかが画面の下に出ます。
データに無い名前があったときは、その名前も出ます — *空にはしません*。

**元に戻せます。** `Ctrl+Z` で差し込む前に戻ります。

== プログラムから

[source,python]
----
d.render({"宛名": "日本フネン株式会社", "合計": "1,440"},
         rows={"明細": [{"品名": "ボールペン", "数量": "12", "金額": "1,440"}]})
----

1行につき1枚ずつ作りたいときは、繰り返しをプログラムの側に書きます。

[source,python]
----
for 行 in 明細:
    d = doc.Doc.open("雛形.docx")
    d.render(行)
    d.save(f"請求書_{行['宛名']}.docx")
----
