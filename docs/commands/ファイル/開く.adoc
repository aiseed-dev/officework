= 開く

ファイルのページにあります。キーは `Ctrl+O` です。

*状態: 実装済み* — いま使えます

== 何をするか

ファイルを選んで、編集画面に出します。
開いたものはタブとして並ぶので、*前に開いたものは閉じません*。
同じファイルをもう一度開いたときは、そのタブに移ります。

**docx を開くと、本文はこのアプリの持ち方に移し替わります。**
元のファイルはそのままですが、そこに書き戻すと同じ物には戻りません。
何が読めなかったかは右クリックの
link:../右クリック/この版で読み飛ばしたもの.adoc[この版で読み飛ばしたもの]に、
書き戻したときにどうなるかは link:保存.adoc[保存]に書いてあります。

== ダイアログ

ファイルを選ぶ画面が出ます。選べる種類は次のとおりです。

[cols="1,2"]
|===
|種類 |拡張子

|officework の文書 |`.adoc` `.asciidoc`
|Word 文書 |`.docx`
|===

表(`.sheet.adoc` `.xlsx`)を選んだときは、表の編集画面が開きます。
*どちらの画面になるかは、名前で決まります。*

== プログラムから

[source,python]
----
from officework import doc, sheet

d = doc.Doc.open("報告書.docx")     # 文書
b = sheet.Book.open("売上.xlsx")    # 表
----

読めなかった部品は `d.unsupported` に出ます。空なら全部読めています。
