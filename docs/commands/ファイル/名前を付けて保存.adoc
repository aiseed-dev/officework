= 名前を付けて保存

ファイルのページにあります。キーは `Ctrl+Shift+S` か `F12` です。

== 何をするか

名前と場所を決めて保存します。*保存した先が、以後の保存先になります。*

== ダイアログ

保存先を決める画面が出ます。選べる種類は次のとおりです。

[cols="1,2"]
|===
|種類 |拡張子

|officework の文書 |`.adoc`
|Word 文書 |`.docx`
|===

*拡張子で形が決まります。* `.adoc` を選べば AsciiDoc、`.docx` を選べば Word 文書になります。

== プログラムから

[source,python]
----
d.save("別の名前.docx")
----
