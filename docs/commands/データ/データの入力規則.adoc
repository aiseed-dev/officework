= データの入力規則

データタブにあります。

== 何をするか

セルに入れてよい値を決めます。
決めた範囲から外れた値を打つと、そう言って止めます。

== ダイアログ

3つを順に聞きます。

=== 1. 何を確かめるか

[cols="1,2"]
|===
|種類 |意味

|すべての値 |確かめません(規則を外すときに選びます)
|整数 |小数点のない数だけ
|小数 |数なら何でも
|リスト |決めた候補の中から選ぶ
|文字列の長さ |字の数で確かめる
|===

=== 2. どう比べるか

「整数」「小数」「文字列の長さ」を選んだときに聞きます。

* 次の値の間 / 次の値の間以外
* 次の値に等しい / 次の値に等しくない
* 次の値より大きい / 次の値より小さい
* 次の値より大きいか等しい / 次の値より小さいか等しい

「次の値の間」を選んだときは、下と上の2つを打ちます。
それ以外は1つです。

「リスト」を選んだときは、候補をカンマ区切りで打ちます。

=== 3. 何を出すか

入れる前に出す案内と、外れたときの断りの文を決められます。
どちらも空のままで構いません。

断り方は3つから選びます。

[cols="1,2"]
|===
|止め方 |どうなるか

|停止 |入れられません
|警告 |「このまま入れますか」と聞きます
|情報 |知らせるだけで、入ります
|===

== プログラムから

[source,python]
----
s.add_data_validation(…)
----

規則は xlsx と行き来します。判定できない規則も、消さずに持ち越します。
