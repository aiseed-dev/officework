= CSV の形

データにあります。

== 何をするか

読み書きするときの区切りと文字コードを決めます。

== ダイアログ

形式を6つから選びます。

[cols="1,2"]
|===
|選べる値 |区切り

|UTF-8(BOM付き) |カンマ(*既定*)
|Shift_JIS(CP932) |カンマ
|UTF-8(BOMなし) |カンマ
|UTF-8(BOM付き) |タブ
|Shift_JIS(CP932) |タブ
|UTF-8(BOM付き) |セミコロン
|===

読み込みと書き出しで同じ6組を使います。
**列の型の指定はありません。** Excel は読み込むときに
「テキスト インポート ウィザード」の3段目で列ごとの形式を選べますが、
ここにはその画面がありません。

**Excel とは既定が違います。** ここは UTF-8(BOM付き)から始まります。
Excel で「CSV (コンマ区切り)」を選ぶと、日本語版では Shift_JIS になります。
Excel 側で UTF-8 にしたいときは「CSV UTF-8」の形式を選んでください。
