データにあります。

== 何をするか

読み書きするときの区切りと文字コードを決めます。

== ダイアログ

形式を6つから選びます。

[cols="1,2"]
|===
|選べる値 |区切り

|UTF-8(BOM付き) |カンマ(*既定*)
|Shift_JIS(CP932) |カンマ
|UTF-8(BOMなし) |カンマ
|UTF-8(BOM付き) |タブ
|Shift_JIS(CP932) |タブ
|UTF-8(BOM付き) |セミコロン
|===

読み込みと書き出しで同じ6組を使います。
**列の型の指定はありません。** Excel は読み込むときに列ごとの型を選べますが、
ここにはその画面がありません。

**既定が UTF-8 なのは Excel と違います。** Excel の既定は Shift_JIS です。
