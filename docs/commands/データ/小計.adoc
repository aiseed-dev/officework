= 小計

データにあります。

*状態: 実装済み* — いま使えます

== 何をするか

同じ値のかたまりごとに、合計の行を挟みます。

== ダイアログ

3つ選びます。

* *グループ化する列* — 見出しから選びます
* *集計する列* — 複数選べます
* *集計方法* — 合計・平均・個数・最大・最小 など

**グループは1つだけ**です。Excel のように小計の中にさらに小計を作る、
多段の形はありません。

== プログラムから

専用の呼び方はありません。こう書けば同じことができます。

[source,python]
----
s['A9'] = '=SUBTOTAL(9,A2:A8)'
----
