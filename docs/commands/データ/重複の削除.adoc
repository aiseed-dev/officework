= 重複の削除

データにあります。

*状態: 実装済み* — いま使えます

== 何をするか

同じ中身の行を1つだけ残します。

== ダイアログ

2つ選びます。

* *比べる列* — チェックで選びます。既定は全部の列です
* *先頭行は見出し* — チェック。既定は入っていません

Excel の「重複の削除」と同じ形です。

== プログラムから

専用の呼び方はありません。こう書けば同じことができます。
画面と同じ2つ — *比べる列* と *先頭行は見出し* — をそのまま書きます。

[source,python]
----
見出しあり = True
比べる列 = [0, 2]              # 何も指定しなければ全部の列

見た = set()
残す = []
for i, 行 in enumerate(s.rows()):
    if 見出しあり and i == 0:
        残す.append(行)
        continue
    組 = tuple(行[c] for c in 比べる列)
    if 組 not in 見た:
        見た.add(組)
        残す.append(行)
----
