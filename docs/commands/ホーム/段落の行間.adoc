= 段落の行間

ホームにあります。

*状態: 実装済み* — いま使えます

== 何をするか

行と行の間を広げます。押すたびに 1.0 → 1.5 → 2.0 と回ります。

**Word や本家とは決め方が違います。** あちらは「最小値」「固定値」「倍数」から
選んで数を打ちますが、こちらは*倍数の3択*だけです。
段落の前後の空きも、このボタンでは変えられません。

細かく決めたいときは、プログラムから書いてください。
