= 紙に収める

レイアウトにあります。

*状態: 実装済み* — いま使えます

== 何をするか

何ページに収めるかを決めます。

== ダイアログ

5つから選びます。

* 拡大縮小しない
* すべての列を1ページに
* すべての行を1ページに
* シートを1ページに
* 横2ページ×縦1ページ

**任意の倍率はありません。** Excel は拡大率を % で打てますが、
ここではよく使う型から選びます。
