= calc の手引き

_元は英語版(link:calc-manual.adoc[calc-manual.adoc])です。こちらは日本語訳です。_

officework の表の編集画面の手引き。
ブック(.sheet.adoc)も xlsx も開いて、直して、保存する。
式も計算する。

このマニュアルには**いま動くことだけ**を書く。
リボンにグレー表示で並んでいるコマンドは未実装で、押せない(できないものを、できるように見せない)。
グレー表示のものと Python での代替はlink:#未実装のものグレー表示と代替[巻末]に。

3つの約束:

* *書式は据え置き。* 開いた帳票の罫線・結合・列幅・図形・テーマは、保存しても壊れない(理解しない部品は原文のまま持ち越す)
* *どの操作も1手で戻せる。* 迷ったら Ctrl+Z
* *黙って落とさない。* 読めないもの・保存で失われるものはステータスバーで言う

== 起動

[source,bash]
----
./target/release/officework            # 前回の姿で開く(初回はフォルダを選ぶ)
./target/release/officework 帳票.xlsx  # ファイルを指定して開く
----

日本語フォントが機械に無いと起動しない(`fonts-noto-cjk` か``fonts-ipaexfont`` を入れる。
`OFFICE_FONT=/path/to/font.ttf` で明示も可)。

== 画面

画面の枠はデスクトップ版の形。
**1段目**が保存・印刷・戻す・やり直しとブック名(未保存は \* 印。
この行を掴むと窓が動く)、**2段目**が白地のタブ(現在地は緑の下線。
右端の 🔍 = 検索と置換)。
リボンのボタンは本家と同じ**一段のアイコンボタン**(主要なボタンはラベルつき。
ボタンに乗ると名前が下のステータスバーに出る。
ホームだけ2段)。
*ファイルタブは全面のページ* —左のメニュー(新規作成・開く・最近開いた・保存・名前を付けて保存・印刷・保護する・詳細情報・ファイルの場所を開く・終了)と、右に「ブックの情報」(統計と、xlsx の情報 = 作成者・タイトルなど。
*欄を押して打ち、Enter で控える* — 保存で xlsx の docProps に入り、Excel でも見える)。
**作成者は何人でも**書ける — 「＋ 著者を追加」で1人ずつ足し、名前の右の × で外す(xlsx では `;` で継いだ1つの欄になる。
Excel の書き方と同じ)。
その下の**カスタムプロパティ**は、決まった欄では足りないものを自分で足す所。
「プロパティを追加」を押すと**名前 → 型 → 値**の順に訊く(型は文字・数・日付・はい/いいえ の4つ。
空 Enter で文字)。
値まで打って初めて足すので、途中でやめれば何も残らない。
外すのは行の ×。
他所で付けた見慣れない型の値も**消さずにそのまま持ち越す**(打ち直しはさせない)。
鎖の印が付いた項目は Excel の「内容にリンク」で、こちらは繋ぎ直さないが外しもしない。
「最近開いた」は12件残る。
タブの並びは Euro-Office と同じ:*ファイル / ホーム / 挿入 / 描画 / レイアウト / 数式 / データ / ピボットテーブル /表のデザイン / 共同編集 / 保護 / 表示 / マクロ*(本家の全タブ。
「プラグイン」は 2026-08-16 に**マクロ**へ改名 — 使う人の言葉に寄せた)。
*インターフェイステーマ*(表示タブ)で画面を暗くできる —*セルは白のまま*(画面と紙の一致を守る)。
**下端**がステータスバー — シートタブ、操作の結果・警告・エラー、そして範囲を選ぶと**合計・平均・個数**がリアルタイムで出る(Excel の下端と同じ)。
保護したシートのタブには 🔒 が付く。

*表示タブ*(本家デスクトップ版に合わせた): 拡大・縮小(50〜200%。
セルも文字も一緒に伸縮 — 紙は変わらない)、数式バーの表示/非表示、枠線表示、見出し(行番号・列名。
消すと表だけの見た目になる)、0を表示する(0 の値を隠す — **見え方だけ。
値は 0 のまま**で式にも効く)。
枠の固定・シートの表示(隠しシートを戻す/隠す)・インターフェイステーマ(画面の明暗)もここ。

=== マウス

* クリックで選択、ドラッグで範囲選択、Shift+クリックで起点から拡張
* 行番号・列名の見出しをクリックで行・列ごと選択
* 見出しの境界をドラッグで列幅・行高の変更
* ハイパーリンクは Ctrl+クリックで開く
* テキストボックス(と文字を入れた図形)は、選ぶと図形の設定パネルに**「中の文字」**の段が出る — 横の揃え(左/中央/右)、縦の位置(上/中央/下)、箇条書き(なし/・/1.)、縦書き、取り消し線、上付き・下付き。xlsx と往復するので Excel でもそのまま見える。*タブ位置は無い*(文字を1枚の面で出しているので、位置を守って描けない)
* 図形はドラッグで移動、右下の角で大きさ変更、*枠の上の丸をドラッグで回転*(Shift で15度刻み)。選ぶと右に**図形の設定**のパネル(塗り・線の色と太さ・不透明度・回転/反転・影)。*Ctrl+クリックで複数選択* →右クリック→整列で 揃え(2個から)・分布(3個から)。右クリックには切り貼り・配置(前面/背面)・SVG で保存もある。Del は選んだ分まとめて削除

== 式と関数

`=` で始めると式。
四則(`+ - * /`)、比較(`= <> > >= < <=`)、範囲(`A1:B3`)、絶対参照(`$A$1`)、定義した名前が使える。
編集すると自動で再計算され、循環参照は検出してエラーになる(黙らない)。

*串刺し集計*: `=SUM(4月:6月!B2)` で、**ブックの並び順**で2枚の間にある全シートの同じ場所を集める(タブを並べ替えれば集める範囲も変わる)。

*別のシートの参照*: `=4月!B2` のように直接書ける(範囲は `=SUM(4月!B1:B5)`、空白や記号を含む名前は `='4月 実績'!B2`)。
知らないシート名は *#REF!* —黙って自分のシートと読むことはしない。
別シートの値は**その時の値を写す**ので、参照先を直したら再計算(F9)で追いつく。
シート名を変えると式の中の``古い名前!`` も書き換わる(ただし `INDIRECT("古い名前!A1")` の**文字列の中は追随しない** — Excel も同じで、INDIRECT は「動かない参照」を作る道具だから)。
**追随しなかった数は改名のとき状態行で言う**ので、手で直せる。

実装済みの関数は**約185**(新しい別名を含む)。

「トレース矢印の削除」で消える)、数式の表示。

名前は英数字と `_`(先頭は文字。
セル参照の形は不可)。

== 書式

* 文字: 太字・斜体・下線・取り消し線・*下付き*・文字色・書体・大きさ
* *書体の欄はコンボ*: 押すと一覧が開き、開いた時は今の書体の位置に居る。打つほど絞られ(日本語名でも英語名でも引ける)、↑↓で選び Enter で確定、Esc で閉じる。一覧の各項は**その書体で描く**ので見た目で選べる。一覧の頭に**最近使った書体**が出る。一覧に無い書体名も打って確定できる(リボンの書体一覧は**この機械にあるフォント**)
* *大きさの欄もコンボ*: 一覧は 6〜72pt の17段。自由に数を打つと4〜409pt・0.5 刻みに**黙って丸めて**掛かる(丸めは画面の入力だけ —よそで作った半端な大きさはそのまま往復する)。*大きく/小さく*(+/−)は一覧の値を1段ずつ辿る(半端な大きさは隣の一覧値へ寄り、端では止まる)
* セル: 塗りつぶし(単色のほかに**柄**6種と**グラデーション**4向き。塗りのパレットの下にある。*色を選ぶとべた塗りに戻る*。柄の地の色は「柄の地の色…」で。Excel の柄は 18 種あり読み書きはどれも通るが、画面で描き分けられない柄(横線・縦線など)は一覧に出していない —そういう帳票を開いたときは濃さで見せる)、罫線(上下左右を独立に)、縦横の揃え(**両端揃え**を含む)、折り返し、*文字の向き*(押すたびに縦向き → 縦に積む → 戻る。日本の帳票の縦の見出しに)
* *図形の足し引き*: 2つ選んで(Ctrl+クリック)右クリック→「図形を結合」から結合・交差・減算。減算は**主(先に選んだ方)から控えを引く**。中を抜くと穴のあいた形になる。*結果は自由な形になり、元の形と回転は戻りません*(押したときにそう出ます)。輪郭を点で取れない形(吹き出しなど)は断ります
* *ポイントの編集*: 点で作る図形(自由な形・ペンの線・スパークライン)は、右クリック→「ポイントの編集」で頂点をつまんで動かせる。**Ctrl+クリック**で頂点の追加・削除、**ダブルクリック**で角と曲線の切り替え。曲線にすると制御点の丸が出て、つまむと曲がり方が変わる。自由な形は 挿入→図形→線→「自由な形(点で作る)」から。xlsx にベジェのまま残るので Excel でも曲線
* *スパークライン*: 選ぶと図形の設定パネルで色・線の太さのほか、*点の印*(高点・低点・最初・最後)を入切できる。空セルの扱いと縦軸のそろえはありません — この線は挿したときの数を焼き付けているので、元データを引き直す設定は掛かりません(パネルにもそう出ます)
* *コメント*: 右クリック→コメントを追加。付いたセルを右クリックすると**返信を追加**と**解決済みにする**が押せる(コメントの無いセルでは灰色)。返信も解決の印も xlsx に残り、Excel でもスレッドとして見える。誰が書いたか・いつ書いたかも往復する
* *右横書き*(ホーム): セルの中を1字ずつ右から並べる。*日本語の右横書き*(昔の看板・横額)のための機能で、ラテン文字の双方向(bidi)は扱わない
* *シートの方向*(レイアウト): 列を右から左へ並べる(右横書きの帳面)
* *セルのスタイル*(ホーム): 見出し・表題・良い/悪い/どちらでもない・メモ・計算・通貨・パーセント。選ぶと選択に書式が掛かる(Ctrl+Z で戻る)
* *テーマ色*: 今どきの Excel は色を「テーマの何番目 + 明るさの加減」で持つことがある。それを読んで実際の色に解くので、*色が消えない*。*配色の変更*(レイアウト)で色の組(Office / 暖色 / 寒色 / 墨)を入れ替えると、テーマ色を使っているセルの色が**そのまま追従する*
* 表示形式: 桁区切り・小数桁の増減・% ・通貨
* セル結合(隠れた値は消えない)
* *条件付き書式*: 「〜より大きい / 小さい / 等しい」で文字色・塗りを変える(cellIs 型。xlsx と往復する)
* *入力規則*(データタブ): リスト型。候補は直書き(`甲,乙,丙`)か範囲参照(`=D2:D5` — 参照先を書き換えれば候補も追従)。規則に合わない入力はセルに入らず Esc で戻る。別シート参照など解決できない規則ではブロックしない(通して警告しない)。list 以外の型は読めない旨を報告する
* *表のデザイン*(表のデザインタブ): 範囲を選んで1手ずつ掛ける道具 —ヘッダー行(1行目に色を敷く)・縞模様の行 / 列・最初 / 最後の列(太字)・*合計行*(下に =SUM の行を足す。式なので元が変われば追従。下に中身があれば断る)・フィルタのボタン(絞り込みと同じ)。表は**表オブジェクト**(名前の付いた範囲)として持つので、*範囲に変換する*(表を外す。見出し行の色や縞模様の書式と式はそのまま残る — Excel と同じ)と**テーブルのサイズ変更**(ダイアログで A1:C9 のように新しい範囲を打つ)もできる。表は xlsx の table として保存され、Excel でも表として見える。まとめて掛けるなら挿入タブの「表の挿入」(表オブジェクトも一緒に作る)

== シート・データの操作

* *複数シート*: 追加・削除・名前の変更・切り替え
* *行・列の非表示*: 見出しを右クリック →「非表示」。戻すときは**隠れた分を挟むように**見出しを選んで「再表示」。畳んだ状態は xlsx に残る(グループ化と同じ器)ので、隠したまま次の人に渡る。*使っている分を全部は隠せない*(戻す道が見えなくなるため断る)
* *枠の固定*(表示タブ): カーソルの上の行・左の列を固定。もう一度で解除
* *フィルター*: セルの値で絞る(見た目だけ。中身は変わらない)。解除も1手
* *並べ替え*: 列単位の昇順・降順。見出し行は据え置き
* *重複削除*(データタブ): 件数を確認してから消す
* *テキストからデータ*(データタブ): CSV/TSV をいまのセルから流し込む。文字コード(CP932 含む)と区切りは自動判定
* *外部リンク*(データタブ): 他のブックの値を**値として**取り込む。参照は張らない — リンク切れの帳票を作らないため
* *データテーブル*(データタブ): 入力値を差し替えながら式の答えを表に埋める感度表。四角い範囲を選んで押すと、列の入力セル → 行の入力セル(空 Enter = 1変数)を聞く。*表の形は Excel と同じ* — 1変数は「左の列に入力値・上の行に式・角は空」、2変数は「角に式・左の列と上の行に入力値」。計算はブックの複製の上でやるので本物の入力セルは荒れない。**その時の値**を埋めるので、入力を直したらもう一度押す
* *ゴールシーク*(データタブ)
* *ソルバー*(データタブ): ONLYOFFICE と同じ「ソルバーのパラメータ」のダイアログ。目的のセル(最大/最小/値)・変数セル(範囲かカンマ区切り、最大64個)・制約(左辺セル / <= = >= / 右辺の数かセル)を決めて「解を求める」。解法は**単体法 LP**(裏方 scipy)。係数は表の複製から測り、*線形でなければ断る*(本家と同じ)。解は変数セルに書かれ、Ctrl+Z の1手で戻る
* *小計*(データタブ): 見出し付きの表を範囲で選んで押すと、区切りの見出し(例: 部署)→ 合計する見出し(空 Enter = 数の列全部)の順に聞かれ、区切りごとに「〜 小計」(=SUM)の行と最後に総計の行が入り、**明細だけ**がグループ化される。*詳細の非表示で畳むと、小計と総計だけが残る*。式なので明細を直せば追従する。先に並べ替えておくと区切りがまとまる(Excel と同じ)。全部まとめて Ctrl+Z の1手
* *グループ化*(データタブ): 行の見出し(番号)を撫でて選んでから「グループ化」。**詳細の非表示**で畳み、**詳細の表示**で開く(選択なしならカーソルの行が属するグループひとつながり)。列の見出しを選べば列にも効く。もう一度グループ化すると深さが増える(7段まで)。深さと畳みは xlsx のoutlineLevel / hidden と往復するので、Excel で開くと普通のアウトラインに見える。畳んだ行・列は印刷(PDF)にも出ない。絞り込みと違って**保存に残る** — 畳んだ台帳は畳んだまま渡る。畳んだときに合計を見せたいときは、手で行を選ぶより上の「小計」が早い。かたまりの直後の行の見出しには **+/− の丸印**が出て、押すだけで畳んだり開いたりできる(Excel のアウトラインの縁と同じ)
* *ピボットテーブル*(ピボットテーブルタブ): 見出し付きの表を範囲で選んで「挿入」を押すと、行に並べる見出し(複数可)→ 列に広げる見出し(省略可)→ 値と集計(合計/平均/個数/最大/最小)の順に聞かれる。裏方の polars が集計し、結果は**その時の値**として元の表の右の空きに置かれる(埋まっていればさらに右へ — 黙って上書きしない)。定義はブックに控えるので(独自部品 xl/joPivot.xml)、元の表が変わったらピボットの上にカーソルを置いて**更新**(すべて更新はブック全部)。*総計*(行と、列に広げていれば列も)・*小計*・*空行*(行の見出しが2つ以上のとき)・*レポートのレイアウト*(表形式 ⇔ コンパクト)は押すたびに切り替えて置き直す。**計算の種類**は そのまま/比率(総計を100%とした %)/累計/前との差 の4択 — *累計と差は小計・総計を落とす*(積み上げの途中に総計が挟まると読み違えるため)。**選択する**はピボット全体の選択。集計はどの操作でも polars が元データからやり直すので、平均の総計も正しい(行の平均の平均ではない)。どれも Ctrl+Z の1手。Excel で保存し直すと定義の部品は消える — その後は「更新」できない、ただの値の表になる(正直な劣化)
* *コメント*: セルに1件。空で Enter すると消える。保存で xlsx に残る

== 挿入

* *表の挿入*: 罫線と見出し付きの表の枠を一括で作る
* *画像*: PNG / JPEG。図形は**分類から選ぶ2段の一覧**(基本図形・ブロック矢印・数式図形・フローチャート・星とリボン・吹き出し・線の7分類、全 37 種。中に文字も書ける)、記号、テキストボックス、スパークライン。Excel で作った帳票の図形も、こちらが作図を持つ形はその形で出る。持たない形は四角で見せ、*開いたときの報告でそう言う*(保存では元の形のまま)
* *グラフ / 推奨チャート*: 選択範囲を裏方の matplotlib が描いて、画像としてシートに浮かべる(1列目が項目名、2列目以降が系列。先頭行が見出しなら系列名になる)。日本語フォントは機械のものを登録するので豆腐にならない。Python が見つからないときはステータスバーが手順を言う
* *SmartArt*: 分類(リスト / プロセス / 循環 / 階層 / 関係 / マトリックス /ピラミッド)→ 形、の順に選ぶ。分類・並び・名前は Euro-Office の現物と同じ。入るのは**図形の集まり**なので、各図形を選んで Enter で文字、ドラッグで移動、Del で削除ができ、全部まとめて Ctrl+Z の1手で戻る。xlsx へは普通の図形として入る(Excel でも図形として見える。本物の SmartArt 部品ではない — そのぶん、どの道具でも開いて直せる)。一覧には**この方式で組める形だけ**を出している
* *テキストアート*: 飾り文字。文字を打つと太字+縁取りで描いて、画像としてシートに浮かべる(裏方 matplotlib。方程式と同じ道)
* 描画タブの**ペン・蛍光ペン・消しゴム**: 押してツールを出し、表の上をドラッグすると線が引ける(ペンは細い黒、蛍光ペンは太く薄い黄)。消しゴムは線をなぞると**1筆ずつ**消える。もう一度同じボタンか Esc でセルの操作に戻る。線は**普通の図形(折れ線)として保存される**ので、Excel でも線に見え、Ctrl+Z で1手ずつ戻り、印刷(PDF)にも出る
* *チェックボックス*: 空のセルに置くと ☑/☐ になり、*空白キーで切り替わる*(値は TRUE/FALSE — 式から `=E4` や `=COUNTIF(E:E,TRUE)` で普通に使える)。TRUE/FALSE の値を持つセルはどれも ☑/☐ で見える。中身のあるセルは潰さない。Excel で開くと TRUE/FALSE の値で見える(部品の書式は書かない)
* *スライサー*: カーソルの列の値がボタンで並ぶパネル。押すとその値の行だけに絞れる(≡ で複数選択、✕ で解除、Esc で閉じる)。絞り込みと同じく**見え方だけ** — 保存される中身は変わらない
* *方程式*: 数学の式の清書(セルの計算式とは別物 — 計算はしない)。TeX の書き方で打つと(例: `\frac{a}{b}`、`\sum_{i=1}^n i^2`)、裏方のmatplotlib(mathtext)が清書して画像として置く。読めない式はそう言って断る。Microsoft 日本語版の「数式」と同じ機能で、名前はEuro-Office の訳語(方程式)に合わせている
* *ハイパーリンク*: 右クリックまたは挿入タブ。空で Enter すると消える

== 自分の AI から calc を操る(MCP)

**向きが逆の道**もあります。
calc が AI を呼ぶのではなく、*あなたが使っている AI*(Claude Code / Claude Desktop など、MCP を話す物なら何でも)がcalc を道具として使う形です。

----
pip install "officework[mcp]"
----

AI の客に `officework-mcp` を登録すると、こう言えます:

[NOTE]
====
「いま開いている表の B 列を合計して、下に置いて。見出しは太字にして」
====

*calc が動いている必要があります。* 動いていなければ、そう言って断ります。

渡している道具は8つだけです — ブックの様子 / 使っている範囲 / 値を読む /式を読む / 値を書く / 書式を掛ける / 幅を合わせる / 保存。

* *任意のコードを走らせる道具は置いていません。* 「Python を実行」を1つ置けば何でもできてしまい、許した範囲を越えます
* ファイルを開く道具もありません — 何を開くかは人が calc の側で決めます
* 保存は頼まれたときだけ。勝手に上書きしません

この道なら、**AI の枠を使うのはあなたとその AI の製品の間**の話になり、officework は表計算の道具を差し出すだけです。

== AI — 左パネルで相談する

*2026-08-15、AI タブは無くなりました。* 10 個のボタン(要約・書き直す・敬語にする・…)は、**左パネルの会話**に置き換わっています — 「この表を売上の多い順に並べて」と打てば済み、ボタンでは作れない頼み方(「表にして、列は日付と金額で」)もできるからです。

開き方: *表示タブ > 左パネル*。

* **選んでいる範囲が相談の相手**になります(選んでいなければ、範囲の要らない用件として通ります)
* *表を直す頼みは、officework の Python のスクリプトにして見せます。押すまで走りません* — 中身を読んでから「入れる」を押して初めて表が変わります。走った跡は **Ctrl+Z 一手**で戻せます
* 表を直さない頼み(意味を訊く・式を1つ教える)は、そのまま答えます
* *やりとりは続きます*(2026-08-16)。「さっきのを今度は昇順に」が通ります — 直近3往復を添えて頼んでいます
* *落ちたら「直してもらう」。* スクリプトが失敗すると、出た誤りがそのまま会話に出て、一押しで直したスクリプトを頼めます。走らせて、落ちたら直す —これを繰り返せます
* **「新しい会話」**で話を畳めます(表は触りません)
* **宛先は欄の下**で替えられます(詳細設定まで行かずに済みます)

スクリプトという形にしているのは、AI がいちばん正確に書ける形であり(xlwings と openpyxl の形)、**人が読んで確かめられる**からです。

**宛先の選び方**は ファイル > 詳細設定 の「AI の宛先」に移りました。
押すたびに 手元のモデル → *Claude Agent* → *OpenAI Codex* → Claude(API)と回ります。

* *Claude Agent* — Anthropic の Agent SDK 経由。`pip install claude-agent-sdk` だけで足ります(実行体は SDK が同梱)
* *OpenAI Codex* — 手元の `codex` を呼びます(`npm i -g @openai/codex`)。**その CLI が持っている認証をそのまま使う**ので、ChatGPT の契約でも動きます。入れたあと一度 `codex` を起こしてサインインしてください
* *Claude(API)* — API を直に叩きます。Python も要りません

*Claude の2つは `ANTHROPIC_API_KEY` が要ります。* Anthropic は、第三者の製品が claude.ai のログインと枠を提供することを事前の承認なしには許していないので、こちらは API キーでの認証だけにしてあります(承認は別途取りに行く前提です)。

使えない宛先なら**その場で理由**を言います。

=== 会のサーバーを1台立てる(API キーを1本にまとめる)

*既定の「手元のモデル」の宛先は、自由に変えられます。* 会で1台だけサーバーを立てて全員がそこを向けば、API キーの管理も請求も1箇所で済みます。
その先で何を動かすか(手元のモデルでも、どこかの API への中継でも)は運用する人が決めることで、officework は **OpenAI 互換の口**を叩くだけです。

`~/.config/officework/settings.toml` に1行:

[source,toml]
----
ai_url = "https://ai.example.org/v1/chat/completions"
ai_model = "gpt-oss-120b"
----

* *`https://` にすると暗号が掛かります。* 会の外へ出す文書を平文で流さないでください(`http://` は手元の 127.0.0.1 のときだけ)
* API キーが要るサーバーなら、*環境変数 `OFFICE_API_KEY`* に置きます(設定ファイルにも文書にも API キーは書きません)
* その場だけ変えたいときは環境変数 `OFFICE_URL` が優先します
* いまの宛先と「外へ出るかどうか」は、この画面の**手元のモデルの宛先**の行に出ています

よく使われる置き場の例: Ollama は `11434`、llama.cpp server は `8080`、LM Studio は `1234`。
どれも `/v1/chat/completions` です。

繋がらなければ「できません」と言います(黙って空にしません)。
*API キーがブックに入ることは決してありません*。

== セルの文字は AsciiDoc

文字列のセルは **AsciiDoc として描かれます**(writer の本文と同じ書き方 — 覚えるのは1つです)。
セルが持つのは平文のままで、解釈するのは画面に描くときだけです。

----
これは**太字**です                    → これは太字です
__斜体__ ``等幅`` [.line-through]##取消線##
https://…[こちら] を見て              → 青い下線のリンクになる
= 見出し   == 中見出し   === 小見出し
* 甲      . 一つめ(番号は書かない — 続けて打つと 1. 2. と出る)
----

* **リボンのボタンで足ります。** 何も選ばずに押せばセル全体、**編集中に字を選んで押せばその字だけ**に効きます(選んだ所に印が入る。もう一度押せば外れる)。印を自分で打っても同じです
* **印は二重が確実です。** 一重(`*太字*`)は語の外でしか効かないので、語の間に空白の無い日本語の文中では効きません(欧文の `this is *bold*` は効く)
* `=` の後ろに空白が**無ければ式**です(`=SUM(A1)`)。空白が**あればセルの見出し**です(`= 大`)
* セルが持つのはいつも平文 — 数式バーにも Python にも、印ごとそのまま見える
* *xlsx へは平文のまま入る*。往復で絶対に化けない(Excel では記号がそのまま見える — 正直な劣化)
* *選んでいるセルは生の文字を見せる*(打ち直せるように)
* 見出しや箇条書きを縦に積むには、セルを**折り返し**にする(折り返しの無いセルは今までどおり改行を空白に畳む)
* 和文の書体は斜体の面を持たないので、`__斜体__` は日本語では傾かない(印は外れる。欧文は傾く)
* *見出しの大きさは型紙で決める* — ブックの名前付きセルスタイル「見出し 1 / 2 / 3」を見る。型紙(.xltx)に定義しておけば、そこから作ったブック全部に効く(Excel で編集しても追随する)。無ければ既定の1.6 / 1.35 / 1.15 倍・太字。*見出しを打つと行が広がる*(狭めはしない)

*表を壊さない線引き*: 書式と読めるものが1つも無ければ何もしない。
`2*3*4`(掛け算)・`2**10`(冪)・`ABC_001`(名前)・`-100`・`1.5`・`2026-08-09`・`商品名*`(片方だけの印)は、今までどおりそのまま出る。
印が語の中にあるとき、そして囲みの中身が数字だけのときは、書式にしない。

== Python — マクロの代わりに

コードの書き方(*範囲⇄配列*・API・=PY の引数と返り値)の説明はlink:python-manual.ja.adoc[Python の手引き]。
この章は操作の側から。

*VBA 型のマクロはない。* データとプログラムを1つのファイルに入れる仕組みを**持たない**。
VS Code と Excel を合わせたものだと思ってほしい — 表は .xlsx、コードは .py で、どちらもファイルとして別々にある。

* 人とやり取りするのは**データだけ**。受け取ったブックにコードは入っていない
* 関数は `~/.config/officework/funcs/*.py`、手続き(マクロ)は``~/.config/officework/plugins/*.py`` に置く。*1機械1回の据え付け*
* だから「開いただけで他人のコードが走る」が原理的に起こらない
* コードが自分のものだけなので、サンドボックスは使わない(VS Code でスクリプトを走らせるのと同じ扱い)

=== 準備

* Python: `JO_PYTHON` → `.venv/bin/python` → `python3` の順で探す
* `officework` パッケージを **calc の実行ファイルの隣**に置く。あるいは``pip install officework`` で入れる。calc は自分の居場所を `sys.path` に足して``from officework import sheet`` するので、要るのは **`officework/` のディレクトリ**であって裸の `.so` ではない。この木から作るなら``maturin build -m pysheet/Cargo.toml --release`` の wheel を入れる
* 置き場は2つ(無ければ作る):
** `~/.config/officework/funcs/` — *セルの式から呼ぶ関数*(UDF)
** `~/.config/officework/plugins/` — *人が押して走るマクロ*

=== 置き場を2つに割った理由(2026-08-16)

前は1つでした。
すると**マクロの補助関数まで、表の式から呼べる関数になっていました** — `def 補助():` と書いたつもりの物が `=補助()` で呼べる。
危うさが違います:

[cols="1,1,1"]
|===
| |関数(funcs) |マクロ(plugins)

|呼ぶ人 |*式*(`=税込(A1)`) |*人*(一覧から選ぶ)
|いつ走る |ブックを開くたび・再計算のたび |押したときだけ
|誰の判断で |セルに残った式(書いた本人が居なくてもよい) |そのときの人
|引数 |値だけ |ブック丸ごと
|===

*式に残るものは、人の押す手を通らずに走り続けます。* だから置き場を分け、「式から呼べる」は funcs に置いた物だけにしました。

既に plugins に関数を置いている場合は、funcs へ移してください(空のまま plugins に .py があると、起動時にそう言います)。

=== セル関数を Python で書く

`~/.config/officework/funcs/道具.py` に**普通に def を書くだけ**:

[source,python]
----
def 倍(x):
    return x * 2

def 縦横(表):
    return [[v * 10 for v in row] for row in 表]
----

セルには普通の関数として書く。
*デコレータも登録も要らない*:

----
=倍(A1)              → 42(A1 が 21 のとき)
=縦横(A1:B2)         → 右下へ 2×2 に広がる
----

* 関数の名前は**日本語でよい*
* *引数が変われば裏で計算し直す*(`@計算` を押さなくていい)。計算は別スレッドでまとめて回り、答えが揃ってから1手で書き戻る
* 引数は式を**いま評価した値**で渡す(範囲は行×列の2次元リスト)
* 返り値が2次元なら右下へ**スピル**(1次元は縦に展開)。展開先に他人のデータや式があれば `#SPILL!` で止まる — 潰さない。結果が縮んだら前回の面の残りは消える
* 組み込みの関数名(SUM など)は譲らない。同じ名前の def は見送る
* 同じ名前が2つの .py にあるときだけ `=道具.倍(A1)` とモジュール名を付ける
* .py を書き換えると calc が気づいて計算し直す
* 一度も計算していないセルは `#PY?`。Excel で開くと `#NAME?` になる(保存された値は Excel が再計算するまでは見える)
* 古い書き方 `=PY("倍", A1)` も動く
* **数式 > Python の関数**を押すと、funcs にある関数が一覧で出ます。選ぶとその .py が編集の道具で開きます

*セル関数から AI を呼ばないでください。* 式は再計算のたびに走ります。
1万行に入れれば1万回走り、開き直すたびに答えが変わります。
何回走ったかも見えません。

*AI はマクロから呼びます。* 押したときだけ1回走り、結果は普通の値としてセルに入ります。
以後は揺れません。
取り消しの1手で戻せます。

これは手元で動くモデルでも同じです。
料金と「字が外へ出る」心配は減りますが、答えが揺れることと、走る回数が見えないことは変わりません。

=== @コマンド

[cols="1,1"]
|===
|打つもの |動き

|`@モジュール` |`~/.config/officework/plugins/モジュール.py` を上から下まで走らせる
|`@モジュール.関数` |その .py の関数だけを呼ぶ
|`@edit 名前` |*その .py を calc の中で開いて編集する*(無ければ下書きを作る)
|`@list`(または `@`) |funcs と plugins の .py と、その中の def の一覧
|`@計算` |セル関数の計算を手で回す(普段は自動なので要らない)
|`@export 名前` |**古い**ブックに載っているコードを .py に取り出す(実行はしない)
|`@del 名前` |古いブックに載っているコードを外す
|===

`@名前 net` は要らなくなった(サンドボックスを使わないので網の区別が無い)。
打つとそう言われる。

=== 記録は何を書くか(2026-08-16)

*記録中は下のステータスバーに赤い「● 記録中 N 行」が出ます。* 押すと止まります。
リボンの「操作を記録」も赤くなります。

書かれるのは、押した命令の名前ではなく**掛かった結果**です:

[cols="1,1"]
|===
|したこと |残る行

|A1 を選ぶ |`s["A1"].select()`
|太字 |`s["A1"].font.bold = True`
|中央揃え |`s["A1"].align = "center"`
|パーセント |`s["A1"].number_format = "0%"`
|並べ替え・消去・貼り付け |`s["A1:B3"].value = [[…], […]]`
|余白を変える |`s.set_page_setup(margins_mm=(10, 10, 10, 10))`
|リボンに足したマクロを押す |`xw.run_macro("締め")`
|===

*入切の物は「押した回数」ではなく行き着いた姿を書きます。* 太字を2回押したら `= True` と `= False` の2行になります。
巡回する余白のボタンも同じで、最後に行き着いた mm が入ります。

選択の行は、**何かを記録する直前に**前と変わっていたときだけ入ります(矢印キー1回ごとに書くと記録が洪水になるため)。

=== まだ書けない操作

罫線・図形・グラフのように Python から使う方法がまだ無い操作は、記録に

    # この操作はまだ Python で書けません: テキストボックスを挿入する(instext)

と残ります。
*黙って落としません。* この行がそのまま、Python から使う方法の宿題の一覧になります。
書式の一部だけ書けた場合も、この註が出ます —半分だけ走るマクロは、走らないマクロより悪いからです。

* *新しい .py*: 置き場に新しいスクリプトを作って開く
* *一覧*: `~/.config/officework/plugins` の .py を並べ、*選ぶと走る*。直すのは「置き場を開く」か `@edit 名前`
* **ファイル > マクロ**からも同じ一覧が出ます(本家と同じ場所)
* *置き場を開く*: `~/.config/officework/plugins` をファイル管理で開く

置き場の名前は `plugins` のままです — 既に置いてある人の物を迷子にしないためで、画面の言葉だけを「マクロ」に揃えました。

=== 3つの置き場(まとめ)

[cols="1,1,1"]
|===
|置き場 |呼ぶ人 |いつ走る

|`funcs/` |*式*(`=税込(A1)`) |開くたび・再計算のたび

だから同梱のスクリプトを置き場へ写しても、そのままでは同じようには走りません。

== 保護タブ

* *保護*: いまのシートを読み取り専用にする(編集をブロック。同じボタンで解除)。*パスワードは掛けない — 掛けた振りもしない*。xlsx のsheetProtection と往復するので Excel でも保護されたシートに見える
* *暗号化する*: パスワードを決めると次の保存から **AES-256(Agile。Excel 2013+ の既定)**で包む。Excel や LibreOffice でも開ける。空にして Enter で暗号化をやめる。開くときはパスワードのダイアログ(伏せ字)。*開く側は古い AES-128(2007 の Standard)も Agile も両方読める*
* *デジタル署名を追加*: *隣に置く署名ファイル*(`名前.xlsx.sig`、Ed25519)。押すと、署名が有効なら報告、無い・中身が変わったなら署名し直す。Excel の署名欄に出る方式ではない — 改ざん検知と名前の証明が実体

== 印刷と PDF

レイアウトタブで設定し、ファイル > 印刷 で PDF に書き出す。

* 用紙: A4 / A3 / B4 / B5 / A5。*B は JIS*(日本の事務様式の実情に合わせる)
* 向き・余白(既定 20mm / 狭い 10mm / 広い 30mm)・拡大縮小(100→90→80→70→50%)
* 印刷範囲(選択して指定。もう一度で解除)、改ページ、タイトル行の繰り返し、枠線も印刷、見出し(行番号・列名)も印刷
* これらは xlsx にも保存される(原文への属性差し替え — 理解しない属性は消さない)ので、Excel で開いても同じ印刷設定になる
* PDF には値・書式・罫線・塗りと、このアプリで挿した図形・画像が写る
* *横に大きい表は横へページを送る*: 紙の幅で列を束に割り、束ごとに全行を出してから次の束へ(Excel の既定と同じ「縦 → 横」の順)。束の頭には列名の見出しとタイトル行も出る。**1列だけで紙より広い列**は割りようが無いので切れ、その本数をステータスバーで言う(幅を詰めるか用紙を大きく)。図形・画像は最初の束の紙にだけ出る
