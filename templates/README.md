# 台帳テンプレ集 — 「N 個のブック」の実証

**新しいソフトはバイナリではなくブック**(SEKKEI「端末のソフトの土台として」)。
このフォルダの xlsx は、帳票+運用が1つになった「業務アプリ」の見本。
共有フォルダに置いてコピーして使う。作り直しは `cargo run -p sheet --example gen_templates`。

**ブックにコードは入っていない**(2026-08-09 確定 — データとプログラムを1つの
ファイルにしない)。関数も手続きも隣の .py にあり、`~/.config/office/plugins/` に
自分で据え付けて使う(1機械1回)。

    cp templates/台帳の関数.py  ~/.config/office/plugins/
    cp templates/取り込み.py    ~/.config/office/plugins/

**中身を読んでから置くこと。** 受け取った .py を確かめずに据え付けるのは、
受け取った実行ファイルを叩くのと同じ。生成器(`gen_templates`)は配る前に
**ブックにコードが入っていないこと**を確かめている。

## 問い合わせ台帳.xlsx

Web フォームの受信箱を事務で回す台帳。

- 状態列は三択(未対応/対応中/完了 — 入力規則)
- H2 の集計は、plugins に関数を置けば `=状態集計(…)` で出る。
  **引数が変われば裏で計算し直す**(押すボタンは無い)
- 取り込みの手続きは隣の **取り込み.py**。中身を確かめて
  `~/.config/office/plugins/取り込み.py` に置き、`@取り込み` で新着を追記する

## 在庫台帳.xlsx

- 在庫金額は式(=在庫数×単価)
- 「要発注」(在庫数<発注点の品)は plugins の関数で出す

## 勤怠表.xlsx

- 曜日は日付関数(WEEKDAY/DATE)。出勤・退勤を「9:00」の形で打つ
- 実働h(休憩1時間引き)は plugins の関数。合計は SUM

## 共通の約束

- **開いただけでは何も実行されない。** ブックにコードが入っていないので、
  受け取ったファイルが実行の起点になることが原理的に起きない
- 走るのは自分で plugins に置いた .py だけ。**置く前に読む**のが唯一の門
- 同僚が Excel で開いても値は見える(plugins の関数を呼んでいるセルは
  Excel では #NAME? になる — 値は保存されているので再計算するまでは見える)

## 見出しの書式は型紙で決める

セルの文字列は**マークダウンとして描かれる**(`# 見出し` `**太字**` `- 箇条書き`)。
見出しの大きさは、ブックの**名前付きセルスタイル**「見出し 1 / 2 / 3」
(xlsx の `cellStyles`、Excel の builtinId 16/17/18)を見る。

- 型紙(.xltx)にこのスタイルを定義しておけば、そこから作ったブック全部に効く
- Excel や ONLYOFFICE で「見出し 1」を編集すると、こちらの見え方も追随する
- 定義が無ければアプリの既定(普通の文字の 1.6 / 1.35 / 1.15 倍・太字)に落ちる
- 見出しを打つと、その大きさに合わせて**行の高さが広がる**(狭めはしない —
  手で決めた高さを打ち直しで壊さないため)
