= officework 0.5.0-beta.6

English: link:RELEASE.adoc[RELEASE.adoc]

試すには: `pip install --pre officework`

この版も、公開されている様式が教えてくれたものです。国税庁の「酒税関係
総括表」と「消費税の課税状況」、総務省の「給与所得者数・給与額・税額」、
内閣府の「面談の記録」を officework で PDF にして、同じ場所に置いてある
PDF と見比べました。

前の版でいちばん目立ったのは、**表が紙からあふれる**ことでした。原因は
2つに分かれ、どちらも直りました。

== 列の幅が、Excel と同じ幅になります

**余白の5画素を二重に足していました。** xlsx が列に持っているのは
「標準の書体の数字が何文字ぶん入るか」という値で、セルの内側の余白は
その値にもう入っています。それをもう一度足していたので、**1列あたり
1.3mm ずつ広がって**いました。列の多い表ほど効きます。酒税の総括表は
21 枚が 12 枚になりました。

**数字1文字の幅を 7画素の決め打ちにしていました。** これは書体と大きさで
変わります。ＭＳ 明朝 10.5pt なら 7画素ですが、Arial 12pt なら 9画素です。
そのブックの標準の書体から測るようにしました。給与所得の表は標準が
Arial 12pt で、列が 22% 狭くなっていました。

**「紙 N 枚に収める」を、選ばれていないのに使っていました。** この指定は
「拡大縮小」の欄と組で意味を持ちます。印が無ければ Excel は倍率のほうを
使います。消費税の表は倍率 78% と「横2枚」の両方を持っていて、後者を
使うと 83.7% に**広がり**、紙が1列ぶん増えていました。

**表の右の縁を、数えなくなりました。** 表の右端を「隣の列の左の罫線」と
して書いてある帳票が多く、その1列を刷る範囲に数えると紙が増えます。
酒税の総括表は5シート中4つがこの形でした。

== 数字が、隣の欄にはみ出しません

**無い書体を、幅の合う書体に置き替えます。** 前は系統(明朝かゴシックか)
だけ合わせていました。ＭＳ 明朝は半角95字すべてが同じ幅ですが、当てて
いた IPAex明朝は字ごとに幅が変わり、数字が 24% 太くなります。桁の多い表
では数が隣とぶつかっていました。

梅明朝・梅ゴシック・梅P明朝・梅Pゴシックが、ＭＳ の4つと**1字ずつ
一致**します。Century は C059、Arial・Times・Calibri・Cambria・
Courier New はそれぞれの互換フォントに当てます。

**組む幅を、実際に描く書体で測ります。** どの書体でも「半角 0.55em・
全角 1.0em」で見積もっていました。右揃えの位置も、折り返す所も、セルに
入るかの判定も、この見積りで決まっていました。

**入らない数は `#####` にします。** Excel と同じです。文字は右隣が空いて
いればはみ出してよいのですが、数はいけません。桁の切れた数を見せるより、
入らないと知らせるほうが安全です。

== セルの書式を、全部見ます

25 項目のうち 11 しか見ていませんでした。紙に出るものは全部入れました。
読まないのは保護の2つだけです。

* 字下げの1段が、空白3つぶんになりました。全角1字で数えていました。
  右揃えのセルは右から空けます
* 縦の揃えを見ます。前はどのセルも下揃えでした。上下に結合したセルは
  高さも合算するので、見出しが結合の1行目の下端に出なくなりました
* 縦書きの見出しが、縦に積まれます。前は横に伸びて隣の列まで届いて
  いました。0度から180度の回転も出ます
* 「縮小して全体を表示」が効きます。字を縮めて入れます。何行にもなる
  セルには効きません
* 下線・取り消し線・下付き・斜体を刷ります。斜体は、書体が斜体の顔を
  持っているときだけ倒します
* 網掛けが18種類とも出ます。前は全部が前景色のべた塗りで、薄い網掛けが
  真っ黒に潰れていました。柄の濃さに応じて色を混ぜます
* グラデーションは、2色を混ぜた1色で塗ります

== 図が出ます

**WMF(Windows メタファイル)の図を描きます。** 内閣府の面談記録の様式は
3枚の図のうち2枚がこの形で、前は絵として読めず消えていました。WMF は
絵ではなく線と塗りの並びなので、画素にせずそのまま刷ります。**拡大しても
粗くなりません。**

PDF の書き手が、曲線・切り抜き・点線を扱えるようになりました。

== そのほかの変更

* 文書の部品を、名前ではなく関係の種類で探します。名前が違う docx でも
  開けます
* 右クリックの品書きが、訳の表を通るようになりました
* 編集のたびにシートを丸ごと控えるのをやめました。20万升のシートで
  1回 33ms が 36µs になります
* 様式のパネルの見出しが、どの面でも同じ並びになりました

== 内部の変更

PDF の書き手に「道」が増えました。移動・直線・ベジェ曲線・閉じるの並びで、
塗りと線を両方付けられ、点線と切り抜きも持てます。切り抜きは1つの道に
だけ掛かるので、並びの途中に物を足しても残りません。

書体の置き替えが、幅の合う相手を先に探すようになりました。相手はどれも
自由に使える許諾のもので、同梱はしていません。
