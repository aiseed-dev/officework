= officework 0.5.0-beta.7

English: link:RELEASE.adoc[RELEASE.adoc]

試すには: `pip install --pre officework`

この版も、公開されている様式が教えてくれたものです。国税庁の「酒税関係
総括表」、内閣府の「調査票(適性評価)」と「面談の記録」を officework で
PDF にして、同じ場所に置いてある PDF と見比べました。

前の版で表の幅が合うようになったので、今度は**縦**が合いませんでした。
同じ文書が向こうより1〜2枚多くなり、行が下へずれていきます。

== 行の高さを、書体から出します

**どの行も 6.4mm の決め打ちでした。** 書体も字の大きさも見ていません。
Word も LibreOffice も、まず書体から自然な高さを出し、その上に段落の
指定を掛けます。同じ2段にしました。

**置き替えた書体の縦の寸法は、原本と揃いません。** 梅明朝は 1.0000em、
ＭＳ 明朝は 1.292em です。横幅は合わせてありますが、縦は別物です。
行送りは原本の書体の名前で引くようにしました。名前が表に無ければ、
その機械にある書体そのものから出します(LibreOffice と同じで、OS/2 の
usWinAscent と usWinDescent に hhea の lineGap を足します)。

**「行の高さを何 pt にする」という指定を、倍率に直していました。**
`w:lineRule` の `exact` と `atLeast` は高さそのものです。6.4mm で割って
倍率にしていたので、決め打ちをやめると合わなくなります。高さのまま
持つようにしました。

調査票は6枚が5枚になり、向こうと同じ枚数になりました。本文の行送りは
15.50pt で、向こうは 15.54pt です。

== 段落スタイルの見た目が効きます

docx はスタイルの定義を一緒に持ってきます。そこにある字の大きさ・色・
揃えを、こちらのテンプレートで上書きしていました。面談の記録の見出しは
20pt・中央揃え・青ですが、うちのテンプレートの 16pt・左揃え・黒で出て
いました。

文書が自分でその名前のスタイルを持っていれば、そちらを使います。持って
いなければ今までどおりテンプレートです。`w:basedOn` の連なりもたどります。

字の大きさも同じ話で、調査票の本文は 12pt のところを 11pt で組んで
いました。本文のスタイルが `w:sz 24` と言っているのを見ていなかった
ためです。

== 画像が、字と同じ行に並びます

docx の絵は run の中に入るので、字の流れの一部です。うちは段落の下に
置いていたので、見出しの絵が見出しの1行下へ落ち、見出しと絵をまとめて
中央に置くこともできませんでした。

段落の頭にある絵は、1行目の字の左に置きます。絵が字より高ければ、
行をその高さまで広げます。

**透けている絵の背景が、灰色の四角になっていました。** PNG の透けぐあいを
捨てていたためです。PDF の決まりどおり、透けを別の流れにして色の側から
指すようにしました。

== テキストボックスの余白

左右 1.5mm の決め打ちで、縦はどの箱も真ん中に寄せていました。DrawingML の
既定は左右 0.1インチ(2.54mm)・上下 0.05インチ(1.27mm)で、縦の寄せは
上です。ファイルが `lIns` などで別の値を言っていれば、そちらを使います。

== 罫線

* **結合したセルの罫線が、中まで引かれていました。** 結合は1つのセル
  なので、外側だけ引きます
* **斜めの罫線を引きます。** 結合したセルでは、結合の全体に1本引きます

== 開いて保存しても、原本が変わりません

**行頭にタブが増えていました。** 段落の設定にある「タブを打ったとき字が
止まる位置」の定義を、タブの文字として読んでいたためです。調査票では
8つの段落で字が変わっていました。

**絵の控えが途中で切れていました。** ファイルの頭に BOM が付いている
docx で、原文を切り出す位置が3バイトずれます。面談の記録がこれで、
開いて保存しただけで壊れた XML になっていました。

**スタイル定義への関係を、二重に書いていました。** 部品の名前が
`styles.xml` でない docx(面談の記録は `styles2.xml`)で、こちらの分を
足していました。同じ種類の関係は1つだけです。

== そのほかの変更

* 升の内側の余白が、Excel と同じ2画素になりました
* 行の終わりの空白1つが、それだけの行になることがなくなりました
* 番号付きの箇条書きの印を、文書が言うとおりに出します
* 図形の塗りの色を、字の色として使わなくなりました
* 「紙1枚に収める」で、いちばん高い行のぶんを見落として最後の行が
  はみ出すことがなくなりました

== 内部の変更

`kumihan::Document` に `style_matome` が入りました。スタイル定義を
`w:basedOn` までたどって1つにまとめ、その文書が持っていなければ `None` を
返します。

`InlineImage` が、段落の字の中でどこに居るかを持つようになりました。

openpyxl と python-docx との差分検査が入りました。公開されている属性を
すべて歩いて、こちらの値と突き合わせます。
