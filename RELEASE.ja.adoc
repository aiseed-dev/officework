= officework 0.5.0-beta.4

English: link:RELEASE.adoc[RELEASE.adoc]

試すには: `pip install --pre officework`

この版は、実物の文書1つが教えてくれたものです。内閣府が配っている告知書を
officework で PDF にして、同じ場所に置いてある PDF と見比べました。その1つの
ファイルから3つの不具合が出ました。どれも、同じ形の日本の書類なら同じように
出ます。

== 字下げが元と合うようになりました

原因は3つあり、どれも1ページ目に出ていました。

左のインデントを全角2文字きざみに丸めていたので、1文字の字下げが2文字に、
3文字が4文字になっていました。あの告知書では 123 か所で指定しています。
段落がファイルの値をそのまま持ち、保存でも同じ値を書き戻すので、開いて
保存しただけで字下げが動くこともなくなりました。

文字数で書いた字下げ(`w:leftChars` など)を読んでいませんでした。日本語の
Word はこの形で書き、両方あるときは**こちらを優先します**。文字数だけで
書かれた文書は、字下げが全部消えていました。

あの告知書の字下げは、そもそも段落の設定ではありません。**行頭に全角
スペースを打ってあります**。日本の書類ではこちらが普通です。それを落として
おり、落とさないようにしても半角スペースの幅(12pt に対して 3.48pt)で
描いていました。9個で、宛名が本来の場所から 76.7pt ずれます。

直した後は、「様」が 178.90pt(元の PDF は 178.92pt)、「大臣」が 394.90pt
(同 394.92pt)です。

== 他のソフトで作ったテキストボックスが印刷されます

同じ告知書には、窓口の欄が3つ(省庁・住所・電話・電子メール)と、その下に
注記があります。1つも出ていませんでした。

**消えていたのではありません。** うちが書いた物でない図形は原文のまま
持ち越すので、開いて保存しても壊れません。紙まで届いていなかっただけです。
Word はこの種の枠を本文の流れに対する位置で書くので、組んでみないと場所が
決まりません。大きさと中身は XML から読み、置き場所は組んだ後で決める、と
2つに分けました。

中身を読ませるために2つ直しました。枠の中の**最初の1行しか読んで**
いませんでした。うちが書く図形は1行なので気づきませんが、この欄は5行あり、
4行が落ちていました。描く側も1行に繋げていたので、隣の枠まではみ出して
いました。

== 英語がイギリスとアメリカに分かれました

画面の文言は英語で1つ、文書の設定は2つです。日付の並びが国で割れていて、
どちらかを黙って選ぶと必ず片方が間違うためです。

[cols="2,1,1"]
|===
|言語の設定 |短い日付 |用紙

|`en`・`en_US` |m/d/yyyy |レター
|`en_GB`・`en_AU`・`en_IE`・`en_ZA`・`en_NZ` |dd/mm/yyyy |A4
|===

国を名乗っていて、それがアメリカでない英語はイギリス式にします。豪州・
ニュージーランド・アイルランド・南アフリカ・インドがどれも dd/mm/yyyy を
使うためです。知らない国も止まらず同じ側に落ちます。

これは選べるようにしただけでなく、不具合の修正でもあります。日付の表は
`en` という札の下にイギリス式を持っていて、アメリカ英語も同じ所へ落ちて
いました。アメリカの表計算を開くと、日付が英国式で出ていました。docx にも
`en-GB` か `en-US` と書くようになりました(前は短く `en` と書いていました)。

== そのほかの変更

* 右のパネルを「プロジェクトパネル」、左を「エージェントパネル」という
  名前にしました(15言語とも)。右のパネルは「ファイル」と名乗って
  いましたが、作成・名前の変更・削除ができるようになった時点で、
  ファイルの一覧ではなくなっていました
* 見本のスクリプトを、いまのエンジンの書き方に合わせました

== 内部の変更

利用者からは見えません。**検査が3つ、何も検べていない状態**になっていました。

リボンの解析器の自己試験は、表を6通りに崩して全部で止まることを見ます。
そのうち5つがボタンの表示名を字で持っていて、表示名が8月に英語へ変わった
日から**何も崩していませんでした**。崩していないファイルを渡して、
「この検査は効いていません」と言い続けていたことになります。崩す先を
原文から探し、字が実際に変わったかどうかも見るようにしました。

リボンの表を作る生成スクリプトが、実物を再現できなくなっていました。
そのまま生成し直すと、beta.3 で押せるようにした9つのボタンが灰色に
戻ります。直す途中で、生成スクリプト自身の穴も出ました。灰色の
「どれか1つ」は出せるのに、押せる方を出す道がありませんでした。

Windows で組めるかの検査を Linux から行っていましたが、polars が C の
コードを連れてきた時点でできなくなっていました。Windows の機械で行います。
