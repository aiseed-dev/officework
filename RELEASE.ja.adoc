= officework 0.5.0-beta.3

English: link:RELEASE.adoc[RELEASE.adoc]

試すには: `pip install --pre officework`

== ページ割りが Word の決まりに合いました

docx を保存するとき、行の高さもファイルに書くようにしました。書かないと、
開いたソフトが自分の既定の行の高さを使います。Word の「1行」は文字の
1.15 倍ほど、こちらは 10.5pt に対して 6.4mm(1.73 倍)だったので、同じ
文書が別のページ数になっていました。

あわせて、最後の行が下の余白へはみ出す不具合も直しました。ページ割りの
計算が文字の下に伸びる部分を数えておらず、1.4mm はみ出していました。

200 段落の文書で確かめています。直す前は、こちらで作ると5ページ、
LibreOffice で開くと3ページでしたが、いまは**どちらも6ページで、
各ページの区切りまで同じ**です
(1ページ目 1〜38 行目、2ページ目 〜78、3ページ目 〜118、4ページ目 〜158)。

NOTE: 確かめたのは LibreOffice です(手元に Word がありません)。行送りの
決まりは Word と同じ物を書いているので、Word でも同じに折れるはずですが、
実機では見ていません。

== openpyxl・python-docx でできることに追いつきました

エンジン(`pip install officework`)の機能を openpyxl・python-docx の機能の
一覧と突き合わせ、100% になりました。

[cols="2,1"]
|===
|突き合わせた物 |結果

|openpyxl の Workbook / Worksheet / Cell |100%
|python-docx の Document / Paragraph / Run / Table |100%
|openpyxl が書けるグラフの種類 |11 / 11
|===

グラフは openpyxl と同じ 11 種類を作れます。縦棒・折れ線・面・円・
ドーナツ・補助縦棒付き円・レーダー・散布図・バブル・高安終値(株価)・
等高線です。補助縦棒付き円グラフでは、円と棒を結ぶ線も引きます。

公開されている記事のサンプル 24 本を、元のライブラリと officework の
両方で動かして結果を突き合わせ、見つかったずれを直しました。いちばん
大きかったのは `ws["A1"]` で、元のライブラリはセルを返すのに、こちらは
値を返していた所です。

== 図形が文書に入りました

docx に図形を置けるようになりました(python-docx は画像しか置けません)。
`d.add_shape("roundRect", 25, 80, 40, 25, fill="DDE7F0", text="承認")` の
ように、形の名前と位置と大きさを渡します。四角形・角丸四角形・楕円・
矢印・ひし形・線の6種類に、塗りつぶし・枠線・中の文字・回転・不透明度・
影を付けられます。

位置と大きさは、ページの左上からの mm で指定します。図形の標準の形式
(DrawingML)で書くので、Word でも LibreOffice でも**図形として選んで
編集できます** — 画像に変換して貼るのではありません。
開いて保存し直しても壊れず、2ページ目以降にも置けます。

グループ化した図形は本物のグループ(`grpSp`)として書くので、Excel や
Word で開いてもひとまとまりのまま扱えます。

writer の画面でも図形を選んで動かせるようになりました。

== リボンの押せないボタンが無くなりました

押しても何も起きないボタンと、押せない灰色のボタンが、writer にも calc にも
1つも残っていません(beta.2 の時点では 14 件ありました)。

図形の前面・背面への移動、整列、グループ化、結合、ブックの構造の保護、
改ページプレビューが押せるようになっています。

== そのほかの変更

* ページを画像でも保存できます(`save("ページ.png")`)。既定は 150 dpi で、
  `dpi=300` のように細かさを指定できます
* セルの中の一部だけに付けた飾り(文字の一部だけ太字など)が、保存で
  消えなくなりました
* 表計算の画面から、ブックの構造と範囲を保護できるようになりました。
  **パスワードは掛けません。** 実際には守れないものを、守れるように
  見せないためです。どちらも xlsx に書くので、Excel でも効きます
* 表計算の画面で、改ページプレビューと標準表示を切り替えられます
* 蛍光ペンのような半透明の塗りが、画面でも PDF でも出ます
* 手描きのペンが PDF にも出るようになりました(蛍光ペンは文字の下に、
  ペンは文字の上に描かれます)
* 画面の言葉とテンプレートの訳を、15 言語すべてで見直しました

== 内部の変更

利用者からは見えませんが、この版で**印刷の見た目を画像で突き合わせる
検査**を作りました。見本のページを画像にして控えておき、同じ入力から
同じ画像ができるかを毎回確かめます。

作ったのは、数値の試験は全部通るのに、見た目だけが壊れることが続いた
ためです。この版で見つけて直した物のうち6件は、出来上がりを開いて
見るまで分かりませんでした。画像と透かしが PDF から消えていた、
角丸四角形が PDF でだけ角の丸みを失っていた、影と不透明度が PDF で
効いていなかった、画面の図形の枠線が半分の太さだった、手描きのペンが
PDF に出ていなかった、最後の行が余白へはみ出していた、の6件です。
