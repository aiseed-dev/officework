= officework 0.5.0-beta.5

English: link:RELEASE.adoc[RELEASE.adoc]

試すには: `pip install --pre officework`

この版は、公開されている2つの様式が教えてくれたものです。国税庁の
「酒税関係総括表」と内閣府の「適性評価の実施に当たってのお知らせ」を
officework で PDF にして、同じ場所に置いてある PDF と見比べました。
以下はすべて、その見比べから出たものです。

== 表計算が、ファイルの言うとおりに刷れます

7件あり、どれも酒税の表の1ページ目に出ていました。

**セルの中で折り返していませんでした。** 見出しのセルは「販 売 場 数」の下に
「Number of licensed sites to sell liquors」を持ち、折り返しが指定されて
います。1行に伸ばしていたので、隣のセルを越え、右の余白を越え、紙からも
はみ出していました。折り返すようにし、**結合したぶんの幅**で折ります。
この手の見出しは何列にもまたがるので、そこが要でした。

**セルの中の飾りを見ていませんでした。** 同じセルは 8pt で、英文だけ 6pt の
別の書体です。セル1つに大きさ1つで描いていたので、英文が大きく出て、
折り返しの位置もずれていました。run ごとの大きさで描きます。

**PDF に埋める書体が1本だけでした。** この様式は本文にＭＳ明朝、見出しに
ＭＳゴシック、英文に Century を使いますが、全部1つの字で出ていました。
要るだけ埋めます。その書体に無い字は、消さずに別の書体に落とします。

**負の数が書式の負の区画を見ていませんでした。** 書式は「正;負;ゼロ;文字」の
区画に分かれ、この様式は「△ 5,148」と書きます。最初の区画だけを読んで
`-` を付けていました。

**均等割付が左に詰まって**いました。区分の列はセルの幅いっぱいに字を配ります。
**中央揃えも左に出て**いました。左か右かしか見ていなかったためです。

**紙の上下の余白を、左右の値で扱っていました。** この様式は左右 25mm・
上下 30mm です。1ページ目は正しく、2ページ目からは 5mm 高く始まり、
下も 5mm 余っていました。1ページに2行余分に入ります。

== 文書が、字下げと枠と罫線を保ちます

**字下げが消えていました。** 日本の様式は段落の設定ではなく空白で字下げ
します。3つの所で落ちていました。左のインデントを全角2文字きざみに丸めて
いたので1文字が2文字になり、文字数で書いた指定(日本語の Word が使う形)を
読んでおらず、行頭の全角スペースを捨てるか半角の幅で描いていました。
内閣府の告知書では、宛名が本来の場所から 76.7pt ずれていました。いまは
178.90pt(元の PDF は 178.92pt)です。

**他のソフトで作ったテキストボックスが紙に出ていませんでした。** 開いて
保存しても壊れてはいませんでした(原文のまま持ち越すので)。うちが書いた
図形しか描いていなかっただけです。告知書6ページ目の窓口の欄3つと、その
中の5行が出るようになりました。

**表の罫線を読んでいませんでした。** 模型に置き場が無く、どの表も四方に枠が
出ていました。下線だけの記入欄が枠だらけになります。表ごと・セルごとの
指定どおりに引きます。何も言っていない docx の表には引きません(Word が
そうです)。

**部品を決まった名前で探していました。** `word/styles.xml` は慣習で、決まり
ではありません。OOXML は関係で在り処を示します。片方の様式は
`word/styles2.xml` を使っていて、**スタイルも設定もテーマも1つも読めて
いません**でした(403 件のスタイルの名乗りが見えていませんでした)。

== 表を AsciiDoc にするとき

セルの中の飾りは adoc に持ち込まない決めなので、**せめて形が残る**必要が
あります。3つが残っていませんでした。

セルの中の改行が空行になり、段落2つとして読まれていました。AsciiDoc 本来の
改行で書きます。行頭と行末の空白が削られ、字下げごと消えていました。
AsciiDoc が持っている「空の印」で守ります。升は桁の数で行に切り分けますが、**入るかどうかを
見ずに**入れていたので、幅の広い結合が行から溢れ、後ろが1行ずつずれて
いました。

酒税のシートは、557 升とも往復するようになりました。前は 56 升が
変わっていました。

== そのほかの変更

* 右のパネルが IDE のような木になり、ファイルを開くとその場所が見えます
* 1つのことをするリボンのボタンを1段にまとめました

== 内部の変更

PDF の書き手は、書体を1本だけ埋める作りでした(1つの面・1つの部分集合・
1つの資源)。何本でも持てる形にしたのが、セルごとの書体の元です。
1本だけ渡す入り口は今までどおりです。

`Paper` が余白を4つ持つようになりました。欄を足すとコンパイラが 25 か所
すべてを挙げるので、見落としようがありません。
