# 見本の .py — 置けば動きます

ここの `.py` を **`~/.config/officework/plugins/`** にコピーして、calc を開き直すと使えます。

```
mkdir -p ~/.config/officework/plugins
cp sample/plugins/*.py ~/.config/officework/plugins/
```

置き場はアプリが起動時に作るので、無ければ一度 calc を開いてください。

## 何が置いてあるか

| ファイル | 呼び方 | 何をするか |
|---|---|---|
| `税込.py` | `=税込(A1)` | セルの関数。消費税を足して丸める |
| `天気.py` | `@天気` | 手続き。天気予報を取って表に書く |
| `家計簿.py` | `@家計簿` | 手続き。レシートの写真を AI に読ませて表に足す |

## 2つの呼び方の違い(ここが officework の形)

**セルの関数**(`=税込(A1)`)は、値から値を作るものです。**網には出ません** —
囲いの中で、外との通信を切って走ります。計算のたびに外へ出ることになり、
ブックを開いた瞬間に意図しない通信が起きるためです。

**手続き**(`@天気`)は、押した時だけ走る仕事です。動いている calc を
そのまま操り(ファイルの複製ではありません)、網にも出られます。何行
書いても **Ctrl+Z 一回で戻せます**。

外から取ってくる仕事は手続き、計算はセルの関数 — この分け方は
[xlwings の記事](https://qiita.com/yniji/items/b38bc312e860027108ac)の
「UDF は計算・マクロは仕事」と同じ筋です。

## 書き方

**飾りは要りません。** `def` を書けばそれが名前になります。

```python
def 税込(x):
    return round(float(x) * 1.1)
```

これだけで `=税込(A1)` が使えます。`@xw.func` のような印は不要で、
**日本語の名前もそのまま**使えます。

手続きは `officework.calc` で動いている calc に繋ぎます。

```python
from officework import calc as xw

def main():
    b = xw.Book.attach()      # いま開いている calc
    b.selection.value = [["あ", 1], ["い", 2]]   # 選んでいる所に表を置く
```

## 要る物

- **Python** — 配り物には同梱されています。自分で入れた Python でも動きます
- **追加のライブラリ** — この2つの見本には要りません(標準の物だけ)
- 手続きから calc を操るには **officework** パッケージ(`pip install officework`)。
  配り物には同梱されています
- `家計簿.py` だけ **AI** が要ります(`ANTHROPIC_API_KEY` か `claude`)。
  レシートは感熱紙で薄く斜めに撮れるので、手元の OCR では金額を読み違えます —
  **家計簿で金額を間違えるのは、読めないより悪い**。AI が無ければ名指しで
  断ります(できない物をできるように見せない)
