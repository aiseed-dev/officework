= adoc の早見表

このファイルを writer で開くと、左にコード、右にページが並びます。
左の書き方と、右の出来上がりを見比べてください。
右のページを押すと、左のその行へ移ります。

== 見出しは、行の頭に == を書きます

=== 小さな見出しは === です

== 段落は、空行で分けます

続けて書いた行は、1 つの段落になります。
ここも前の行と同じ段落です。

空行をあけると、次の段落になります。

== 字の飾り

日本語の中では、**太字**のように * を 2 つずつで囲みます。
斜体は __斜体__ のように _ を 2 つずつで囲みます。

== 箇条書き

* 行の頭に * と空白を書きます
* 1 行が 1 つの項目です

. 番号を付けるときは、行の頭に . を書きます
. 番号は自動で振られます

== 表

|===
|項目 |内容

|氏名 |山田 花子
|住所 |東京都千代田区
|===

表は |=== で始めて |=== で閉じます。
セルは | で区切ります。
1 行に書いたセルが、表の 1 行になります。

== 改ページ

次の行の <<< で、ページを改めます。

<<<

ここから新しいページです。
