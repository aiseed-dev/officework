= aiseed office の紹介ページ(office.aiseed.dev)

Flet(Python の UI の仕組み)で作った 1 枚のページです。aiseed office の紹介と、Flet の紹介を兼ねます。

== 手元で見る

[source,console]
----
$ pip install flet
$ flet run --web --port 8550 web/main.py
----

ブラウザで `http://localhost:8550` を開きます。

== サーバーで動かす

自前のサーバー(office.aiseed.dev)で動かします。置く物は `deploy/` にそろえてあります。

[source,console]
----
$ sh web/deploy/install.sh              # サーバーで root で 1 回
$ certbot --nginx -d office.aiseed.dev  # TLS
----

`install.sh` がすることは次のとおりです。手で置くときも同じ順です。

. `/srv/officework/web` に `main.py`・`assets`・`requirements.txt` を写し、venv を作って `pip install -r requirements.txt` を入れます。Flet の版は `requirements.txt` で決めています(手元と同じ版)。
. `deploy/aiseed-office-web.service` を systemd に置き、`flet run --web --host 127.0.0.1 --port 8550 main.py` を動かします。
. `deploy/office.aiseed.dev.nginx.conf` を nginx に置き、`office.aiseed.dev` を `127.0.0.1:8550` へ渡します。Flet は WebSocket を使うので、`Upgrade` と `Connection` のヘッダーを通します。

版を上げるときは、`main.py` と `assets` を写し直して `systemctl restart aiseed-office-web` です。

[source,nginx]
----
location / {
    proxy_pass http://127.0.0.1:8550;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
}
----

== 載せる物の決め

* 載せるのは動いている物だけです(手引きと同じ)。
* 比較の絵(`assets/word.png` と `assets/office.png`)は、名古屋市立大学が公開している「物品借用願」を Word と aiseed office で開いた物です。版を上げたら撮り直します。様式そのもの(`assets/buppin202411.docx`)も置いてあり、見る人が自分の Word で試せます(発注者 2026-09-19「ダウンロードできたらいいのは docx」)。
* 「画像をコピー」は、Flutter が絵を canvas に描くためブラウザの「画像をコピー」が使えないので、`assets/index.html` の script がページの題名を合図にしてクリップボードへ入れます。
* 版の数字(`VERSION`)はリリースのたびに直します。
* 幅は 1040 までで、それより狭いブラウザ(携帯)では画面の幅に合わせます(`page.on_resize`)。
* 箇条書き(`ft.Markdown`)は、そのままだと字が薄いので、`md()` で本文と同じ色と大きさにしています。

== 保守

版を止めて放っておくことはしません。API は版の間で変わります(Flet 1.0 で `page.launch_url` が `UrlLauncher` に変わりました)。月に 1 回、次をやります。

. `pip install -U flet` で上げ、`requirements.txt` の版をその番号にします。
. `flet_web/web/index.html` を `assets/index.html` に写し直し、2 つの script を足し直します(下の「書体」)。
. `flet run --web --port 8550 web/main.py` で開いて、パソコンの幅と携帯の幅で最後まで見ます。sample/flet_insatsu も同じように開きます。
. 壊れた所を直します。何が変わったかは SEKKEI.adoc に 1 行残します。
. サーバーに写して `systemctl restart aiseed-office-web` です。

`requirements.txt` の版は「この版で動くことを確かめた」という記録です。

== 書体

Flutter(Flet の描画)は日本語の書体を持たず、字ごとに Google の Noto から補います。どの Noto(日本語・簡体字・繁体字・韓国語)で補うかはブラウザの言語設定で決まり、アプリからは指定できません。日本語以外の設定のブラウザでは「、」「。」が繁体字用の中央寄せの字形で出ます(2026-09-19 発注者の指摘)。

書体は同梱しません(発注者「書体の同梱は厳しい」)。代わりに `assets/index.html`(Flet の index.html の写しに 1 か所足した物)で、Flutter が動き出す前に `navigator.language` を `ja` にします。Flet は assets に index.html があればそれを使います。**Flet の版を上げたら、Flet の index.html(`flet_web/web/index.html`)を写し直して、同じ 1 か所を足します。**

根本の直しは Flutter の側です(起動の設定で補いの言語を指定できるようにする)。SEKKEI「検討: Flutter の Web の日本語」を見てください。
